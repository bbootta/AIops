argument-hint: [작업 디렉터리 경로 또는 "용어 = 번역" 직접 입력]
---

회사 용어집(`translation/glossary/glossary.md`)에 용어를 추가하라. 인자: $ARGUMENTS

1. 인자 해석:
   - 작업 디렉터리 경로가 주어지면 그 안의 `delivery-report.md`(또는 `termbase.md`)에서 "용어집 추가 후보"를 읽는다.
   - "용어 = 번역" 형식이면 그 항목을 직접 추가 대상으로 삼는다.
   - 인자가 없으면 `translation/jobs/` 아래 최신 작업의 추가 후보를 사용한다.
2. 각 후보를 기존 용어집과 대조한다:
   - 이미 등재된 용어와 충돌하면 추가하지 말고 충돌 내용을 보고한다.
   - 동일 원문·동일 번역이 이미 있으면 건너뛴다.
3. 추가할 후보 목록(원문, 번역, 분류될 절)을 사용자에게 제시하고 AskUserQuestion으로 승인받는다.
4. 승인된 항목만 `glossary.md`의 해당 절(조직명/직급/제품/업무 용어)에 가나다순으로 삽입한다. 다국어 열은 아는 언어만 채우고 나머지는 비워 둔다.
5. 추가된 항목 수와 위치를 보고한다.
