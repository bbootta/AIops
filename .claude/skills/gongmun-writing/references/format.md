# 공문서 서식·표기 규정

근거: 「행정업무의 운영 및 혁신에 관한 규정」(대통령령, 이하 '영')과 같은 규정
시행규칙(이하 '규칙'), 행정안전부 「행정업무운영 편람」(2020).

## 1. 공문서의 종류 (영 제4조)

| 종류 | 범위 |
|---|---|
| 법규문서 | 헌법·법률·대통령령·총리령·부령·조례·규칙 등 |
| 지시문서 | 훈령, 지시, 예규, 일일명령 등 |
| 공고문서 | 고시, 공고 등 일정한 사항을 일반에 알리는 문서 |
| 비치문서 | 행정기관이 내부에 갖추어 두는 대장, 카드 등 |
| 민원문서 | 민원인이 허가·인가 등을 요청하는 문서와 그 처리 문서 |
| 일반문서 | 위에 속하지 않는 모든 문서 |

## 2. 문서의 성립과 효력 (영 제6조)

- 문서는 결재권자의 **결재**로 성립한다.
- 문서는 수신자에게 **도달**함으로써 효력이 생긴다.
- 공고문서는 특별한 규정이 없으면 **고시 또는 공고가 있은 날부터 5일이
  지난 때**에 효력이 생긴다.

## 3. 문서 작성의 일반원칙 (영 제7조)

1. 어문규범에 맞게 **한글로** 작성한다. 뜻을 정확히 전달하기 위해 필요하면
   **괄호 안에** 한자나 외국어를 함께 적을 수 있다. 특별한 사유가 없으면
   가로로 쓴다.
2. 내용은 **간결하고 명확하게** 표현하고, 일반화되지 않은 약어와 전문 용어는
   쓰지 않는다.
3. 시각장애인 등의 편의를 위해 음성정보·영상정보 등이 수록되거나 연계된
   바코드 등을 표기할 수 있다. 바코드는 문서 상단 '행정기관명' 표시줄
   오른쪽 끝에 2cm × 2cm 범위에 넣는다.
4. 숫자는 특별한 사유가 없으면 **아라비아 숫자**로 쓴다.
5. 날짜와 시간은 아래 4항의 방식으로 쓴다.
6. 용지는 특별한 사유가 없으면 **가로 210mm, 세로 297mm**(A4)로 한다.

## 4. 숫자·날짜·시간·금액 표기

### 숫자 (영 제7조 제4항)

아라비아 숫자로 쓴다. 영어식 천 단위 표기는 쓰지 않는다.

- (×) 10천㎡ 미만 → (○) 1만㎡ 미만

### 날짜 (영 제7조 제5항)

숫자로 쓰되 연·월·일 글자는 생략하고 그 자리에 마침표를 찍는다. **마지막
마침표를 빠뜨리지 않는다.**

- (○) `2022. 12. 31.`
- (×) `20○○.9.7` → (○) `20○○. 9. 7.`
- (×) `20○○.11.2` → (○) `20○○. 11. 2.`

기간은 물결표로 잇는다. 붙임표나 긴 줄표를 쓰지 않는다.

- (×) `10.28-29간` → (○) `10. 28.~29.에`
- (×) `11.20.(금)자에` → (○) `11. 20.(금)에`
- (×) `20○○.1월 이후` → (○) `20○○. 1. 이후`

### 시간 (영 제7조 제5항)

시·분은 24시각제로 쓰되 시·분 글자는 생략하고 그 사이에 쌍점(:)을 찍는다.

- (×) 오후 3시 20분 → (○) `15:20`
- (×) 오전 7시 9분 → (○) `07:09`

### 금액 (규칙 제2조 제2항)

아라비아 숫자로 쓰되 숫자 다음에 괄호를 하고 한글로 적는다.

- (○) `금113,560원(금일십일만삼천오백육십원)`

## 5. 항목의 구분 (규칙 제2조 제1항)

### 가. 항목 기호

내용을 둘 이상의 항목으로 나눌 필요가 있으면 순서대로 아래 기호를 쓴다.
필요하면 □, ○, -, · 같은 특수 기호를 쓸 수 있다.

| 구분 | 기호 |
|---|---|
| 첫째 항목 | 1., 2., 3., 4., … |
| 둘째 항목 | 가., 나., 다., 라., … |
| 셋째 항목 | 1), 2), 3), 4), … |
| 넷째 항목 | 가), 나), 다), 라), … |
| 다섯째 항목 | (1), (2), (3), (4), … |
| 여섯째 항목 | (가), (나), (다), (라), … |
| 일곱째 항목 | ①, ②, ③, ④, … |
| 여덟째 항목 | ㉮, ㉯, ㉰, ㉱, … |

둘째·넷째·여섯째·여덟째 항목이 `하., 하), (하), 하` 이상 계속되면
`거., 너., 더., …` 순으로 단모음 순서를 이어 간다.

### 나. 표시 위치와 띄우기

1. 첫째 항목 기호는 **왼쪽 기본선**에서 시작한다.
2. 둘째 항목부터는 바로 위 항목 위치에서 **오른쪽으로 2타씩** 옮겨 시작한다.
3. 항목이 두 줄 이상이면 둘째 줄부터 **항목 내용의 첫 글자에 맞추어**
   정렬한다.
4. 항목 기호와 그 항목 내용 사이는 **1타** 띄운다.
5. **항목이 하나만 있으면 항목 기호를 붙이지 않는다.**

2타는 한글 1자, 영문·숫자 2자에 해당한다. 아래에서 `v`는 1타를 뜻한다.

```
수신vv○○○장관(○○○과장)
(경유)
제목vv○○○○○
1.v○○○○○○○○○○○
vv가.v○○○○○○○○○○○
vvvv1)v○○○○○○○○○○○
vvvvvv가)v○○○○○○○○○○○
vvvvvvvv(1)v○○○○○○○○○○○
2.v○○○○○○○○○○○○○○
```

### 다. 하나의 본문 아래 항목을 붙이는 경우

첫째 항목은 `1., 2., 3.`부터 시작하고 왼쪽 기본선에서 시작한다.

```
수신vv○○○장관(○○○과장)
제목vv○○○○○

문서관리교육을 다음과 같이 실시하오니 참석하여 주시기 바랍니다.

1.v일시:v○○○○○
2.v장소:v○○○○○○○○○○○
3.v참석 대상:v○○○○○○○○○○○.vv끝.
```

## 6. 본문 구성

문서는 **두문 / 본문 / 결문**으로 이루어진다(규칙 제4조).

### 가. 제목

문서 내용을 쉽게 알 수 있도록 간단하고 명확하게 적는다. 내부 문서는
제목에 문서 성격을 드러내는 말(위촉, 계획, 개최, 조사, 회의 결과 등)을
넣는다.

### 나. 붙임 표시 (규칙 제4조 제4항)

서식·유가증권·참고 서류, 그 밖의 문서나 물품이 첨부되면 **본문이 끝난 줄
다음**에 "붙임"을 적고 첨부물의 명칭과 수량을 쓴다. 첨부물이 둘 이상이면
항목을 나눈다.

```
(본문)………………………………… 주시기 바랍니다.

붙임vv○○○계획서 1부.vv끝.
```

```
(본문)………………………………… 주시기 바랍니다.

붙임vv1.v○○○계획서 1부
vvvvvv2.v○○○서류 1부.vv끝.
```

- 붙임은 본문과 구분되게 붙여 쓰거나 한 줄 띄어 쓸 수 있다.
- 계산서·통계표·도표 등 작성상의 책임을 밝힐 필요가 있는 첨부물에는 그
  여백에 작성자를 표시한다(규칙 제6조 제2항).

### 다. 문서의 "끝" 표시 (규칙 제4조 제5항)

1. 본문 마지막 글자에서 **한 글자(2타) 띄우고** `끝.`을 쓴다.
   `…… 주시기 바랍니다.vv끝.`
2. 첨부물이 있으면 붙임 표시문 다음에 한 글자(2타) 띄우고 쓴다.
3. 본문이나 붙임 표시문이 오른쪽 한계선에서 끝났으면 **다음 줄 왼쪽
   기본선**에서 한 글자(2타) 띄우고 쓴다.
4. 본문이 표로 끝나는 경우
   - 표의 마지막 칸까지 채웠으면: 표 아래 왼쪽 기본선에서 한 글자 띄우고
     `끝.`
   - 표 중간에서 기재 사항이 끝났으면: `끝.`을 쓰지 않고 마지막으로 작성된
     칸의 다음 칸에 **"이하 빈칸"**이라고 쓴다.

`끝` 뒤의 마침표를 빠뜨리지 않는다. (×) `끝` → (○) `끝.`

## 7. 여백과 쪽 번호

- 여백: 위 3cm, 왼쪽 2cm(기본선), 아래·오른쪽 1.5cm(한계선).
- 표의 위치는 정해진 사항이 없다. 왼쪽 기준선부터 전체를 쓰거나 표 제목
  아래부터 시작한다.
- 쪽 번호는 문서 중앙 하단에 표시한다. 중요한 문서는 전체 쪽수와 일련번호를
  붙임표로 이어 표시한다(규칙 제18조).

## 9. 띄어쓰기

- **조사는 앞말에 붙여 쓴다.** `10. 25.(금)까지`, `귀사에`
- **단위를 나타내는 명사는 앞말과 띄어 쓴다.** 23만 개, 3천 명, 50만 명,
  5천억 원, 4개 부처, 60여 개국, 50여 회, 각 1부, 26~29쪽
- **의존명사는 띄어 쓴다.** 계약할 때, 검토 중, 3일 내, 10월 초,
  20○○년 말, 1년 이상, 30% 미만
- **한 단어는 붙여 쓴다.** 귀사, 귀교, 귀댁 / 함께하다 / 잠금장치
- `-간`이 기간을 뜻하면 붙여 쓰고(2개월간, 50여 년간), 대상 사이를 뜻하면
  띄어 쓴다(기관 간, 부서 간).

## 10. 외국 문자와 약어

- 한글을 앞세우고 필요한 경우에만 괄호에 넣는다: `업무 협약(MOU)`,
  `정보 기술(IT)`, `주요 20개국(G20) 정상회의`
- 일반화되지 않은 약어는 쓰지 않는다(영 제7조 제2항). 기관 내부 코드나
  사업 약칭은 처음 나올 때 풀어 쓴다.
- 로마자 인명·지명은 국어의 로마자 표기법과 외래어 표기법에 따라 한글로
  적는다: `Obama` → `오바마`
- 문서 안의 참조 표기도 한글로 바꾼다: `p21` → `21쪽`,
  `para.1-2` → `1~2단락`, `Step1.` → `1단계`
