# 네일 시뮬레이터

네일샵에서 시술 전에 손톱 디자인을 미리 보여주는 웹 앱입니다.
음영을 입힌 손 위에 컬러·아트·마감·모양·길이를 조합해 얹어 보고, 마음에 드는 조합을
저장하거나 PNG로 내보낼 수 있습니다.

## 바로 써보기

호스팅된 버전: https://claude.ai/code/artifact/5cef133c-b669-4ba5-ba31-39606ce86e91

## 실행

빌드 과정도, 설치할 것도 없습니다. `index.html`을 브라우저로 열면 됩니다.

```
xdg-open index.html      # 또는 파일을 더블클릭
```

로컬 서버로 띄우고 싶다면:

```
python3 -m http.server 8000     # http://localhost:8000
```

## 사용법

- **추천 디자인** — 클래식 프렌치, 밀키 젤, 체리 레드 등 14가지 조합을 한 번에 적용
- **컬러** — 22색 팔레트 또는 컬러 피커로 메인·포인트 색 직접 지정
- **아트** — 단색 / 프렌치 / 옴브레 / 글리터 / 마그네틱 / 팁 글리터
- **마감** — 글로시 / 매트 / 펄 / 크롬
- **모양** — 라운드, 오벌, 스퀘어라운드, 스퀘어, 아몬드, 스틸레토, 코핀
- **길이** — 짧게 ~ 아주 길게 4단계 (연장 길이가 손끝 밖으로 늘어납니다)
- **포인트 네일** — 미리보기에서 손톱을 누르면 그 손톱만 따로 편집합니다.
  `전체 선택`을 누르면 다시 다섯 손톱에 함께 적용됩니다.
- **3D 보기** — 손을 입체로 그립니다. 드래그로 돌리고 휠로 확대하며, 손톱을 눌러
  개별 편집하는 것도 그대로 됩니다. 다시 누르면 2D로 돌아옵니다.
- **손 · 배경** — 피부톤 6종, 배경 3종
- **내 룩** — 조합을 이름과 함께 브라우저에 저장(localStorage) / 불러오기 / 삭제
- **PNG 저장** — 현재 화면을 2배 해상도 이미지로 내려받기
- **확대** — 손톱 위주로 크게 보기

## 구조

```
index.html
css/style.css
js/geometry.js   손·손가락·손톱 형태 계산 (SVG path 생성)
js/presets.js    피부톤·팔레트·마감·아트·추천 디자인 데이터 + 색상 유틸
js/render.js     상태 → SVG 문자열 (2D)
js/hand3d.js     3D 손 — 형태 생성 + WebGL2 렌더러
js/app.js        상태 관리, UI 연결, 저장, PNG 내보내기

build-single-file.py   위 파일들을 dist/nail-simulator.html 하나로 묶는다 (공유·호스팅용)
```

라이트/다크 테마는 CSS 커스텀 속성으로만 갈립니다. 색을 추가할 때는 `style.css`
맨 위 토큰 블록에만 넣고, 컴포넌트에서는 `var(--...)`로만 쓰면 두 테마가 같이 따라옵니다.

손은 이미지 파일이 아니라 매번 SVG로 계산해 그립니다. 손가락은 기준점·기울기·길이·
폭 프로파일로 정의하고, 손톱은 모양별 절반 윤곽선을 좌우 대칭시켜 만듭니다. 덕분에
길이·모양을 바꾸면 손톱 윤곽이 실제로 다시 계산되고, 같은 코드로 PNG 내보내기까지
재사용합니다.

렌더는 손등과 손가락을 **같은 평면 살색 한 덩어리**로 깔고 그 위에 음영만 얹는
순서로 그립니다. 손등을 별도 실루엣으로 손가락 위에 덮으면 경계선이 생겨
벙어리장갑처럼 보이기 때문입니다.

## 피부를 살처럼 보이게 하는 요소

벡터로 손을 그릴 때 "송장처럼 보이는" 원인은 대체로 다음 네 가지였고, 각각 이렇게 처리했습니다.

1. **중성 회색 음영** — 살의 그늘은 회색이 아니라 붉은 갈색입니다. 검정으로 어둡게
   하면 채도가 빠져 밀랍이 됩니다. 피부톤마다 `shade`(그늘색)를 두고 음영·그림자·
   주름을 전부 그 색으로, 하이라이트는 순백 대신 따뜻한 흰색으로 넣습니다.
2. **혈색 없음** — 관절과 손끝에 `blood`(혈색)를 깔아야 핏기가 생깁니다.
3. **고주파 정보 없음** — 매끄러운 그라디언트만으로는 플라스틱입니다. 저주파 색
   얼룩(부위마다 붉은 기가 다름)과 고주파 모공을 `feTurbulence`로 얹습니다.
   회색 노이즈가 아니라 **색이 있는** 얼룩이어야 피부로 읽힙니다.
4. **곧고 나란한 손가락** — 마네킹처럼 보입니다. 손가락마다 `bend`를 줘서 밑동은
   벌어지되 끝은 서로 모이게 합니다.

실제 손 사진과 비교하면서 추가로 잡은 것들입니다.

5. **관절 주름** — 사진에서 손을 손처럼 보이게 하는 가장 큰 단서입니다. 나란한 곡선
   몇 개로는 원통에 그은 선처럼 보이므로, 아주 옅은 가로 주름을 촘촘히 깔고 짧은
   세로 주름을 얽어 전체를 한 번 흐립니다. 진하게 그으면 해시태그를 새긴 것처럼 됩니다.
6. **물갈퀴 골** — 사진의 손가락은 훨씬 높은 곳에서 갈라집니다. 골을 깊고 좁게 팠습니다.
7. **손톱 폭** — 손끝보다 확실히 좁아서 양옆에 살이 보입니다.

## 비율은 눈이 아니라 자로 맞춥니다

"이상하다"는 느낌의 대부분은 형태가 아니라 **치수**에서 옵니다. 눈으로 고치면 한
군데를 맞추다 다른 데를 망가뜨리므로, 실제 성인 손 치수와 나란히 놓고 잽니다
(너클 폭 7.8 / 손목 폭 5.4 / 손바닥 길이 9.8 / 중지 8.0 / 엄지 6.5cm).

이 방법으로 잡은 것들입니다.

- **엄지가 18% 짧았습니다.** 그래서 손가락이 아니라 발가락처럼 뭉툭하게 읽혔습니다.
- **손끝 지름이 7% 가늘었습니다.** 손가락이 원뿔로 보이는 원인이고, 손톱 폭도
  여기서 나오므로 손톱까지 같이 작아집니다.
- 3D 쪽은 너클 폭이 22%나 좁았습니다. 그 하나 때문에 손 전체가 주걱처럼 보였습니다.

나머지 오차는 ±6% 안에 있습니다. 손등 형태(힘줄·너클·중수골 골)는 원래도 그려져
있었지만 알파가 0.05~0.16 에 블러가 커서 전부 뭉개져 사라졌습니다. 잔주름과 달리
넓고 부드러운 덩어리 음영은 진하게 넣어도 긁힌 자국처럼 보이지 않으므로, 형태가
읽힐 만큼 올렸습니다.

손톱은 주위에 살 능선(큐티클·측면 네일폴드)을 둘러야 얹힌 스티커가 아니라 살에
파묻힌 것으로 보입니다. 이 능선은 살이 있는 곳에만 있어야 하므로 손가락 실루엣으로
클립합니다 — 그러지 않으면 손끝 밖으로 나간 연장 부분에 후광이 생깁니다.

하이라이트 색은 반드시 피부톤에서 뽑습니다(`hiOf`). 모든 톤에 고정된 흰색을 쓰면
어두운 톤에서 재를 뿌린 듯 창백한 줄무늬가 생깁니다. 네일 광택은 폴리시 표면의
반사이므로 거기엔 흰색을 그대로 씁니다.

## 손톱 해부 구조

네일 앱이라 손톱은 따로 조사해 반영했습니다.

- **네일 플레이트는 반투명**합니다. 아래 혈관 색이 비쳐 분홍으로 보입니다.
- **프리엣지**(손끝 밖으로 자란 부분)는 베드에서 떨어져 나와 불투명한 흰빛입니다.
- **루눌라**(밑동의 반달)는 엄지가 가장 크고 소지는 거의 없습니다.
- 손톱 비율은 손가락마다 다릅니다(`NAIL_ASPECT`). 엄지는 폭에 비해 짧고, 소지는
  전체가 작습니다. 다섯 개를 같은 비율로 그리면 붙여놓은 것처럼 보입니다.

손톱마다 아주 살짝 다르게 기울어야(`NAIL_ROLL`) 다섯 개가 붙여놓은 것처럼 보이지
않습니다. 다만 이 회전의 중심은 **손톱 자신의 중심**이어야 합니다. 손가락 밑동 기준으로
돌리면 150~230px 떨어진 손톱이 옆으로 밀려, 3도만 줘도 손톱 반폭의 65%만큼 한쪽으로
몰립니다. 휨(`nailBend`)은 반대로 밑동 기준이어야 휜 손가락 끝을 따라갑니다.

디자인의 `sheer`(0~1)는 폴리시 불투명도입니다. 1보다 작으면 위 구조가 비쳐서
자연 네일처럼 보입니다. 생략하면 불투명이고, 이때 루눌라·프리엣지는 폴리시가
덮으므로 보이지 않아야 합니다 — 그리면 모든 손톱에 가로 이음선이 생깁니다.

## 조명

광원은 **월드 좌표계에 하나**입니다(`LIGHT`). 원통 음영을 손가락 로컬 좌표계에
그대로 걸면, 52도 돌아간 엄지가 다른 방향에서 조명받는 것처럼 보입니다. 손가락
축에 수직인 방향과 광원 방향의 내적으로 밝은 쪽을 계산합니다(`cylGradient`).

음영 프로파일에는 밝은 코어 · 터미네이터 · 코어 섀도우 · 환경 바운스 · 접지 엣지가
들어갑니다. 좌우 대칭 그라디언트만으로는 플라스틱 원통처럼 보입니다.

어두운 피부톤은 같은 알파로도 대비가 약해 형태가 묻히므로 밝기에 반비례해
하이라이트를 올립니다.

## 3D 보기

같은 상태를 입체로도 그립니다(`js/hand3d.js`). 라이브러리는 쓰지 않았습니다 — 이
프로젝트는 빌드 과정도 의존성도 없어야 하는데 three.js를 벤더링하면 그 성질이 깨지므로,
형태 생성·행렬·셰이딩을 전부 직접 씁니다(WebGL2).

**형태는 부호거리장(SDF)으로 정의하고 등위면을 뽑습니다.** 원기둥과 타원체를 그대로
겹쳐 놓으면 교차선이 자국으로 남아, 손등에 혹을 붙인 것처럼 보입니다. 손은 그런 경계가
없는 한 덩어리이므로 부위마다 거리장을 정의하고 부드럽게 합친 뒤(`smin`) 표면을
메시로 만듭니다. 이렇게 하면 손가락 밑동·물갈퀴·너클이 살처럼 이어집니다.

- 뭉개는 정도는 위치에 따라 다릅니다. 밑동에서는 크게(물갈퀴), 손가락 중간부터는
  작게 — 위쪽까지 크게 잡으면 다섯 손가락이 하나로 붙어버립니다.
- **중수골**을 넣어야 손등이 판자처럼 보이지 않습니다. 너클 봉우리와 손등 능선은
  따로 얹은 혹이 아니라 이 뼈대에서 나와야 합니다.
- 등위면은 마칭 큐브 대신 **surface nets**로 뽑습니다. 256행 테이블이 없어 코드가
  훨씬 짧고, 결과가 매끈해서 살에 어울립니다.
- 이 장은 정확한 거리함수가 아니어도 됩니다. 필요한 건 0 등위면의 위치뿐이고 법선은
  중심차분 기울기로 얻으므로, z를 늘려 납작한 단면을 만드는 편법을 그냥 써도 됩니다.

관절 주름은 2D에서와 같은 이유로 결정적입니다. 등위면에는 매개변수가 없으므로 정점마다
가장 가까운 손가락 스파인을 찾아 길이비를 되찾고, 그 값으로 셰이더에서 주름을 넣습니다.
손등 쪽은 잔주름 여러 줄, 손바닥 쪽은 굵은 접힘선 하나입니다.

손톱은 2D의 모양 정의(`SHAPES`)를 그대로 써서 윤곽을 만들고 손가락을 감싸는 곡면 위에
얹으므로, 모양·길이를 바꾸면 3D 형태도 실제로 다시 계산됩니다. 손톱을 손끝만큼 넓게
잡으면 옆면이 살 위로 떠서 스티커처럼 보입니다 — 손끝보다 확실히 좁아야 합니다.

손톱 클릭은 손톱만 id 색으로 다시 그려 픽셀을 읽습니다. 광선 검사와 달리 실루엣이
그대로 맞습니다.

첫 진입에서 등위면을 뽑느라 1초 남짓 걸립니다. 한 번만 치르는 비용이고, 이후에는
컨텍스트와 메시를 그대로 재사용합니다 — 모드를 오갈 때마다 WebGL 컨텍스트를 새로
만들면 브라우저 상한에 걸려 몇 번 만에 컨텍스트를 잃습니다.

## 한계

벡터로 그린 손도, 절차적으로 만든 3D 손도 사진은 아닙니다. 포즈는 고정된 한 가지이고,
카메라로 사용자 손을 인식해 얹는 AR 방식은 포함하지 않았습니다. 실제 고객 손에 얹어
보여주려면 사진을 올려 손톱 위치를 잡는 방식이 더 정확합니다.

2D 렌더 비용은 브라우저에서 프레임당 약 12ms(레이아웃 포함)입니다. 컨트롤을 바꿀 때마다
SVG 전체를 다시 만들지만 슬라이더 드래그에도 충분합니다.
