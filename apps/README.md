# apps

작은 인터랙티브 앱 세 개. 빌드 도구도, 의존성도, 서버도 필요 없습니다.
각각 단일 HTML 파일이라 브라우저로 바로 열면 동작합니다.

```
open apps/index.html          # macOS
xdg-open apps/index.html      # Linux
```

또는 `python3 -m http.server` 로 띄운 뒤 `/apps/` 로 접속.

## focus — 뽀모도로 + 할 일

- 집중 25분 / 짧은 휴식 5분 / 긴 휴식 15분 모드
- 시작·일시정지·리셋, 탭 제목에 남은 시간 표시
- 할 일 추가·완료·삭제, 클릭으로 활성 작업 선택
- 집중 세션을 끝까지 마치면 활성 작업에 🍅가 하나 추가
- 종료 시 짧은 알림음(WebAudio), 목록은 `localStorage`에 저장

타이머는 만료 시각(timestamp) 기준으로 계산해서, 탭이 백그라운드로 밀려
`setInterval`이 밀리더라도 남은 시간이 어긋나지 않습니다.

## kaleido — 만화경 드로잉

- 캔버스를 드래그하면 대칭 수(2~16)만큼 무늬가 복제
- 거울 모드 on/off, 선 굵기, 색 변화 속도 조절
- `lighter` 합성 모드라 겹칠수록 밝아짐
- 지우기 / PNG 저장(검은 배경을 깔아 내보냄)
- Pointer Events 사용 — 마우스와 터치 모두 동작

## snake — 스네이크

- 21×21 격자, 방향키 또는 WASD
- 스페이스로 일시정지, 모바일은 스와이프(짧은 탭은 일시정지)
- 먹을 때마다 한 칸씩 빨라짐 (140ms → 최소 60ms)
- 최고 점수는 `localStorage`에 저장
- 보드를 가득 채우면 승리 화면
