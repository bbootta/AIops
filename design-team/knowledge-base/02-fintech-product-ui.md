# 02. 금융 프로덕트 UI 패턴 (Fintech Product UI)

화면 디자인(앱·웹) 담당 에이전트의 핵심 지식. AI 기반 금융 제품의 특수 패턴 포함.

## 신뢰를 만드는 UI 원칙

금융 UI의 제1과제는 "예쁨"이 아니라 **불안 제거**다.

1. **현재 상태를 항상 보여줄 것** — 잔액, 처리 상태, 마지막 업데이트 시각
2. **되돌릴 수 있음을 보여줄 것** — 이체 전 확인 단계, 취소 가능 시간 안내
3. **숨기지 말 것** — 수수료, 환율, 우대 조건은 클릭 전에 노출. 다크패턴은 금소법 위반 리스크
4. **시스템이 살아있음을 보여줄 것** — 로딩은 스켈레톤으로, 실패는 원인+다음 행동으로

## 핵심 화면 패턴

### 홈/대시보드
- 최상단: 총자산 or 핵심 KPI 1개 (큰 숫자, tabular)
- 자산 숨김 토글(눈 아이콘) 제공 — 공공장소 사용 배려
- 카드 단위 모듈: 계좌 / 투자 / 소비 / AI 인사이트 순으로 개인화 가능하게
- Pull-to-refresh + 마지막 갱신 시각 표기

### 금액 입력
- 키패드는 자체 구현(시스템 키보드 X), 천 단위 콤마 실시간 표기
- 금액 프리셋 버튼(+1만, +10만, 전액) 제공
- 한글 금액 병기: "1,500,000원 (백오십만원)" — 이체 실수 방지의 표준 패턴
- 잔액 초과 시 즉시 인라인 오류 (제출 후 오류 금지)

### 이체/거래 플로우
- 3단계 표준: 입력 → 확인(수취인명 크게, 금액 한글 병기) → 완료
- 확인 화면이 가장 중요 — 여기서 정보 밀도를 최대로
- 완료 화면: 체크 애니메이션 + 영수증 공유 + "다음 행동" 제안

### 인증
- 생체인증 우선, PIN 폴백, 공동인증서는 최후순위로 숨김
- 인증 요청 시 "왜 지금 인증이 필요한지" 한 줄 설명

### 온보딩/KYC
- 진행률 표시 필수 (단계가 5개 이상이면 이탈 급증 — 저장 후 이어하기 제공)
- 신분증 촬영: 가이드 프레임 + 자동 촬영 + 빛반사 안내
- 약관: 전체동의 + 필수/선택 구분 명확히. 선택 약관을 필수처럼 보이게 하면 금소법 위반

## AI 기능의 UI 패턴 (금융 AI 특화)

### AI 인사이트/추천
- **근거를 함께 제시**: "지난달보다 외식비 32% 증가" ← 데이터 출처와 기간 명시
- **단정 금지 표현**: "~할 것으로 예상돼요" / 수익률 예측에는 반드시 범위 또는 불확실성 표기
- AI 생성 콘텐츠임을 시각적으로 구분 (아이콘, 배경색, "AI 분석" 레이블)
- 투자 추천은 규제 영역 — "투자 판단의 참고자료이며, 투자 결과의 책임은 투자자 본인에게 있습니다" 고지 상시 노출 (07 문서 참조)

### 대화형 AI (챗봇/어시스턴트)
- 스트리밍 응답 + 중단 버튼
- 금융 데이터 조회 결과는 말풍선 안 텍스트가 아니라 **구조화된 카드**로 (계좌 카드, 차트 카드)
- 실행형 액션(이체 등)은 챗 안에서 완결하지 말고 확인 플로우로 핸드오프
- 오류/환각 대비: "이 정보가 정확한가요?" 피드백 버튼, 상담원 연결 탈출구 상시 제공

### 신뢰 등급 표시
- AI 확신도가 낮은 답변은 시각적으로 구분하거나 출처 링크 제공
- 규제 관련 질문(세금, 상품 약관)은 원문 문서로 딥링크

## 컴포넌트 규칙

- 버튼: 높이 48~56px(모바일 primary), 라운드는 브랜드 톤에 따라 8~16px 일관 적용
- 카드: 그림자보다 보더+배경 대비 우선 (다크모드 호환)
- 차트가 들어가는 컴포넌트는 03 문서의 규칙을 따른다
- 빈 상태(empty state): 일러스트 + 한 줄 설명 + CTA — "데이터 없음"만 띄우는 것 금지
- 에러 상태: 원인 + 사용자가 할 수 있는 행동 + 문의 경로

## 안티패턴 (금지)

- 손실/수수료를 회색 작은 글씨로 숨기기
- 해지/탈퇴 경로 숨기기 (다크패턴, 규제 리스크)
- 확인 없이 실행되는 금전 액션
- 마케팅 푸시와 거래 알림을 같은 채널/토글로 묶기
- 소수점·콤마 없는 금액 표기, 원화에 소수점 표기
