# 03. 금융 데이터 시각화 (Financial Data Visualization)

차트·그래프·대시보드를 만들 때의 규칙. UI, 홍보물, PPT 전 매체 공통.

## 차트 선택 기준

| 전달할 것 | 차트 | 비고 |
|---|---|---|
| 시간에 따른 추이 (주가, 잔액) | 라인 차트 | 금융 기본값. 영역(area)은 단일 시리즈만 |
| 기간별 비교 (월 지출) | 세로 막대 | 막대 간격은 막대 폭의 30~50% |
| 항목별 비교 (카테고리 지출) | 가로 막대 | 항목명이 길면 가로가 정답 |
| 구성비 (포트폴리오) | 도넛 | 5조각 이하, 초과분은 "기타"로 합산. 파이 3D 금지 |
| 가격 변동 상세 (트레이딩) | 캔들스틱 | 상승 빨강/하락 파랑 (한국 관례) |
| 목표 대비 달성 | 프로그레스 바/링 | 게이지 차트 남용 금지 |
| 상관/분포 | 산점도, 히트맵 | B2B·리서치 자료용 |

## 정직한 시각화 (금융에서 특히 중요)

- **Y축 조작 주의**: 수익률 차트에서 축을 잘라 변동을 과장하는 것은 홍보물에선 규제 리스크, 제품에선 신뢰 파괴. 축 절단 시 반드시 절단 표시(⌇)와 축 라벨
- 기간 선택 편향 금지: "최근 3개월 +40%"만 보여주고 1년 −20%를 숨기는 구성은 금융광고 규제 위반 소지
- 누적 수익률 vs 연환산 수익률을 명확히 라벨링
- 과거 수익률 차트에는 "과거 수익률이 미래 수익을 보장하지 않습니다" 고지 (07 문서)

## 스타일 규칙

- 시리즈 색상: 최대 6개, 그 이상은 상위 5 + 기타로 묶기
- 그리드라인: 가로선만, 최소한으로, 낮은 대비 (데이터보다 튀면 안 됨)
- 데이터 포인트 직접 라벨링 > 범례 (범례는 시선 왕복을 만든다)
- 금액 축약 표기: 1.2억, 3,400만 — 축 라벨은 축약, 툴팁/상세는 전체 자릿수
- 툴팁: 날짜 + 정확한 값 + 전기 대비 변화량
- 모바일 차트: 터치 타깃 고려, 스크럽(드래그로 시점 탐색) 인터랙션 기본

## 색 사용

- 손익 컬러(빨강/파랑)는 손익에만 사용 — 일반 카테고리 구분에 빨강 사용 금지
- 단일 지표 추이는 브랜드 컬러 1색 + 그라데이션 영역
- 색각이상 대응: 색상 + 패턴/라벨 병행, 8% 남성이 적록색약임을 전제로 검증
- 다크모드: 채도 낮춘 파스텔 톤 시리즈 컬러 (순색은 다크 배경에서 진동함)

## 대시보드 구성

- KPI 타일(큰 숫자) → 추이 차트 → 상세 테이블 순의 정보 깔때기
- 타일 하나당 지표 1개 + 전기 대비 변화(방향 부호 병기)
- 화면당 차트 4~6개 초과 시 탭/드릴다운으로 분리
- 모든 수치에 기준 시점 표기 ("2026.08.07 15:30 기준")
