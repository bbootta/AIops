# 05. 마케팅·홍보물 디자인 (Marketing & Promotional Design)

홍보물 담당 에이전트의 핵심 지식. 디지털 광고, SNS, 랜딩페이지, 인쇄물.

## 매체별 규격 (2026 기준 표준)

### 디지털 광고
| 매체 | 규격(px) | 비고 |
|---|---|---|
| 인스타그램 피드 | 1080×1350 (4:5) | 정방형 1080×1080도 병행 |
| 인스타그램 스토리/릴스 | 1080×1920 (9:16) | 상하 250px은 UI에 가려짐 — 세이프존 준수 |
| 유튜브 썸네일 | 1280×720 | 텍스트 3~5어절, 모바일에서 판독 테스트 |
| 카카오 비즈보드 | 1029×258 | 텍스트 중심, 여백 승부 |
| 네이버 배너(타임보드) | 매체 규격 준수 | 애니메이션 규정 확인 |
| 디스플레이 배너 세트 | 300×250, 728×90, 320×100 외 | 핵심 메시지+CTA만 |

### 인쇄물
- 리플렛: A4 3단 접지 (펼침 297×210mm), 재단 여백 3mm, 접는 선 안쪽 5mm 세이프존
- 포스터: A2/A3, 3m 거리 판독 기준으로 헤드라인 크기 결정
- 명함: 90×50mm (한국 표준), 인쇄는 CMYK + 300dpi 필수
- 배너(X배너): 600×1800mm, 시선 높이(상단 1/3)에 핵심 메시지

## 금융 광고 크리에이티브 원칙

1. **숫자가 헤드라인이다** — "연 4.5%", "수수료 0원"이 어떤 카피보다 강하다. 단, 조건 병기 필수 (07 문서)
2. **혜택 1개 원칙**: 배너 하나에 소구점 1개. 두 개면 광고를 나눠라
3. **CTA는 행동 동사로**: "자세히 보기"(약함) → "금리 확인하기", "3분 만에 개설하기"
4. **신뢰 장치 배치**: 인증마크, 예금자보호 문구, 다운로드 수, 제휴 로고 — 단 과장 금지
5. **AI 소구 시**: "AI 추천"만으로는 약함 — "무엇을 어떻게 해주는지"를 구체적으로 ("AI가 매일 내 포트폴리오 리밸런싱 시점을 알려줘요")

## 필수 고지 사항 (금융 광고 — 07 문서와 연동)

- 대출: 이자율 범위, 상환 조건, "과도한 빚, 고통의 시작입니다" 등 경고 문구
- 투자: "원금 손실 가능", "과거 수익률은 미래를 보장하지 않음"
- 예적금: 우대금리 조건, 예금자보호 한도
- 고지 문구도 **판독 가능해야 함** — 배경과 대비 확보, 최소 크기 준수. 심의 반려 1순위가 고지 문구 가독성
- 금융 광고는 집행 전 내부 심의 + 협회 심의 대상임을 항상 산출물에 명시 (심의 여백/문구 자리 확보)

## 랜딩페이지 구조 (표준 스켈레톤)

1. **히어로**: 헤드라인(혜택) + 서브(방법) + CTA + 제품 스크린샷/그래픽
2. **사회적 증거**: 사용자 수, 리뷰, 언론 보도, 제휴사
3. **핵심 기능 3개**: 아이콘/스크린샷 + 한 줄 설명 (기능 나열이 아니라 혜택 번역)
4. **작동 방식**: 3단계 스텝 (가입 장벽 낮추기)
5. **신뢰/보안 섹션**: 금융 제품은 필수 — 보안 인증, 규제 준수, 데이터 처리 방식
6. **FAQ**: 수수료·해지·안전성 등 구매 장벽 질문
7. **최종 CTA + 필수 고지 footer**

- 스크롤 30% 지점 안에 첫 CTA, 이후 섹션 2개마다 반복
- 모바일 우선: 트래픽의 80%+ 가 모바일

## SNS 콘텐츠 유형 (금융 AI 제품)

- **데이터 스토리텔링**: "2030이 가장 많이 쓴 지출 카테고리" — 자사 데이터 기반 인포그래픽 (개인정보 비식별화 전제)
- **금융 상식 카드뉴스**: 6~8장, 1장=1메시지, 마지막 장 CTA
- **기능 데모 릴스**: 15초 안에 문제→해결, 자막 필수(무음 시청 85%)
- 카드뉴스 표지: 피드에서 멈추게 하는 것은 질문형 헤드라인 + 숫자
