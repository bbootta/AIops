# 07. 규제 준수와 접근성 (Compliance & Accessibility)

모든 에이전트가 산출물 최종 검수 시 참조하는 문서. 디자인 리뷰어의 1차 체크리스트.

> 이 문서는 디자인 관점의 요약이다. 실제 광고 집행·상품 출시 전에는 반드시 준법감시인/법무 검토를 거친다. 산출물에는 "심의 전 시안" 워터마크 또는 표기를 권장한다.

## 금융 광고·표시 규제 (한국, 디자인에 영향을 주는 것만)

### 금융소비자보호법 광고 규제 핵심
- 금융상품 광고에는 **필수 포함 사항**(상품 내용, 위험, 조건)과 **금지 행위**(단정적 판단, 사실과 다른 표현)가 있다
- 디자인 함의: 필수 고지 문구의 **자리와 가독성**을 시안 단계부터 확보할 것 — 나중에 욱여넣으면 레이아웃이 무너진다

### 표현 금지 목록 (카피·헤드라인 검수용)
- "확실한 수익", "원금 보장"(보장 상품이 아닌 경우), "최고", "제일", "무조건"
- 손실 가능성을 숨기거나 축소하는 표현
- 우대 조건 없이 최고 금리만 크게 쓰는 표기 (조건 병기 필수, 유사한 크기·대비로)

### 상품 유형별 필수 고지 (디자인 시 자리 확보)
| 상품 | 고지 |
|---|---|
| 투자상품 | "금융상품 판매업자는 예금자보호법에 따라 보호하지 않습니다" 등 + 원금 손실 가능 + 과거 수익률 미보장 |
| 대출 | 이자율·연체이자율 범위, 중도상환수수료, "과도한 빚, 고통의 시작입니다" 계열 경고 |
| 예적금 | 예금자보호 한도(1억 원), 우대금리 조건 |
| 로보어드바이저/AI 투자 | "투자 판단의 참고자료", 알고리즘 한계 고지, 투자자 책임 문구 |

### AI 관련 표시
- AI가 생성·추천한 콘텐츠임을 사용자가 인지할 수 있게 표시 (레이블, 아이콘)
- AI 성과 광고 시 검증 가능한 수치만, 기간·조건 명기

## 접근성 (WCAG 2.2 AA 기준 + 한국형 웹 접근성)

### 색과 대비
- 텍스트 대비 4.5:1 이상 (18pt+ bold는 3:1), UI 컴포넌트·차트 요소 3:1 이상
- 색상 단독으로 정보 전달 금지 — 손익은 색+부호+화살표, 차트는 색+라벨/패턴
- 검증 도구 없이 감으로 판단하지 말 것 (대비 계산해서 수치로 확인)

### 텍스트와 구조
- 본문 확대 200%에서 깨지지 않는 레이아웃
- 실제 텍스트 사용 (이미지 텍스트 지양 — 배너 예외, 단 대체텍스트 필수)
- 명확한 포커스 표시, 논리적 탭 순서

### 인터랙션
- 터치 타깃 최소 44×44px (금융 앱 주 사용층에 고령층 포함 — 48px 권장)
- 시간 제한 있는 인증(OTP 등)은 연장 수단 제공
- 애니메이션: 깜빡임 3회/초 이상 금지, reduced-motion 대응

### 고령층 배려 (금융 앱 특수사항)
- 큰글씨 모드 제공 검토
- 전문용어에 쉬운 설명 병기
- 중요 액션의 확인 단계 생략 금지

## 개인정보·보안의 시각 표현

- 화면 캡처 홍보물의 계좌번호·이름·잔액은 반드시 더미 데이터 (실데이터 마스킹 아니라 처음부터 가짜 데이터)
- 마케팅용 데이터 인포그래픽은 비식별·통계 처리 명시
- 보안 신뢰 요소(자물쇠, 인증마크)를 근거 없이 사용하지 말 것 — 실제 취득한 인증만

## 디자인 리뷰 체크리스트 (전 매체 공통)

- [ ] 필수 고지 문구 포함 + 판독 가능한 크기/대비인가
- [ ] 금지 표현(단정·과장) 없는가
- [ ] 손익 표현에 색상 외 보조 수단이 있는가
- [ ] 텍스트 대비 4.5:1 이상인가
- [ ] 더미 데이터를 사용했는가 (실계좌 정보 노출 없음)
- [ ] 수치에 기준 시점·출처·조건이 병기됐는가
- [ ] AI 생성/추천 요소에 표시가 있는가
- [ ] "심의 전 시안" 상태 표기가 있는가 (대외 광고물)
