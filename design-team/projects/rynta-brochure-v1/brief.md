# 크리에이티브 브리프: RYNTA 3단 접지 브로셔 10종 시안

작성: design-director | 2026-08-08 | 상태: 제작 지시

## 배경과 목표

RYNTA RiskOps(원라인에이아이의 금융 리스크모형 검증 AI 에이전트 플랫폼)의 대면 영업·행사용 인쇄 브로셔. 금융회사-핀테크 Meet-Up, 위탁테스트 제안 미팅에서 실무진에게 전달한다. 10가지 디자인 방향 시안을 만들어 내부 선정 후 1종을 인쇄 발전시킨다.

**성공 기준**: ① 10종 모두 동일 콘텐츠 골격·동일 규격으로 디자인만 상이 (공정 비교 가능) ② 브라우저에서 바로 열려 확인 가능 + 인쇄 CSS 포함 ③ 검수 통과(규제 표기·대비·브랜드 일관성)

## 타깃

금융회사 리스크·감리·검증 부서 실무진과 부서장 (B2B, 금융 전문가, 보수적, "재현 가능성·감사추적"에 반응). AI 과장 표현에 냉소적 — 근거와 구조로 설득.

## 핵심 메시지

**"숫자는 엔진이, 문장은 에이전트가, 판단은 사람이."**
보조: ① 검증 2~4주 → 목표 5~10영업일 ② 데이터는 나가지 않는다(온프레미스) — 근거는 `research/brand-research.md`의 카피 소스만 사용.

## 규격 (전 시안 공통 — 필수)

- **A4 3단 접지(트라이폴드), 양면**: 펼침 297×210mm 가로 2면(바깥면/안쪽면), 면당 3패널(각 99mm)
- 바깥면(왼→오): **[날개 패널] [뒷면 패널] [표지 패널]** — 접으면 표지가 앞, 날개가 안으로 접힘
- 안쪽면(왼→오): **[내부1] [내부2] [내부3]** — 펼쳤을 때 하나의 흐름
- HTML 1파일 = `.sheet` 2개(각 297×210mm), CSS Grid 3열, 접는 선은 화면에서만 점선 표시(`.fold-guide`, 인쇄 시 숨김)
- `@page{size:A4 landscape;margin:0}` + `print-color-adjust:exact`, 재단 여백 주석으로 명기(3mm bleed, 날개 패널은 실제 인쇄 시 폭 2~3mm 축소 필요)
- 서체: `Pretendard,"Noto Sans KR","Malgun Gothic",sans-serif` (외부 로드 금지, 시안별 세리프 병용 시 `"Noto Serif KR",serif` 폴백)
- 외부 의존성 0 — 이미지·아이콘 전부 인라인 SVG

## 콘텐츠 골격 (전 시안 공통 — 문안은 research/brand-research.md 기반, 표현 다듬기 허용·사실 변경 금지)

| 패널 | 내용 |
|---|---|
| 표지 | RYNTA 브랜드마크+제품명, 한 줄 정의(핵심 메시지), Vol.1, 원라인에이아이 엠블럼(소형) |
| 날개 | 위탁테스트 제안: 병행 운영 3~6개월, 성공 기준 4지표 표("목표" 명기, 측정 주체=귀사) |
| 뒷면 | 회사 소개 1문단+태그라인, 연락처(마포대로 122 프론트원 14F, www.onelineai.com, info@onelineai.com), 원라인 엠블럼, 하단 고지 문구 |
| 내부1 | 왜 지금인가 — 반복 재계산·수기 문서·개인 의존의 문제 |
| 내부2 | 우리의 답 — 4계층 구조(엔진/에이전트 AVI·ARI/사람 4-Eyes/Evidence Ledger), 계층 컬러 활용 |
| 내부3 | As-is→To-be 비교 + 소요기간(2~4주→목표 5~10영업일), 보안(온프레미스·데이터 비반출) |

**필수 고지(뒷면 하단, 판독 가능한 크기·대비)**: "본 자료의 성과 지표는 위탁테스트 목표 기준이며 실제 결과는 기관별 환경에 따라 다를 수 있습니다. AI 산출물은 승인 권한자의 검토·승인 전 확정되지 않습니다. — 심의 전 시안" + 시안 번호/일자.

**금지**: "보장", "무조건", "오차 제로 보장" 등 단정 표현. 목표 수치를 실적처럼 쓰기. 실명·직통번호.
