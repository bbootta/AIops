## 디자인 결정 사항 (리뷰어 참고)

1. **시안 08의 내부2 계층 표현**: brief 콘텐츠 골격은 "계층 컬러 활용"이나, 08 디자인 방향("포인트 엔진블루 1색")이 우선한다고 판단 — 계층 구분을 번호(1~4)·괘선·타이포 위계로 대체하고 블루는 공통 마커로만 사용. 시안 01은 4계층 컬러 바(#42a9ff/#a78bfa/#f6bb56/#2dd4bf)를 그대로 활용.
2. **시안 01의 red #ff3b30**: 대비 3.2:1로 본문 사용 불가 → 대형 굵은 강조(밑줄·목표 태그·소요기간 숫자)에만 한정. CMYK 전환 시 채도 확인 필요.
3. **시안 08의 엔진블루**: 백색 대비 2.5:1 → 텍스트·의미 전달 요소로 쓰지 않고 장식 면/바 전용. [목표] 태그는 블루 배경 + ink 텍스트(≈7.5:1).
4. 날개 패널 폭은 비교용으로 99mm 균등 — 인쇄 데이터 확정 시 96~97mm 축소 필요(주석 명기).
