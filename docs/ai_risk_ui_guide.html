1. 공통 원칙

P1 원장 집계만 표시. 모든 숫자는 적재된 원장(D.data[...])의 행을 세거나 더한 값이다. 화면이 추정·보간·예측값을 만들지 않는다.
P2 완전 적재 원장만 집계. 표본만 실린 원장(shown < total)은 건수 계산에서 빼고, 그 자리에는 원장 이름과 표본 안내를 둔다. 헬퍼 aiFull(key)가 이 규칙을 강제한다.
P3 결정론. 무작위처럼 보이는 배치(관계 그래프 첫 위치, 격자 회전 위상)는 실행 식별자 run_id를 FNV 해시한 씨앗과 mulberry32 난수로 만든다. 같은 실행이면 같은 첫 그림이다. 렌더된 HTML 은 두 번 만들어도 바이트가 같다.
P4 보이지 않으면 멈춘다. 모든 애니메이션 루프는 자기 화면 section.on 이고 문서가 숨겨지지 않았을 때만 그린다. 다른 화면으로 가면 CPU 를 쓰지 않는다.
P5 외부 자원 없음. 폰트·라이브러리·이미지를 내려받지 않는다. 캔버스 2D 와 SVG 만 쓴다.
P6 색 외 단서. 톤(good·warn·bad)만으로 뜻을 전하지 않는다. 라벨 텍스트, 건수, 게이트 문자열을 함께 둔다.
P7 긴 대시 금지. 코드·주석·문구·문서에 em dash 와 en dash 를 쓰지 않는다. 범위는 ~, 연결은 · 또는 하이픈.

4. 관계 그래프 시뮬레이션 (드래그·장력)

데스크 10번 패널과 종합보고서 그림 9b 가 같은 함수 dkGraph(card, M) 를 쓴다. 노드는 도메인(반지름 9), 도구(6), 에이전트(3, 위험등급 상이면 5)이고, 간선은 에이전트 → 소속 도메인(가중 0.9)과 에이전트 → 보유 도구(0.35)다.

G1 상시 시뮬레이션. 화면이 보이는 동안 매 프레임 한 스텝을 돈다. 에너지가 낮아도 멈추지 않으므로 드래그하면 곧바로 이웃이 반응한다. 통계의 수렴은 100 - 평균 운동에너지 × 40 을 0~100% 로 자른 값이다.
G2 드래그. 노드 위(14px 이내)에서 pointerdown 하면 그 노드가 잡힌다. 잡힌 노드는 포인터의 화면 좌표를 역변환한 시뮬레이션 좌표에 고정되고 속도는 0 이다. 이웃은 간선 장력에 끌려 따라오고, 나머지는 반발로 밀려난다. setPointerCapture 로 캔버스 밖으로 나가도 잡힘이 유지되며 pointerup·pointercancel 에서 놓인다. 터치에서도 같다(touch-action:none).
G3 커서. 노드 위에서는 grab, 끌 때는 grabbing, 빈 곳은 기본 커서.
G4 화면 맞춤. 매 프레임 노드 경계상자를 캔버스에 맞추는 배율·이동을 계산한다. 배율 상한 3. 끌고 있는 동안은 뷰를 고정해 그림이 튀지 않게 하고, 놓으면 새 목표로 부드럽게 보간한다(에너지가 높으면 25%, 낮으면 6%씩).
G5 강조. 마우스를 올린 노드 또는 끌고 있는 노드는 반지름 +3, 테두리, 굵은 라벨, 이웃 간선을 강조색으로 그린다. 통계의 선택 칸에 라벨과 차수를 적는다. 에이전트 노드 라벨은 강조될 때만 보인다.
G6 통계·범례. 노드 수, 간선 수, 수렴, 에이전트 수, 도구 수, 제안 전용 비율, 선택. 범례는 도메인 색과 도구 회색, 오른쪽 끝에 조작 힌트 "노드를 끌면 이웃이 장력으로 따라온다".

계산 비용은 노드 수의 제곱이다. 현재 규모(노드 80, 간선 302)에서 한 스텝은 1ms 미만이다. 노드가 수백을 넘으면 격자 근사(Barnes-Hut)를 검토한다.

5. 콕핏 LIVE 활동 로그

콕핏 통제 구역 아래에 카드 한 장이 붙는다. 머리에 "AI 에이전트 활동 로그 · n건" 과 LIVE 배지, 본문은 데스크와 같은 dkLiveLog 를 8행·짧은 높이(152px)로 띄운 것이다. 꼬리에 AI 관제 데스크로 가는 화면 링크가 있다. 추적 이벤트가 0건이면 카드를 만들지 않는다.

6. 종합보고서 9장 AI리스크

  • 개조식 항목: 등록 에이전트 수와 운영 반영 권한, 활동 기록과 게이트 대기, 비상정지 이력과 2차 확인 없음, 4-Eyes 승인과 직무분리 충족, 마스킹 적중과 규칙 수, 요건 76건 커버리지(반영·부분·미반영 건수). 톤은 운영 반영 권한이 있으면 bad, 2차 확인 없는 비상정지가 있으면 warn.
  • 그림 9a 도메인별 에이전트 수 (가로 막대, 상위 10). 원장 agent_registry 가 완전 적재일 때만.
  • 그림 9b 관계 그래프 시뮬레이션. 4장의 함수 그대로이며 보고서 안에서도 끌 수 있다. 전폭 그림.
  • 삭제: 장별 요건 추적 격자(구 그림 9a, 요건 76건 · 장별 커버리지 띠)는 이번 판에서 뺐다. 커버리지 수치는 개조식 한 줄로만 남긴다. 상세 추적은 AI 리스크 개요 화면과 요건 추적 화면이 맡는다.

8. 크기·반응형 규격

9. 언어·표기 규칙

  • 화면 기능 문구의 기본 언어는 English 다. 헤더의 언어 버튼으로 한국어로 바꿀 수 있다.
  • 새 문구는 risk_lib/ui_studio/i18n.py 에 '한국어||English' 로 등록한다. 이번 판에 추가된 키: 노드를 끌면 이웃이 장력으로 따라온다, AI 에이전트 활동 로그, 선택, 결정론 씨앗 등 데스크 문구 일체.
  • 원장 데이터는 KR 기관은 한국어, 그 외 기관은 영어로 적재된다. KR 기관 화면에서는 UI 문구만 번역하고 데이터 값은 그대로 둔다.
  • 숫자 서식은 언어와 무관하다. 통계 값은 tabular-nums 로 오른쪽 정렬.
