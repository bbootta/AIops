### 5.2 F-702 (경부적합) — 항등식을 항등식으로 교체했습니다

BR-11의 새 검증 2건은 양변이 모두 같은 `reserve_requirement()` 반환 dict에서
나옵니다.

```
① expected = max(0, L1000 − L2000),  actual = L3000
   L1000=min_provision, L2000=ifrs9_provision, L3000=max(0, min_provision − ifrs9_provision)
   → 정의상 동일

② _sum_check(L4000 = L3000 + L5000)
   L5000 = offset_effect ≡ L4000 − L3000
   → 항등
```

무작위 자료 **20,000회로 `_br11`을 재구성해 실행한 결과 검증 실패 0건**입니다.
`br_npl`에 신설한 3건도 같은 구조입니다(라인 3000이 `watch + npl`로 만들어지고
2900=watch, 2000=npl; 비율 라인도 분자·분모 라인에서 그대로 계산).

**다만 이전보다 개선입니다.** 옛 검증은 자기 대상 결함(F-601)조차 잡지 못했지만
새 검증 ①은 라인 3000을 건별 합산으로 되돌리는 회귀를 잡습니다 — 그 회귀 시험을
테스트에도 넣었습니다.

지적하는 것은 코드 주석의 **"실제로 틀릴 수 있는 대사로 바꾼다"는 주장**입니다.
자료로는 틀릴 수 없고 배선 회귀만 잡습니다. 둘은 다르며, 그렇게 적어야 합니다.

### 5.3 F-703 (경부적합) — 지표가 자기 사례를 보지 못합니다

`check_strength()`의 판별 기준은 "양변이 모두 0"입니다. 그런데 F-602 시정으로
신설한 5건은 **전부 양변이 0이 아닌 항등식**이라 "실질 대사 1,547건(89.2%)"에
포함됩니다. 이 지표가 잡을 수 있는 것은 F-602의 *이전* 형태뿐이고 *시정 후*
형태는 못 잡습니다.

판별 기준을 **값**(0인가)이 아니라 **구조**(양변이 같은 표현식에서 유도되는가 ·
부등호 방향이 정의역에서 고정되는가)로 옮겨야 합니다.

**도전 지점 1에 부분 답합니다.** 188건을 이름별로 집계(고유 167종)하고 구성 코드를
읽었습니다.

**구조적 항진명제 — 최소 8건**

| 검증 | 건 | 왜 항상 참인가 |
|---|---:|---|
| HHI는 0~1 범위 | 3 | HHI = Σ점유율², 점유율 합 = 1 ⇒ ≤ 1 |
| 심각 시나리오 저점 ≤ 기말 | 1 | trough = 경로 최솟값 ⇒ end ≥ trough |
| CCR RWA ≥ 0 | 1 | RWA = EAD × 0.5, EAD ≥ 0 |
| 표준방법 신용 RWA ≥ 0 | 1 | 동일 |
| 최고 ≥ 일평균 · 최저 ≤ 일평균 | 2 | 같은 계열의 max·min vs mean |

**정당한 0 단언 — 최소 18건**: 미영위 8건, 유동화 미보유 2건, SA-CVA 미적용 1건,
대주주 사용액 0 3건, 담보인정액 ≤ 담보평가액 4건(rec·app이 서로 다른 컬럼 합이므로
자료가 바뀌면 위반 가능).

나머지 167종 전수 판별은 하지 않았습니다 — **미확인**입니다. 완전 판별에는
`FormCheck` 인자 표현식의 AST 대조가 필요하며, 이는 기호적 작업이라 3선이 다음
회차에 도구로 만드는 것이 맞습니다.
