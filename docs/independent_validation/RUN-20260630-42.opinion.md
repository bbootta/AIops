## 5. 주요 결과

### 5.1 강화 모니터링 — 전 필드 반증 (결재 조건 이행)

`request_identifier(request)`는 `asdict(request)`에서 `request_id`·`created_at`
둘만 제외하고 canonical JSON으로 해시합니다.

| 필드 | ID 변동 |
|---|---|
`run_id` · `asof` · `seed` · `headline_digest` · `portfolio_fingerprint` | 변동 ✓ |
`requested_by` · `requested_to` · `branch` · `reproduce` | 변동 ✓ |
**`recalc_targets`** (F-301 대상) | **변동 ✓** |
`self_validation` · `self_validation_failures` · `self_validation_warnings` | 변동 ✓ |
`artefacts` · `known_assumptions` | 변동 ✓ |
`request_id` · `created_at` | (제외 — 사유 타당) |

**놓치는 필드 0건.** F-301의 반증 실험(citation 변경 시 ID 불변)이 더는
재현되지 않습니다. 회귀 테스트도 `dataclasses.fields()` 전수 명제로 일반화되어
새 필드가 자동 커버됩니다.

지문 설계의 3단 진화가 기록될 만합니다.

| 시점 | 지문 대상 | 뚫린 것 |
|---|---|---|
| ~3차 | headline 수치만 | 공시 가정 · WARN |
| 3차 시정 | 여섯 항목 열거 | `recalc_targets.citation` (F-301) |
| **4차 시정** | 요청 전체 (2건 제외) | **없음** |
