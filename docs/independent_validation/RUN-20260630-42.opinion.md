### 5.4 F-802 (경부적합) — F-704 시정이 비율 산출에 닿지 않았습니다

`ADV-PROC-05`를 이번 시정에 다시 적용한 결과입니다.

```
expected_loss_vs_provisions()  ← 올바르게 신설됨
        │ shortfall
        ▼
synthesise_components_from_stack(el_shortfall=…)   ← 자본 명세 "시각화용 분해"
        ✗ 여기서 끊긴다

compute_bis_ratios(capital, rwa_final)  ← capital.cet1 은 synthesise_capital() 산출
                                            차감이 반영되지 않는다
```

즉 EL > 충당금인 포트폴리오에서도 `cet1_ratio`는 그대로이고, **CRE40.11 차감은
여전히 적용되지 않습니다.**

나아가 이 결선은 **새 잠복 결함을 만듭니다.** `synthesise_components_from_stack`은
docstring에 "sums back to the input net values exactly"라고 적혀 있고 BR-02에
대사가 있습니다. 실증:

| `el_shortfall` | 명세 표 합계 | 자본금액 | BR-02 대사 |
|---:|---:|---:|---|
| 0 | 1,000,000,000,000.00 | 1,000,000,000,000 | PASS |
| 56,000,000,000 | 944,000,000,000.00 | 1,000,000,000,000 | **FAIL** (차이 −560억) |

또한 `surplus_recognised`(CRE40.30, 본 실행 한도 39,265,722,314)는 계산되지만
`Tier2Components`로 전달되지 않습니다.

현 자료는 IRB EL 40,237,649,241.38 < 충당금 94,531,443,664.95라 shortfall 0이므로
산출값 영향은 없고 BR-02도 PASS입니다. 그러나 **"지금 0"과 "통제가 있다"는 다르다**는
2선 자신의 문장이 이 시정에도 그대로 적용됩니다.

### 5.6 F-806 (적합) — 도전 지점 1: 3선이 약속한 AST 판별을 구현했습니다

`risk_lib/regulatory`의 `FormCheck` 계열 호출부 **1,209건**을 정적 분류했습니다.

| 분류 | 건수 | 비중 |

| `_ratio_check` (라인 참조형) | 296 | 24.5% |
| 양변 상이 | 294 | 24.3% |

`_sum_check` 523건을 부모 라인의 값 표현식과 자식 라인 표현식의 합으로 대조:

| 판정 | 건수 |
|---|---:|
| **항등 확정** (부모 표현식 = 자식 합) | **20** |
| 실질 대사 (부모가 다른 경로에서 계산) | 128 |
| 판별불가 (동적 라인코드·함수 밖 참조) | 375 |

항등 확정 예: `'요주의이하 = 요주의 + 고정이하'`(부모 `watch + npl`),
`'회수대상 계 = 연체 + 대지급'`, `'비귀속 소계 = CCR+시장+운영+하한'`,
`'당분기 발급 = 신규 + 갱신 + 재발급'`.

단측 단언 96건은 항진명제가 숨는 자리이지만, 대부분(담보인정액 ≤ 평가액,
신규취급액 ≤ 잔액, 고정이하 ≤ 총여신 등)은 **독립 산출값 간 부등식**이라 실패
가능합니다. 8차에 확인한 8건(HHI 0~1 · 저점≤기말 · CCR RWA≥0 · 표준 RWA≥0 ·
최고≥평균 · 최저≤평균)이 이 부류의 항진명제입니다.

**종합: 항진명제 최소 28건 확정, 실질 대사 최소 128건 확정, 나머지 미확인.**

정적 판별의 한계도 명시합니다 — BR-11의 `_sum_check('4000 = 3000 + 5000')`은
5000 ≡ 4000−3000인 **의미적** 항등이라 구문 대조로는 "상이"로 분류됩니다.
정적·동적을 함께 써야 하며, `ADV-CALC-06`의 method를 그렇게 확장했습니다.
