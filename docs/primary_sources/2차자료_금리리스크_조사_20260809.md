사용자(원라인에이아이 이재준 PO) 제공. 조사 기준일 2026-08-09.

**이 문서는 2차자료다.** 조사자가 §7에서 스스로 한계를 밝히고 있다. 별표 9의1
전문을 열람하지 못했고, d578 표의 일부 셀은 소스 간 판독이 엇갈린다. 여기 수치를
원장에 넣을 때는 `evidence_status='2차자료'`이며 `원문확인`으로 올리지 않는다.

## 1. 요약

「은행업감독업무시행세칙」 [별표 9의1]은 금리리스크 산출기준으로, 바젤위원회(BCBS)가
2016년 확정한 은행계정 금리리스크(IRRBB) 기준서(d368)를 국내화한 별표다. BCBS
d578(2024-07-16 공표)은 그 기준서의 표준 금리충격 크기를 재조정한 개정 기준서로,
2026-01-01부터 시행되었다. 핵심 변화는 원화 기준 평행 300→225bp, 단기 400→350bp,
장기 200→225bp다.

평행·단기 충격은 완화, 장기 충격은 강화다. 장기 듀레이션 갭이 큰 은행일수록 ΔEVE
영향의 방향이 달라질 수 있다.

## 3. [별표 9의1] 금리리스크 산출기준

### 3.1 원문 접근 경로

- 세칙 본문: https://www.law.go.kr/행정규칙/은행업감독업무시행세칙
  (또는 https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2200000080553)
- 별표 9의1 파일 직링크(등재본): https://www.law.go.kr/LSW/flDownload.do?flSeq=149558495
  `flSeq`는 등재 버전에 따라 바뀌므로 세칙 페이지에서 최신 별표를 내려받는 것을 권장
- 금융감독원 금융감독법규정보시스템(fss.or.kr → 법규정보)에서도 세칙 전문·별표 제공

law.go.kr·fsc.go.kr은 자동수집을 차단하고 별표가 HWP로만 배포되어, 조사에서 별표
9의1 전문을 직접 열람하지 못했다. 3.3의 내용 구성은 BCBS 원문과 금융감독원 도입
발표 등 공개자료에 근거한 **재구성**이며 항목별 문구·수치는 원문 대조가 필요하다.

### 3.2 도입 경과 (확인된 사실)

금융감독원은 **2018-12-20** BCBS 2016년 IRRBB 기준의 국내 도입을 발표했다.
언론 보도(머니투데이 2018-12-20)로 확인되는 내용:

- 산출지표를 자본변동(ΔEVE)과 이익변동(ΔNII)으로 이원화
- 대출 조기상환·예금 중도해지 등 행동 옵션을 현금흐름에 반영
- 금리충격 시나리오를 기존 2개(상승·하락)에서 6개로 다양화
- 감독상 주의은행(이상치 은행) 선정기준을 **자기자본 대비 20%에서 15%로 강화**
- 표준양식에 따른 공시 의무화

세칙 개정은 2019년 1분기 추진 예정으로 발표되었고, 이후 세칙 별표 9의1로
편제되었다. 별표의 정확한 신설·개정 일자는 원문 표제부에서 확인이 필요하다.

## 4. BCBS d578

### 4.1 배경

d368(2016-04)은 표준 금리충격의 주기적 재조정을 예정했고 d578은 그 이행이다.
종전 방법론은 2000~2015년 데이터에 기반해 저금리 국면에 왜곡이 있었고(금리가 0
부근일 때 상대변화율 기반 산출이 불안정), 2022~2023년 급격한 금리 상승과 2023년
3월 은행 혼란을 계기로 재조정이 확정되었다. 시나리오 체계(6개)와 이상치 테스트
등 프레임워크는 그대로 두고 **충격 크기와 산출방법론만** 바꾼 표적 개정이다.

### 4.2 방법론 변경

| 항목 | d368 (2016) | d578 (2024) |
|---|---|---|
| 데이터 기간 | 2000-01 ~ 2015-12 | 2000-01 ~ 2023-12 |
| 충격 산출 | 글로벌 충격계수(상대변화)를 통화군에 적용 | 통화별 로컬. 6개월 롤링 절대변화 기반 |
| 백분위수 | 99% | 99.9% |
| 라운딩 | 50bp | 25bp (절벽효과 완화) |
| 플로어·캡 | 유지 | 플로어 100bp, 캡 평행 400 / 단기 500 / 장기 300 |

산출 절차는 SRP98.56~98.63에 6단계로 규정된다. 일별 금리 시계열 → 6개월 롤링
절대변화 → 99.9백분위 기반 통화별 충격 → 25bp 라운딩·플로어/캡 적용.

### 4.3 통화별 신구 대비 (bp, 평행/단기/장기)

BIS 원문 PDF Table 2와 KPMG 요약자료의 교차 확인 결과.

| 통화 | 구 (d368) | 신 (d578) | 변화 방향 |
|---|---|---|---|
| KRW | 300 / 400 / 200 | 225 / 350 / 225 | 평행·단기 하락, 장기 상승 |
| USD | 200 / 300 / 150 | 200 / 300 / 225 | 장기만 상승 |
| EUR | 200 / 250 / 100 | 225 / 350 / 200 | 전면 상승 |
| GBP | 250 / 300 / 150 | 275 / 425 / 250 | 전면 상승 |
| JPY | 100 / 100 / 100 | 100 / 100 / 100 | 변화 없음 (플로어) |
| CNY | 250 / 300 / 150 | 250 / 300 / 150 ⚠ | 변화 없음 ⚠ |
| HKD | 200 / 250 / 100 | 225~275 ⚠ / 375 / 200 | 전면 상승 |
| SGD | 150 / 200 / 100 | 175 / 250 / 225 | 전면 상승 |
| AUD | 300 / 450 / 200 | 350 / 425 / 300 | 평행·장기 상승, 단기 하락 |
| CHF | 100 / 150 / 100 | 175 / 250 / 200 | 전면 상승 |
| CAD | 200 / 300 / 150 | 200 / 300 ⚠ / 175 | 장기 상승 |
| SEK | 200 / 300 / 150 | 275 / 425 / 200 | 전면 상승 |

이외 고변동 통화(ARS·BRL·IDR·MXN·RUB·TRY)는 캡 적용으로 400/500/300 유지.
INR 325/475/225, SAR 275/375/250, ZAR 325/500/225로 조정.

⚠ 자동 추출 과정에서 소스 간 판독이 엇갈린 셀. CNY·CAD는 변화 없음으로 읽히는
추출이 우세하고, HKD 평행은 225와 275로 엇갈린다. BIS 원문 PDF Table 2 해당 행의
직접 대조가 필요하다.

## 5. 별표 9의1과 d578의 매핑

| 항목 | 관계 및 확인 상태 |
|---|---|
| 프레임워크 | 별표 9의1은 d368 표준화 프레임워크의 국내 이행 규정. d578은 SRP31.90 Table 2와 SRP98만 개정 |
| 국내 반영 대상 | 통화별 표준 충격표(원화 300/400/200 → 225/350/225 여부), 라운딩·캡 문구, 최초 적용 기준일 |
| 반영 여부 | **미확인.** BCBS 시행일은 2026-01-01이며 세칙은 2026-06-26 일부개정 이력 확인(U-LEX). 금융위 규정변경예고에 개정안 자료가 존재하나 자동수집 차단으로 내용 미확인 |
| 확인 방법 | law.go.kr에서 별표 9의1 최신본을 내려받아 ① 표제부 개정 연혁 ② 통화별 충격표 수치 ③ 부칙 적용례 확인 |

## 6. 원문 확인 체크리스트

| # | 점검 항목 | 확인 위치 | 왜 중요한가 |
|---|---|---|---|
| 1 | 별표 9의1 표제부의 신설·개정 연혁 | 별표 HWP 표제부 | 국내 반영 시점·버전 관리의 출발점 |
| 2 | 원화 충격이 225/350/225로 개정되었는지 | 통화별 충격표 | ΔEVE·이상치 테스트에 직접 영향 |
| 3 | 기타 통화 충격의 d578 일치 여부 | 동일 | 외화 익스포저 은행의 산출 정합성 |
| 4 | 25bp 라운딩·플로어 100bp·캡(400/500/300) 문구 | 산출방법 조항 | 방법론 변경의 국내 수용 범위 |
| 5 | 부칙 적용례(최초 적용 산출 기준일) | 세칙 부칙 | 시계열 단절 시점 식별, 백테스트 기준 |
| 6 | NMD 코어예금 상한·조기상환 가정 등 국내 조정 | 행동가정 조항 | BCBS 대비 국내 보수성 수준 |
| 7 | 이상치 기준(Tier 1의 15%)과 감독조치 연계 | 별표 및 감독규정 | Pillar 2 대응 연계 |
| 8 | 공시 서식(DIS70 상당)의 충격값 각주 갱신 | 공시 별표·서식 | 공시와 산출의 정합성 |

독립 재계산 관점에서는 통화별 일별 금리(2000~2023)로 6개월 롤링 절대변화
시계열을 만들고 99.9백분위 값을 25bp로 라운딩한 뒤 플로어·캡을 적용하면 d578
Table 2를 재현·검증할 수 있다.

`shock = clip(round25(P99.9(|Δr_6m|)), 100, cap_scenario)`

## 7. 조사자가 밝힌 한계

1. law.go.kr·fsc.go.kr의 자동수집 차단과 HWP 전용 배포로 별표 9의1 전문을 직접
   열람하지 못했다. 3.3의 구성은 재구성이며 원문과 차이가 있을 수 있다.
2. d578 표의 일부 셀(CNY·CAD·HKD)은 소스 간 판독이 엇갈린다.
3. 별표 9의1의 신설·개정 일자와 2026-06-26 세칙 개정의 내용을 확정하지 못했다.
4. 국내 반영(원화 충격 개정) 여부가 미확인이므로, 이 문서의 수치를 실무에 쓰기
   전 반드시 별표 최신본과 대조해야 한다.

## 8. 결론

[별표 9의1]은 BCBS IRRBB 표준화 프레임워크(d368)의 국내 이행 별표이고, d578은
충격 크기만 재조정한 표적 개정으로 2026-01-01 시행되었다. 원화 기준 평행·단기
완화(300→225, 400→350)와 장기 강화(200→225)는 은행별 포지션 구조에 따라 ΔEVE와
이상치 테스트 결과의 방향을 달리 만들 수 있어 단순 완화로 단정할 수 없다.

다음 행동은 별표 9의1 최신본 확보 → 충격표·부칙 대조 → 산출 시스템 파라미터
변경관리 증적 확인이다.
