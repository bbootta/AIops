# 세일즈 작업 산출물 디렉터리

세일즈 에이전트팀 하네스(`harness/sales/`)의 작업 산출물이 저장되는 곳이다.

| 디렉터리 | 내용 |
|---|---|
| `outbox/<캠페인ID>/` | 발송 패키지 (PO 승인 대기). 에이전트는 발송하지 않으며(G1), 여기 있는 패키지를 사람이 발송한다 |
| `compliance/` | 컴플라이언스 게이트 A/B/C 판정 기록, LIA(정당한 이익 평가서), suppression 정책. 감사 대비 보존 |
| `campaigns/<캠페인ID>/` | 캠페인 작업물: 브리프, 리스트, 계정 리서치, 터치맵, 카피, QA 판정 |
| `deals/<계정슬러그>/` | 딜 지원 산출물: 미팅 브리프·부검, 파일럿 헌장, ROI 케이스, 보안 설문 패키지 |

캠페인ID 형식: `YYYYMMDD-<region>-<slug>` (예: `20260818-us-asset-mgmt`).
운영 리포트와 회고는 `reports/sales/`에 저장한다.
