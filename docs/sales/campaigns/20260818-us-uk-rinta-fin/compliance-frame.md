# US/UK 컴플라이언스 프레임: 미국·영국 금융기관 (린타 / Rinta)

> 저장 경로: `docs/sales/campaigns/20260818-us-uk-rinta-fin/compliance-frame.md`
> 작성: prospect-researcher · 기준일: 2026-08-18 · 근거: KB09 §2·§4·§8, harness/sales/team.yaml G2·G4·G9·G10
> **이 문서는 법률자문이 아니다.** 컴플라이언스 최종 심사·게이트 판정·LIA 승인 상신은 sales-compliance-officer와 PO 몫이다. 경계 사안은 legal-team 에스컬레이션.

## 0. 관할 정책 요약 (이번 캠페인)

| 관할 | 등급(KB09 §8.1) | 체제 | 핵심 전제 |
|---|---|---|---|
| US | 가능(옵트아웃) | CAN-SPAM | 위생 요건 준수 + 주법 소송 리스크 관리 |
| UK | 가능(조건 충족 시) | PECR + UK GDPR | corporate subscriber 확인(불명 시 개인 가입자로 fail-closed) + UK GDPR LIA(G10) |

관할은 **인물 근무지 기준**(KB09 §8.2). 다국적 기업은 본사 아닌 그 사람이 앉아 있는 나라. 복수 관할 걸치면 더 엄격한 쪽. 관할 불명 = 회피 등급, 발송 금지(fail-closed, G2).

## 1. 미국: CAN-SPAM (옵트아웃 체제)

사전 동의 불요. 콜드 메일 합법. 단 메일 1통 단위로 아래를 전부 충족(KB09 §2.2).

| # | 요건 | 실무 포인트 |
|---|---|---|
| 1 | 헤더 진실성 | From/To/회신주소/라우팅에 허위·오인 금지. 도메인 위장 금지 |
| 2 | 제목줄 진실성 | 본문 오인 유발 금지. "Re:"/"Fwd:" 가장 금지. **허위 긴급성 금지** |
| 3 | 광고 식별 가능성 | 특정 문구 강제는 없음. 기만적 위장 금지 |
| 4 | 물리적 우편주소 표기 | 유효한 현재 주소(사무소/P.O. Box/CMRA 허용). **필수** |
| 5 | 수신거부 수단 | 눈에 띄고 작동. 발송 후 최소 30일 유효. 회신 옵트아웃도 허용(링크가 입증 유리) |
| 6 | 수신거부 처리 | **10영업일 이내**, 무료, 추가 정보 요구 금지. 처리 후 재발송 금지 |
| 7 | 옵트아웃 주소 양도 금지 | 수신거부 주소 판매·이전 금지 |
| 8 | 대행 발송 감독 | 제품이 홍보된 회사가 함께 책임. 에이전트팀 산출물도 대상 |

**주법 리스크(2026 최대 이슈, KB09 §2.4):** 워싱턴주 CEMA(개인 소권, 2026-01-14 판결로 집단소송 급증), 캘리포니아 B&P §17529.5(허위 헤더·제목 통당 $1,000). **미국 타깃이라도 제목줄에 허위 긴급성·가장된 스레드·오인 문구 절대 금지.** 카피 품질이 아니라 소송 리스크 문제.

제재: 위반 메일 통당 최대 약 $5.1만~5.3만(FTC 물가연동). 하베스팅·딕셔너리 어택은 형사처벌.

## 2. 영국: PECR + UK GDPR

### 2.1 corporate subscriber 예외 (PECR Reg 22)

- **법인 가입자(limited company, LLP, 스코틀랜드 파트너십, 공공기관)는 Reg 22 동의 규정 대상이 아니다.** 사전 동의 없이 발송 가능.
- **함정 1(N6):** 개인사업자(sole trader)와 (잉글랜드·웨일스·북아일랜드) 일반 파트너십은 **개인 가입자 = 동의 필요.** 소기업 타깃의 최다 위반 지점. → Companies House로 Ltd/PLC/LLP 확인, 불명 시 개인 가입자로 간주(fail-closed).
- **함정 2:** 법인 예외는 PECR 층위. `john.smith@company.co.uk` 같은 개인 식별 주소는 UK GDPR상 개인정보 → 법적 근거(정당한 이익)·제14조 고지·반대권 대응 의무 그대로.
- **함정 3:** 옵트아웃 무시 금지. 유효 수신거부 수단 + "do not email" suppression 운영. UK GDPR 제21조 반대권으로도 중단 의무.

### 2.2 UK GDPR LIA (G10, 필수)

- **UK/EU 레코드는 PO 승인 LIA 없이 발송 큐 진입 불가(G10, fail-closed).** LIA 초안은 sales-compliance-officer가 `templates/sales/lia-record.md`로 작성, PO 승인. 3단 테스트: (a) 목적 정당성(직무 관련 B2B), (b) 필요성(덜 침익적 대안 검토·데이터 최소화), (c) 이익형량(합리적 기대·완화 장치).
- **제14조 고지**: 첫 메일 푸터에 데이터 출처 + 프라이버시 노티스 링크 + 원클릭 수신거부.
- **보관기간**: 마지막 접촉 + 3년. 만료 레코드 삭제·익명화.
- **검증 도구 역외 이전**: EU 리전 처리 또는 SCC/DPA(KB09 §9.3).
- lia_doc_id와 retention_expiry_date는 sales-compliance-officer가 공급, 전 UK 레코드 필드에 기록(G9).

### 2.3 집행 동향

- **Data (Use and Access) Act 2025**: PECR 벌금 상한 50만 파운드 → **1,750만 파운드 또는 전세계 매출 4%**, 2026-02-05 발효. "가볍게 걸리는 시장" 시대 종료.

## 3. 메시지 층위 요건 (US/UK 대비표)

| 항목 | US (CAN-SPAM) | UK (PECR + UK GDPR) |
|---|---|---|
| 사전 동의 | 불요 | 불요(법인 가입자). 개인사업자·일반 파트너십은 필요 |
| 발신자 실명·회사명 | 필요 | 필요 |
| 물리 주소 표기 | **필수** | 권장(신원 요건) |
| 수신거부 수단 | 필수(30일+ 유효) | 필수(원클릭 권장) |
| 수신거부 처리 | 10영업일 이내 | 즉시(반대권) |
| 제14조 고지(출처 + 노티스 링크) | 불요 | **필수(첫 메일)** |
| 제목줄 허위·긴급성 | **금지(주법 소송)** | 금지 |

메시지 카피 작성은 cold-email-writer, 검수는 outreach-qa(G3), 컴플라이언스 게이트 B는 sales-compliance-officer. prospect-researcher는 리스트 층위(게이트 A 입력)까지.

## 4. 발송 큐 진입 게이트 체크리스트 (G4/G9/G10)

이 리스트가 발송 큐에 들어가려면 아래를 전부 통과해야 한다. 게이트는 fail-closed다.

### G9 (스키마 게이트)
- [ ] 전 레코드 jurisdiction = US 또는 UK (불명·EU 0건, 있으면 제외/이관)
- [ ] 전 레코드 data_source(수집 출처)·collection_date(수집일) 채움
- [ ] 전 레코드 signal_latest·signal_date·signal_source_url 채움(지어낸 값 0건)
- [ ] 전 레코드 receipt_basis(수신 근거) 채움: US=CAN-SPAM 옵트아웃 / UK=corporate subscriber + LIA-ID
- [ ] (UK) corporate_subscriber_flag=true 확인, 개인사업자·일반 파트너십(N6) 제외
- [ ] (UK) lia_doc_id·retention_expiry_date 채움 (sales-compliance-officer 공급)
- [ ] "EU" 단일 세그먼트 부재, 관할은 국가 단위

### G10 (EU 데이터 게이트, UK 레코드)
- [ ] UK 레코드에 PO 승인 LIA 존재(3단 테스트)
- [ ] 첫 메일 제14조 고지 요소 포함 설계
- [ ] 보관기간 3년 정책 반영, 만료 레코드 처리 지시
- [ ] 검증 도구 역외 이전 체크(EU 리전 또는 SCC/DPA)
- [ ] 벤더·검증 도구 DPA 체결

### G4 (시그널 게이트, Tier 1~2)
- [ ] Tier 1~2 전건에 30일 이내 계정 리서치 산출물(시그널·가설·훅·배제 확인) 존재
- [ ] "왜 이 사람, 왜 지금" 한 문장 답변 가능. 불가 레코드는 발송 보류
- [ ] 발송 보류 해제는 PO 기록 존재(G1). **현재 Tier 1~2 전 계정 보류 상태(target-accounts §5)**

### 연동 게이트(참고, 타 에이전트 소관)
- [ ] G2 게이트 A/B/C PASS 기록(sales-compliance-officer)
- [ ] G5 딜리버러빌리티 프리플라이트(deliverability-engineer): 검증·웜업·suppression·안전장치
- [ ] G1 발송은 PO 명시 승인으로만. 에이전트는 발송하지 않음

## 5. PO 결정 대기 항목 (이 문서 관련)

1. **UK LIA 승인**: sales-compliance-officer 초안 → PO 승인(G10). 승인 없이는 UK 레코드 발송 큐 진입 불가.
2. **SOC 2·인증 상태 확정**([확인 필요], KB08 §12): 미국 금융기관 서드파티 리스크 관문 통과 가능성 좌우(icp-draft §6.2 S3).
3. **물리 주소·발신 신원 확정**: US 필수 물리 주소(미국 법인 설립 준비 중, KB08 §3.1). 발신 도메인·주소는 deliverability-engineer·PO.
