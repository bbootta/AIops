# 타깃 계정 맵: 미국·영국 금융기관 (린타 / Rinta)

> 저장 경로: `docs/sales/campaigns/20260818-us-uk-rinta-fin/target-accounts.md`
> 작성: prospect-researcher · 기준일: 2026-08-18

## 상태·규율 배너 (먼저 읽을 것)

- **이 맵은 기관 단위 후보만 담는다. 개인 연락처·개인 이메일은 없다.** 인물 특정과 주소 수집·검증은 `list-build-spec.md`의 페르소나 필터 + PO의 검증 도구로 수행한다.
- **모든 후보는 [가설]이다.** ICP 초안(icp-draft.md)이 PO 미확정(G4)이고 린타 제품 정의가 [확인 필요]이므로, 이 리스트는 잠정이다. 후보 사유는 공개적으로 알려진 기관 유형·성격에 근거한 리서처 가설이며, 특정 계약·성과를 단정하지 않는다.
- **"관측 시그널" 열은 전부 [검증 필요]다.** prospect-researcher는 실제 시그널(사건·날짜·출처)을 지어내지 않는다(G3, 환각 훅 금지). 이 열은 "이 계정에서 어떤 유형의 시그널을 찾아야 하는가"를 지시할 뿐이다. 실측 시그널은 계정별 리서치 산출물(`research/<슬러그>.md`, `templates/sales/account-research.md`)에서 채운다.
- **[G4 발송 보류] 현재 Tier 1·Tier 2 전 계정은 발송 보류 상태다.** 30일 이내 작성된 계정 리서치 산출물(유효 시그널 + 가설 + 훅 + 배제 확인)이 아직 없다. "왜 이 사람, 왜 지금"에 한 문장으로 답하는 실측 시그널 없이는 시퀀스 투입 불가. **보류 해제는 PO만 가능하다(G1).** 발송 보류 목록은 §5.
- **부서·데스크 단위 진입 원칙.** 초대형 기관은 전사가 아니라 "아시아 커버리지가 부족한 특정 부서"만 타깃(icp-draft §2·§6.1 N3).

## 7. PO 결정 대기 항목 (이 문서 관련)

1. **린타 정의·쐐기 확정 후 이 맵 재검토**(H3이면 재작성).
2. **Tier 1 후보의 전사 vs 부서 단위 접근 승인**: 초대형 기관을 후보로 유지할지, 부서 한정으로 좁힐지.
3. **N3 근접 퀀트 계정(Man Group·Marshall Wace·G-Research·Winton) 유지/배제 판정.**
4. **발송 보류 해제**: 계정 리서치 산출물 완비 후, 계정별로 PO가 해제(G1).
5. **공략 앵글 선택**: 계정별 앵글 후보는 계정 리서치 산출물 §7에 2~3개 제시 예정. 선택은 PO(비워 둠).
