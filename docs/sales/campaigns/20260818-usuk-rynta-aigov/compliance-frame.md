## 0. 관할 원칙

- **수신자 소재지(근무지) 법이 기준이다**(KB09 §8.2). 다국적 기관이면 본사가 아니라 그 사람이 앉아 있는 나라. US / UK 국가 단위로 분리, "EU" 세그먼트 금지(G9).
- 관할 불명은 회피 등급(fail-closed)으로 태깅해 sales-compliance-officer 판정에 넘긴다(G2). 임의로 발송 가능 분류 금지.
- 이 캠페인은 US·UK만 대상이다. 그 외 관할 레코드가 섞이면 캠페인을 중단하고 재세그먼트한다.

## 1. 미국: CAN-SPAM (옵트아웃 체제)

콜드 메일 자체는 합법. 단 메일 1통 단위로 아래를 전부 충족(KB09 §2.2).

| # | 요건 | 이 캠페인 적용 |
|---|---|---|
| 1 | 헤더 진실성 | From·회신주소 실제 발송 주체 표시. 도메인 위장 금지 |
| 2 | 제목줄 진실성 | "Re:"/"Fwd:" 가장, 허위 긴급성 금지. **주법 소송 리스크(워싱턴 CEMA·캘리포니아 §17529.5)**: 오인 제목은 카피 품질이 아니라 소송 문제(KB09 §2.4) |
| 3 | 광고 식별 가능성 | 세일즈 메일임이 맥락으로 식별 가능. 기만적 위장 금지 |
| 4 | 물리적 우편주소 | 유효한 현재 주소 표기(사서함·CMRA 허용) |
| 5 | 수신거부 수단 | 눈에 띄고 작동. 발송 후 최소 30일 유효 |
| 6 | 수신거부 처리 10영업일 | 무료·추가정보 요구 금지. 처리 후 재발송 금지(목표는 즉시 자동화) |
| 7 | 옵트아웃 주소 양도 금지 | suppression 주소 판매·이전 금지 |
| 8 | 대행 발송 감독 | 대행사가 위반해도 홍보된 회사(원라인AI)가 함께 책임 |

제재: 위반 메일 1통당 최대 약 $51,744(FTC 물가연동) + 주법 소송(KB09 §2.3).

## 2. 영국: PECR + UK GDPR (두 겹)

### 2.1 PECR corporate subscriber 예외 (KB09 §4.1)

- **법인 가입자(limited company, LLP, 스코틀랜드 파트너십, 공공기관)에는 사전 동의 없이 발송 가능.** 빌딩소사이어티·은행은 통상 여기 해당.
- **함정 1: 개인사업자(sole trader)와 잉글랜드·웨일스·북아일랜드의 일반 파트너십은 개인 가입자 = 동의 필요.** target-accounts §2.4, negative ICP H4. 리스트에서 분리해 동의 기반 채널로.
- **함정 2: 법인 예외는 PECR 층위다. john.smith@bank.co.uk 같은 개인 식별 주소는 UK GDPR상 개인정보** → 법적 근거(LIA)·제14조 고지·반대권 대응 의무가 그대로 남는다.
- **함정 3: 옵트아웃 무시 금지.** 유효한 수신거부 수단 + "do not email" 억제 리스트 운영. UK GDPR 제21조 반대권으로도 중단 의무 발생.

### 2.2 UK GDPR LIA (정당한 이익 평가, G10)

- 발송 전 LIA 3단 테스트 문서화(KB09 §3.2): (a) 목적 정당성(B2B 매출, 수신자 직무 관련성 = 모델리스크·AI 거버넌스 직책), (b) 필요성(덜 침익적 대안 검토), (c) 이익형량(합리적 기대·데이터 최소화).
- **LIA 문서 ID와 보관기간 만료일은 sales-compliance-officer가 공급하고, 스키마(list-build-spec §1.2 lia_document_id·lia_retention_expiry)에 채운다(G9·G10).** 값이 빈 UK 레코드는 발송 큐 진입 불가.
- 제14조 고지: 첫 메일 푸터에 "출처 + 프라이버시 노티스 링크 + 원클릭 반대"를 넣어 고지 의무 겸함.
- 보관기간: 무기한 보관 금지(실무 통설 마지막 접촉 3년, 자체 기준 문서화). 반응 없는 프로스펙트는 기한 도래 시 삭제·익명화.

### 2.3 집행 동향 (KB09 §4.3)

- **Data (Use and Access) Act 2025**: PECR 벌금 상한이 50만 → **1,750만 파운드 또는 전세계 매출 4%**, 2026-02-05 발효. "가볍게 걸리는 시장" 아님.

## 3. sole trader 함정 (별도 강조)

- UK 리스트에서 가장 흔한 위반 지점(KB09 §4.1). 빌딩소사이어티·은행 본체는 문제없으나, 연관 소규모 자문·중개 법인이 sole trader/일반 파트너십이면 개인 가입자다.
- 처리: Companies House로 법인 형태 확인 → uk_entity_form·corporate_subscriber_flag 채움. **불명확하면 개인 가입자로 간주(fail-closed)** 하고 동의 기반 채널로 분리.

## 4. 게이트 체크리스트 (G4 / G9 / G10)

### 게이트 A: 리스트 층위 (G9)
- [ ] 전 레코드 jurisdiction 태그(US/UK), 불명 0건(있으면 제외 → compliance-officer)
- [ ] "EU" 세그먼트 부재(국가 단위 분리)
- [ ] UK: corporate_subscriber_flag=Y 확인, sole_trader·일반 파트너십 분리
- [ ] UK: lia_document_id·lia_retention_expiry 채움(compliance-officer 공급)
- [ ] data_source·collected_date 기록(벤더·추출일·DPA 여부)
- [ ] suppression(전역+도메인) 대조 완료
- [ ] 이메일 검증 통과(valid), catch-all·role 분리, 예상 바운스 2% 미만

### 게이트 B: 메시지 층위
- [ ] 헤더·제목 진실성(미국 주법 소송 리스크 포함)
- [ ] 발신자 실명·회사명 표기
- [ ] 물리 주소 표기(미국 필수)
- [ ] 수신거부 수단(원클릭/회신 안내, 무료, 추가정보 요구 없음)
- [ ] UK 첫 메일: 제14조 고지(출처 + 프라이버시 노티스 링크)
- [ ] 직무 관련성: 문안이 수신자 역할(모델리스크·AI 거버넌스)과의 관련을 스스로 입증

### 게이트 C: 리서치·보류 층위 (G4)
- [ ] Tier 1~2 전건 30일 이내 계정 리서치 산출물 존재
- [ ] "왜 이 사람, 왜 지금" 한 문장 답변 가능(불가 시 발송 보류)
- [ ] 시그널 일자가 유효기간(icp-draft §4) 내
- [ ] 발송 보류 해제 기록(PO 서명) 존재

### 게이트 D: 운영 층위
- [ ] 수신거부 자동 억제 파이프라인 작동(목표 즉시, 상한 미국 10영업일)
- [ ] 시퀀스 후속 메일도 동일 게이트(수신거부자 후속 발송 사고 방지)
- [ ] 게이트 통과 기록 보존(감사 대비)

**게이트는 fail-closed다.** 하나라도 미충족이면 발송 불가. 실행(발송) 자체는 PO 몫이며 에이전트는 발송하지 않는다(G1).
