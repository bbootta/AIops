# Ghost Patrol 3D (고스트버스터즈 팬메이드)

Three.js로 만든 오픈월드 유령 사냥 게임입니다. 설치나 빌드 없이 `index.html` 하나로 실행되고, 휴대폰 터치 조작도 지원합니다.
팬이 만든 비공식 게임이며 공식 로고·음악·인물은 쓰지 않았습니다. 모델, 텍스처, 효과음은 전부 코드로 생성합니다.

## 실행

```bash
cd ghostbusters
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열고 **출동하기**를 누릅니다. Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 게임 흐름

1. 상단 **PKE 미터** 화살표와 미니맵의 유령 점을 따라 이동합니다.
2. **양성자 빔**으로 유령을 붙잡아 기력을 뺍니다. 빔이 유령에 걸리면 조준을 옮겨도 빔이 휘어지며 따라갑니다.
3. 유령이 **기절**하면 빔으로 붙잡은 채 끌고 와서 **트랩**을 던집니다. 트랩 반경 안의 기절한 유령은 빛기둥으로 빨려 들어갑니다.
4. 포획할 때마다 상금을 받고, 5마리를 잡으면 번개와 함께 보스 **네온 거신**이 내려옵니다.
5. 머리 위에 **!** 표시가 뜬 시민에게 E로 말을 걸면 의뢰를 받을 수 있습니다. 의뢰를 끝내면 큰 보상과 **평판**이 오릅니다.
6. 번 돈과 평판으로 본부 앞 **오 박사 연구실**($ 표시)에서 장비를 개조합니다.
7. 차를 빼앗거나 시민·경찰을 다치게 하면 **수배**가 붙고 경찰이 쫓아옵니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 (Shift 달리기, Space 점프, Space를 누르고 있으면 제트팩 비행) |
| 마우스 | 조준 · 왼쪽 버튼 발사 · 오른쪽 버튼 정밀 조준 (기절한 유령을 끌어당김) |
| 1 2 3 4 / 휠 | 양성자 빔 · 슬라임 블래스터 · 보손 다트 · 초대형 게틀링 |
| G | 트랩 던지기, 다시 누르면 회수 |
| E | 의뢰인 대화 · 사다리 오르내리기 · 짚라인 타기 · 오 박사 연구실 (대화창에서 E 수락, X 거절) |
| F | 차량 탑승 · 탈취 · 하차 |
| 운전 중 W S A D / Space / H | 가속·후진·조향 / 핸드브레이크 드리프트 / 고스트 왜건·경찰차 사이렌 |
| 운전 중 Shift | 니트로 (고스트 왜건 튜닝 2단계) |
| 사다리·짚라인에서 W S / Space | 오르내리기 (Shift 빠르게) / 뛰어내리기·손 놓기 |
| R · M · Esc | 비 켜고 끄기 · 소리 · 일시정지 |

휴대폰: 왼쪽 드래그로 이동(끝까지 밀면 달리기, 튜닝한 고스트 왜건에서는 니트로), 오른쪽 드래그로 시점, 버튼으로 발사·무기·트랩·점프(누르고 있으면 제트팩)·탑승. 상호작용할 대상이 가까이 있으면 **행동** 버튼이 나타납니다. 터치에서는 조준 보정이 더 넓게 걸립니다.

## 무기와 효과

| 무기 | 특징 | 팩 온도 |
|---|---|---|
| 양성자 빔 | 5겹 리본(코어·글로우·나선 2가닥·전기 아크) + 곁가지 번개, 명중점 불꽃·연기·그을음, 빔 끝 조명 | 초당 +17 |
| 슬라임 블래스터 | 포물선 점액탄, 명중한 유령 감속, 벽·바닥에 빛나는 점액 자국 | 발당 +2.5 |
| 보손 다트 | 폭발(화구·섬광·충격파 링·파편·연기), 주변 차량 연쇄 폭발, 가로등 쓰러뜨림 | 발당 +16 |
| 초대형 게틀링 | 6열 회전 총열이 돌기 시작한 뒤 초당 22발, 총구 화염·예광탄·탄피 배출, 벽 탄흔·불꽃·연기, 유령·차량·헬기 피해, 쏘는 동안 이동이 느려짐 | 발당 +0.5 (초당 +11) |

팩 온도가 100에 닿으면 과열되어 증기를 뿜으며 식을 때까지 발사할 수 없습니다. 게틀링으로 시민이나 경찰을 맞히면 수배가 붙습니다.

## 달리기와 제트팩

- Shift(휴대폰은 왼쪽 스틱을 끝까지)를 누르고 달리면 보폭이 커지고 팔을 크게 흔들며, 발소리와 먼지가 일고 시점이 넓어집니다. 조준하거나 게틀링을 쏘는 동안에는 달릴 수 없습니다.
- 공중에서 Space(휴대폰은 점프 버튼)를 누르고 있으면 제트팩이 화염을 뿜으며 날아오릅니다. 짧게 누르면 보통 점프입니다.
- 비행 중에는 땅보다 빠르게 움직이고, Shift를 함께 누르면 더 빨라지는 대신 연료를 더 씁니다.
- 왼쪽 아래 **연료** 막대는 땅에 내려서거나 차에 타면 다시 찹니다. 빠르게 떨어지다 땅이 가까워지면 남은 연료로 자동 감속 분사를 해 충격을 줄이고, 연료가 바닥나면 그대로 떨어집니다.

## 경찰과 수배

- 차량 탈취가 목격되거나, 경찰차를 들이받거나 빼앗거나, 폭발로 시민·경찰을 다치게 하면 수배 단계(별 1~5개)가 오릅니다.
- 순찰차가 사이렌을 켜고 도로망을 따라 추격하고, 가까워지면 경관이 내려 전기 충격탄을 쏩니다. 맞으면 잠시 느려집니다.
- 4단계부터 **경찰 헬기**가 탐조등을 비추며 따라옵니다. 슬라임이나 보손 다트, 빔으로 격추할 수 있지만 수배가 더 무거워집니다.
- 경찰 시야에서 벗어나 있으면 별이 하나씩 깜빡이며 줄어들고, 본부 앞마당으로 숨으면 바로 풀립니다.
- 멈춘 채로 경관에게 붙잡히면 **체포**되어 소지금 10%를 벌금으로 내고 본부에서 풀려납니다.

## 옥상 이동

- 빌딩 외벽의 **사다리**에서 E를 누르면 옥상까지 올라갑니다. 옥상 가장자리에서 다시 E를 누르면 내려갑니다.
- 일부 옥상에는 초록 표시등이 깜빡이는 **짚라인**이 있어 길 건너 낮은 옥상으로 미끄러져 내려갈 수 있습니다. 짚라인이 닿는 옥상에도 내려가는 사다리가 있습니다.
- 옥상 12곳에 하늘색 빛기둥의 **PKE 샘플**이 숨어 있습니다. 하나에 $300, 모두 모으면 보너스 $3,000을 받습니다.
- 낮은 옥상에는 제트팩으로 바로 날아오를 수 있습니다.
- 7.5m 넘게 떨어지면 낙하 피해를 입습니다. 제트팩 연료통을 개조하면 줄어듭니다.

## 저장

소지금, 평판, 의뢰 단계, 개조, 모은 샘플은 브라우저 `localStorage`에 저장됩니다(20초마다, 그리고 포획·의뢰·구매·샘플 획득 때). 다시 열면 시작 화면에 저장된 기록이 표시되고 이어서 합니다. 일시정지 메뉴의 **기록 초기화**를 두 번 누르면 처음부터 시작합니다.

## 도시

- 9×9 블록 격자, 도심일수록 높은 빌딩(일부는 셋백 타워와 안테나 경고등), 멀리 이어지는 스카이라인
- 가로등 약 1,000개는 인스턴싱으로 그리고, 가까운 가로등만 실제 조명으로 비춤(아래 그래픽 참고)
- 도로를 따라 달리는 차량 20대, 순찰차 3대, 주차 차량 22대, 인도를 걷다 유령·폭발·차를 피해 달아나는 시민 30명
- 모든 차량은 빼앗아 탈 수 있고, 충돌 피해가 쌓이면 폭발 후 불탑니다
- 비, 번개, 공원, 분수 광장, 네온 간판, 본부(GHOST PATROL 소방서)

## 그래픽

비 오는 흐린 밤의 도시가 사진처럼 보이도록 맞췄습니다. 텍스처와 모델은 모두 코드로 생성하며 외부 파일은 쓰지 않습니다.

- **젖은 도로**: 거울 카메라로 그린 도시가 노면에 실시간으로 비칩니다. 물웅덩이와 배수로에서는 반사가 또렷하고 덜 젖은 곳은 흐리게 번지며, 빗방울 파문이 반사를 흔듭니다. 비를 끄면 노면이 조금 마르지만 젖은 기운은 남습니다.
- **가로등**: 카메라 앞 가까운 가로등 8개(휴대폰은 4개)는 실제 스포트라이트로 노면과 차, 사람을 비추고 나머지는 바닥 빛웅덩이로 처리합니다. 빗속에서는 가로등 아래로 빛줄기가 보입니다.
- **창문**: 가까운 빌딩의 불 켜진 창 안쪽에 천장 조명이 달린 방이 보는 각도에 따라 깊이감 있게 보입니다(interior mapping). 벽면은 법선 맵(normal map)과 유리, 벽체 재질 구분을 씁니다.
- **차량**: 도장에 클리어코트(clearcoat) 광택을 넣고 유리, 타이어, 크롬을 재질별로 구분했습니다.
- **하늘**: 도시 불빛을 받은 낮은 구름이 덮고 있다가, 비를 끄면 걷히면서 별과 달이 나옵니다.
- **후처리**: AgX 톤매핑, 블룸, FXAA 안티에일리어싱, 필름 색보정(스플릿 톤, 비네팅, 그레인).

일시정지 메뉴의 **그래픽** 버튼으로 품질을 고릅니다. **자동**은 높음(휴대폰은 보통)에서 시작해 90프레임 평균이 28fps 밑으로 떨어질 때마다 한 단계씩 내립니다.

| 단계 | 렌더 해상도 배율 | 젖은 도로 반사 | 가까운 가로등 실제 조명 | 블룸 | FXAA, 색보정, 창 안쪽 방 |
|---|---|---|---|---|---|
| 높음 | 기기 배율(최대 1.6, 휴대폰 1.4) | 가로세로 0.5배 | 켜짐 | 켜짐 | 켜짐 |
| 보통 | 1.0 | 가로세로 0.4배(휴대폰 0.3배) | 켜짐 | 켜짐 | 켜짐 |
| 낮음 | 0.7 | 꺼짐 | 꺼짐 | 꺼짐 | 꺼짐 |

## 테스트

```bash
# playwright 와 three@0.160.0 이 설치된 node_modules 경로를 NODE_PATH 로 지정
NODE_PATH=/path/to/node_modules node ghostbusters/smoke-test.cjs [스크린샷_폴더]
```

실제 크로미움에서 게임을 띄워 아래 흐름을 차례로 확인하고, 런타임 오류가 없으면 `PASS`를 출력합니다.

- 빔 명중·과열 상승, 기절한 유령의 트랩 포획, 보손 폭발, 고스트 왜건 탑승·가속
- 달리기 속도, 제트팩 상승·연료 소모·착지 감속·재충전, 초대형 게틀링 회전·명중·탄피·발열
- E로 의뢰 대화창 열기와 수락, 의뢰 HUD·목표 표식, 이름 붙은 원령 포획으로 의뢰 완료
- 귀신 들린 택시의 귀신 분리와 실패 정리, 편의점 습격 유령 출현과 시간 종료 성공, 레이스 출발·체크포인트·완주
- 수배 추격, 5단계 헬기 출동, 경관 체포와 벌금, 석방
- 사다리 오르내리기, 짚라인 착지 높이, 옥상 샘플 획득
- 연구실 구매와 능력치 반영, `localStorage` 저장, 새로 고침 후 이어 하기
