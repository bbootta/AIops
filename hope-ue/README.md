# 호프: 마지막 거리 — Unreal Engine

영화 **호프**의 시가전 장면을 언리얼 엔진으로 옮긴 3인칭 슈팅게임입니다.
같은 저장소의 `hope-shooter/`(three.js + Electron)와 같은 게임이고, 렌더러만 다릅니다.

> **이 프로젝트는 컴파일된 적도, 실행된 적도 없습니다.** 만든 환경에 언리얼 엔진이
> 없었고 설치할 수도 없었습니다. 아래 [검증하지 못한 것](#검증하지-못한-것)을
> 먼저 읽어 주세요.

---

## 왜 언리얼인가

`hope-shooter/`의 WebGL 빌드는 실사화를 계속 밀어붙인 끝에 브라우저가 넘을 수 없는
천장에 닿았습니다. 언리얼로 옮기면서 실제로 달라지는 것은 이 네 가지입니다.

| WebGL 빌드에서 했던 것 | 언리얼에서 대체되는 것 |
| --- | --- |
| PMREM으로 미리 구운 HDRI 환경광 (빛이 튀지 않음) | **Lumen** — 실시간 GI. 햇빛이 파사드에 튕겨 상점 안쪽과 차양 아래로 실제로 들어감 |
| 캐스케이드 섀도우 맵 (근거리에서 계단현상) | **Virtual Shadow Maps** — 접촉 그림자 해상도가 자릿수로 올라감 |
| 빌보드 안개 카드 (AO 패스를 망가뜨렸던 그 카드) | **Volumetric Fog** — 빛을 실제로 산란시키는 참여 매질 |
| 폴리곤 예산에 묶인 절차적 지오메트리 | **Nanite** — 스캔 에셋을 예산 없이 그대로 투입 |

## 실사화는 실제로 어디에서 오는가

**이 저장소의 코드는 렌더러와 파이프라인을 세팅할 뿐, 그 자체로 실사가 아닙니다.**
거리와 인물은 엔진 기본 큐브로 조립된 **플레이스홀더**입니다. 형태와 배치와 조명은
영화 스틸에 맞춰 두었지만, 표면과 인물은 아래를 붙여야 실사가 됩니다.

1. **환경 재질 — Fab / Quixel Megascans.** 실측 스캔 재질입니다. 언리얼 안에서
   무료로 받을 수 있지만 Epic 계정이 필요하고 이 저장소에 재배포할 수 없습니다.
   `M_Hope_Asphalt`, `M_Hope_Brick`, `M_Hope_Stucco` 등의 자리에 그대로 갈아끼우면
   됩니다 — 키 이름은 `HopeStreet.cpp`의 `Materials.Add(...)` 목록에 있습니다.
2. **인물 — MetaHuman.** 지금의 각진 경찰관을 대체합니다. `HopeCharacter`의 조준·
   반동·양손 파지는 메시와 분리해 두었으므로, 스켈레탈 메시 교체와 소켓 연결로 끝나고
   재작성이 필요 없습니다.
3. **거리 소품 — Fab의 스캔 기반 차량/잔해.** Nanite가 켜져 있으므로 폴리곤을
   줄이지 않고 그대로 넣으면 됩니다.

이 세 가지는 계정 로그인이 필요하고 라이선스상 저장소에 담을 수 없어, **제가 대신
넣어 드릴 수 없는 부분**입니다. WebGL 빌드에서 전신 스캔을 구하지 못했던 것과 같은
제약입니다.

## 실행 방법

**필요한 것:** 언리얼 엔진 5.4 이상, 그리고 C++ 툴체인
(Windows: Visual Studio 2022 + "Game development with C++" 워크로드 /
macOS: Xcode / Linux: 엔진에 포함된 clang 툴체인).

```
1. HopeLastStreet.uproject 를 더블클릭 → 엔진 버전 선택 → "지금 빌드" 수락
2. 에디터가 열리면 Play (Alt+P)
```

`.uproject`의 `EngineAssociation`은 비워 두었습니다. 설치된 엔진을 직접 고르게 하는
편이 특정 버전에 고정하는 것보다 안전하기 때문입니다.

**콘텐츠 생성 스크립트(선택).** 안 돌려도 게임은 돌아갑니다 — 재질을 못 찾으면
엔진 기본 재질에 색만 입혀 대체합니다. 돌리면 각 표면에 노이즈 기반 베이스컬러·러프니스
변조가 붙어, 200m짜리 파사드가 민무늬 상자로 보이지 않게 됩니다.

```
에디터 > Output Log > 좌하단 드롭다운을 "Python"으로 변경 후:
exec(open(r"<프로젝트경로>/Tools/build_content.py").read())
```

**조작:** `WASD` 이동 · `마우스` 조준 · `좌클릭` 사격 · `우클릭` 정조준 ·
`R` 재장전 · `Shift` 달리기 · `Space` 재투입

## 구조

```
Config/DefaultEngine.ini        Lumen · Nanite · VSM · TSR · 볼류메트릭 — 렌더러 설정 전부
Config/DefaultInput.ini         입력 매핑
Source/HopeLastStreet/
  HopeBlocks.*                  엔진 프리미티브로 액터를 조립하는 헬퍼 + 재질 폴백
  HopeStreet.*                  거리 지오메트리 + 태양/하늘/안개/포스트프로세스
  HopeCharacter.*               경찰관 — 3인칭 카메라, 오른손 파지, 사격/재장전/반동
  HopeShadow.*                  그림자 괴물 — 추적, 피격, 소멸
  HopeGameMode.*                웨이브 디렉터, 점수, 보급
  HopeHUD.*                     캔버스 HUD
Tools/build_content.py          재질 생성 + 빈 레벨 생성 (선택)
```

### 설계상 택한 것들

- **레벨 에셋이 비어 있습니다.** 거리는 `AHopeStreet`이 `BeginPlay`에서 직접
  세웁니다. `.umap`·`.uasset`은 바이너리라 에디터 밖에서 만들 수 없는데, 그러면
  clone 직후 실행이 불가능해집니다. 대신 런타임 생성 컴포넌트는 `Static`이 될 수
  없어 Lumen 비용을 더 냅니다 — 프로파일에 잡히면 에디터에서 거리를 굽는 것이 답입니다.
- **Enhanced Input이 아니라 레거시 입력 매핑.** Enhanced Input은 `UInputAction`
  에셋을 요구하고, 그건 다시 바이너리 에셋 문제로 돌아갑니다.
- **UMG가 아니라 캔버스 HUD.** 같은 이유입니다.
- **HUD 문구가 영문.** 엔진 기본 폰트에 한글 글리프가 없어 한글은 네모로 나옵니다.
  한글 HUD를 원하시면 한글 폰트 에셋을 추가하고 `HopeHUD.cpp`의 `GEngine->GetLargeFont()`
  자리를 교체하세요.
- **그림자 괴물이 `ACharacter`가 아닙니다.** 평평한 거리를 플레이어에게 직진하는 게
  전부라, 무브먼트 컴포넌트·AI 컨트롤러·내브메시가 전부 불필요합니다.
- **처치 보상을 픽업 액터 대신 즉시 지급.** 드롭 확률(탄약 34%, 치료 16%)은
  WebGL 빌드와 같습니다.

게임플레이 수치 — 탄창 30발, 재장전 1.7초, 웨이브당 적 수 `4 + 웨이브×2`, 3웨이브부터
20% 확률의 브루트, 헤드샷 3배 — 는 WebGL 빌드에서 그대로 옮겼습니다.

## 검증하지 못한 것

만든 환경에는 언리얼 엔진이 없고, 설치도 불가능했습니다. 근거는 이렇습니다.

- 가용 디스크 **29GB**. UE 5 바이너리 설치만 110GB 이상입니다.
- UnrealBuildTool이 요구하는 **.NET SDK가 없습니다**.
- 엔진 소스는 Epic 계정 연동이 필요한 비공개 저장소로, 이 작업 세션의 접근 범위 밖입니다.

따라서 **다음은 전부 확인되지 않았습니다.**

- 컴파일 여부 — C++ 한 줄도 컴파일해 보지 못했습니다. 오래 안정적인 API만 골라
  썼지만, 그건 근거가 아니라 위험을 줄인 것뿐입니다. 엔진 버전에 따라
  `FPostProcessSettings`의 필드명이나 `ASkyAtmosphere`의 헤더 위치가 다를 수 있습니다.
- 실행·렌더링 여부 — 스크린샷이 없습니다.
- `Tools/build_content.py`의 언리얼 Python API 호출.
- 프레임레이트. Lumen 하드웨어 레이트레이싱 + VSM은 무거운 조합이라, 사양에 따라
  `DefaultEngine.ini`에서 `r.Lumen.HardwareRayTracing=0`으로 내려야 할 수 있습니다.

첫 빌드에서 에러가 나면 그건 예상 범위 안입니다. 오류를 보내 주시면 고치겠습니다.
