## 1. 핵심 원칙 요약 (전 팀원 암기 사항)

1. **ICP가 모든 것의 상류다.** 리스트, 시그널, 메시지, 티어링이 전부 ICP에서 파생된다. ICP가 틀리면 하류 전체가 낭비다. 문서화·스코어링된 ICP를 가진 팀이 그렇지 않은 팀 대비 승률 20~40% 우위, 세일즈 사이클 15~30% 단축이라는 보고가 있다(업계 통설에 가까움, §2.1).
2. **ICP는 "누구에게 팔 수 있는가"가 아니라 "누가 사서, 확장하고, 남는가"다.** closed-won만이 아니라 이탈(churn)·실패 딜에서 negative ICP를 함께 추출한다.
3. **자격 미달 배제(disqualification)는 볼륨 손실이 아니라 승률 투자다.** 배제 규칙 도입으로 리드 볼륨 40% 감소, 승률 22% 상승 사례 보고(§2.4).
4. **시그널 없는 아웃바운드는 하지 않는다.** "왜 지금 이 회사인가"에 답하는 트리거(채용, 투자, 인사이동, 기술 변화)가 있어야 발송한다. 시그널 기반 개인화 답장률 15~25% vs 제네릭 1~5%(업계 통설, §5.1).
5. **리서치는 티어에 비례한다.** Tier 1은 계정당 10분+, Tier 3은 계정당 2~3분 또는 자동화. 모든 계정에 같은 시간을 쓰는 것은 전략 부재다(§7).
6. **리스트는 자산이 아니라 부패물이다.** B2B 데이터는 연 20~30% 속도로 부패한다는 것이 업계 통설이다(이직·조직개편·도메인 변경). 발송 직전 검증 없이 90일 이상 묵은 리스트를 쓰지 않는다(§4.3).
7. **한국 시장은 채널 문법이 다르다.** 이메일 옵트인 규제(정보통신망법 제50조), 링크드인 저보급, 소개·대면 중심 문화를 전제로 설계한다. 글로벌 플레이북을 직역하면 실패한다(§8).
8. **ICP는 분기마다 갱신한다.** 분기 갱신 팀이 연 1회 갱신 팀 대비 MQL→closed-won 전환 20~35% 우위 보고(업계 통설, §2.5).

## 2. ICP(이상고객프로필) 정의 방법론

### 2.1 ICP의 정의와 효과

ICP는 "가장 잘 사고, 가장 오래 남고, 가장 크게 확장하는 **회사**의 다차원 정의"다. 페르소나(사람)와 구분한다: ICP는 계정 레벨, 페르소나는 그 계정 안의 개인 레벨이다.

효과에 대한 공개 보고(출처별 모수 상이, 방향성으로만 읽을 것):

| 주장 | 수치 | 비고 |
|---|---|---|
| 명확한 ICP 보유 기업의 승률 우위 | +68% | ZoomInfo 계열 자료 인용 수치 |
| 문서화·스코어링된 ICP 팀의 승률 우위 | +20~40% | 업계 통설 |
| 세일즈 사이클 단축 | 15~30% | 업계 통설 |
| 분기별 ICP 갱신 팀의 전환율 우위 | +20~35% | 연 1회 갱신 대비, 업계 통설 |

### 2.2 ICP의 5개 층 (프레임워크)

ICP 문서는 다음 5개 층을 모두 담아야 완결이다. 1~2개 층만 있는 ICP(예: "직원 50~500명 IT 기업")는 필터이지 프로필이 아니다.

| 층 | 내용 | 예시 기준 |
|---|---|---|
| 1. Firmographic (기업 속성) | 산업/버티컬, 직원 수, 매출 규모, 지역, 성장 단계, 자금 조달 단계 | "국내 금융업 또는 시리즈 B 이상 핀테크, 직원 100~2,000명" |
| 2. Technographic (기술 속성) | 사용 중인 기술 스택, 경쟁/보완 제품 사용 여부, 인프라(클라우드/온프렘) | "AWS 사용, 자체 데이터팀 보유, 경쟁사 X 미도입" |
| 3. Behavioral/시그널 (행동 속성) | 채용 급증, 투자 유치, 신사업 발표, 규제 대응 필요, 웹사이트/콘텐츠 행동 | "리스크·데이터 직군 채용 중, 최근 12개월 내 투자 유치" |
| 4. 조직 준비도 (organizational readiness) | 구매 프로세스 성숙도, 예산 사이클, 챔피언이 될 직무의 존재, 의사결정 구조 | "CDO 또는 데이터 조직장이 존재, 연간 IT 예산 편성" |
| 5. Negative ICP (배제 기준) | 이탈·실패를 예측하는 특성. 감점이 아니라 **탈락** 기준 | "직원 20명 미만, 12개월+ 의사결정 이력 업종, 미지원 스택" |

### 2.3 ICP 도출 절차 (데이터 기반, 5단계)

추측으로 ICP를 쓰지 않는다. 아래 절차를 따른다.

1. **closed-won 분석**: 최근 1~2년 성사 딜 전수를 표로 만든다. 열: 산업, 직원 수, 매출, 딜 크기(ACV), 사이클 길이, 유입 경로, 최초 접점 페르소나, 성사 트리거.
2. **베스트 고객 추출**: 그중 "LTV 상위 + 온보딩 순탄 + 확장 구매 + 추천 의향" 교집합 10~20개를 뽑아 공통 속성을 찾는다. 딜 크기만 크고 유지가 나쁜 고객은 베스트가 아니다.
3. **churn·lost 분석**: 이탈 고객과 패배 딜에서 반복 패턴을 추출해 negative ICP로 명문화한다. 전형적 패턴: 규모 하한 미달(딜 경제성 붕괴), 미지원 기술 스택, 12개월+ 의사결정, 과도한 커스터마이징 요구, 조달 과정에서 딜 가치 잠식.
4. **고객 인터뷰 검증**: 베스트 고객 3~5곳에 "왜 샀나, 무엇과 비교했나, 언제 필요성을 느꼈나(트리거), 누가 반대했나"를 묻는다. 데이터가 못 잡는 구매 맥락을 채운다.
5. **가설 ICP 문서화 → 분기 검증**: ICP 적합 점수와 실제 승률·딜 속도·확장률을 분기마다 교차 검증하고, 예측력 없는 기준은 제거한다.

초기 스타트업 예외: closed-won 표본이 10건 미만이면 통계가 아니라 "창업자 가설 + 빠른 검증 루프"로 시작하되, ICP 문서에 "가설 단계"라고 명시한다.

### 2.4 ICP 스코어링 모델

계정을 점수화해 티어링(§7)의 입력으로 쓴다. 업계에서 통용되는 시작점 가중치(자사 데이터로 분기마다 조정할 것):

| 기준 | 가중치(시작점) | 데이터 소스 예 |
|---|---|---|
| Firmographic 적합 | 25% | 기업 DB, DART, 홈페이지 |
| Technographic 적합 | 20% | BuiltWith류 도구, 채용공고의 기술 요건 |
| 서드파티 인텐트 시그널 | 15% | G2/리뷰 사이트 조회, 인텐트 데이터 |
| 자사 인게이지먼트 | 15% | 웹 방문, 콘텐츠 다운로드, 웨비나 참석 |
| 구매 트리거 | 10% | 투자 유치, 리더십 교체, 규제 이벤트 |
| 경제성 (예상 ACV/LTV) | 10% | 딜 크기 추정 모델 |
| Negative 시그널 | 5% (감점) | 배제 기준 근접 여부 |

주의: negative ICP의 **탈락 기준**(hard disqualifier)은 감점이 아니라 스코어링 이전 필터로 적용한다. 배제 규칙 도입으로 리드 볼륨 40% 감소, 승률 22% 상승 사례가 보고되어 있다(단일 사례이므로 방향성 참고).

### 2.5 ICP 문서 구조 (표준 템플릿)

ICP 문서는 팀 전체가 같은 그림을 보게 하는 계약서다. 아래 섹션을 갖춘다.

```
1. 한 줄 정의            "우리는 [속성]의 [산업] 기업이 [트리거] 상황일 때 가장 잘 판다"
2. Firmographic 기준     범위(하한~상한)와 sweet spot을 구분해 표기
3. Technographic 기준    필수 / 가점 / 배제 스택
4. 트리거·시그널 목록     우선순위 순 (§5의 시그널 분류 사용)
5. Negative ICP          탈락 기준(hard)과 감점 기준(soft) 구분
6. 구매위원회 맵          페르소나별 직함·페인·반대 논리 (§2.6)
7. 스코어링 룰            가중치와 티어 컷오프
8. 근거 데이터            이 ICP의 출처(closed-won 분석 일자, 표본 수)
9. 갱신 이력              분기 검증 결과와 변경 사항
```

갱신 주기: 분기 1회 정기 + 다음 이벤트 발생 시 수시(신제품 출시, 가격 개편, 신규 시장 진입, 승률 급변).

### 2.6 페르소나 설계: 구매위원회 중심으로

2025년 기준 B2B 구매위원회는 평균 9~11명(Gartner 2025 인용 보고, 2017년 5~7명에서 증가), 테크 구매는 14~23명까지 관여한다는 조사가 있다. "의사결정자 1명"을 찾는 모델은 폐기한다. 페르소나는 개인 프로필이 아니라 **역할 맵**으로 설계한다.

핵심 5+2 역할:

| 역할 | 전형적 직함(예) | 원하는 것 | 두려워하는 것 | 우리 메시지 |
|---|---|---|---|---|
| Champion (챔피언) | 실무 팀장, 시니어 실무자 | 문제 해결 + 내부 정치 자본 | 밀었다가 실패하는 것 | 내부 설득용 무기(수치, 사례, 데모) |
| Economic Buyer (예산 결정자) | 부서장, 임원, CFO | ROI, 예측 가능성 | 예산 낭비 책임 | 비즈니스 케이스, TCO, 회수 기간 |
| Technical Validator (기술 검증자) | IT/보안/엔지니어링 리드 | 안전한 통합, 낮은 운영 부담 | 보안 사고, 기술 부채 | 아키텍처, 보안 문서, 통합 명세 |
| User/Operator (실사용자) | 실무 담당자 | 일이 쉬워지는 것 | 배우기 어려운 도구 강요 | 사용성, 온보딩, 교육 |
| Procurement (구매/조달) | 구매팀, 법무 | 조건, 리스크 통제 | 불리한 계약 | 표준 계약, 레퍼런스, 컴플라이언스 |
| Executive Sponsor (임원 스폰서) | C레벨 | 전략 정합성 | 전략과 무관한 투자 | 전략 내러티브 1장 |
| Blocker (잠재 반대자) | 상황에 따라 다름 | 현상 유지 또는 대안 | 자기 영역 침식 | 조기 식별 + 중립화 논리 |

실무 규칙:
- 한 사람이 단계에 따라 챔피언·블로커·예산 결정자 역할을 겸하거나 바꿀 수 있다. 역할은 직함이 아니라 행동으로 판정한다.
- 거부권 보유자(보안·조달·재무) 3인 맵을 먼저 만들고, 실사용자 변형 페르소나는 분기마다 추가한다는 접근이 통용된다.
- 페르소나 문서에는 직함 목록, 핵심 KPI, 페인 포인트, 정보 소비 채널, 전형적 반대 논리와 대응을 담는다. "35세 김과장, 취미는 골프" 류의 서사형 페르소나는 만들지 않는다(실무 효용 없음).
- 한국 기업 적용 시 직급 체계를 반영한다: 실무 검토는 대리~과장, 챔피언은 과장~팀장, 예산은 팀장~임원(상무/전무), 최종 승인은 대표 또는 부문장 결재라인으로 흐르는 경우가 많다(일반화된 관행, 회사별 상이).

## 3. 리스트 빌딩: 데이터 소스

### 3.1 글로벌 데이터 소스 지형 (2025~2026)

단일 소스로 정확도·커버리지·최신성을 모두 만족하는 공급자는 없다는 것이 업계 합의다. 성과 상위 팀은 복수 소스를 순차 조회하는 **워터폴(waterfall)** 을 돌린다(§4.1).

| 도구 | 강점 | 약점/주의 | 이메일 유효율(보고치) |
|---|---|---|---|
| ZoomInfo | 북미 엔터프라이즈 커버리지 최강(5억 연락처·1억 기업 주장) | 고가, 북미 외 커버리지 약함 | ~87~90% |
| Apollo.io | 가성비, 2.75억 연락처, 검색+시퀀스 일체형 | 정확도 소폭 낮음, 한국 데이터 빈약 | ~85% |
| Cognism | EMEA, 전화 검증(phone-verified) 모바일 | 아시아 약함 | ~87~90% |
| Clay | 워터폴 인리치먼트·시그널 워크플로 허브 | 크레딧 과금이 빠르게 비싸짐, 학습 곡선 | 소스 조합에 따름 |
| People Data Labs / 기타 API | 원천 데이터 벌크 공급 | 자체 파이프라인 필요 | 소스별 상이 |
| LinkedIn Sales Navigator | 인물·직함·이동 추적의 사실상 표준 | 이메일 미제공, 한국 보급률 낮음(§8) | 해당 없음 |

이메일 유효율 수치는 각 벤더·리뷰 사이트 보고치로 마케팅 성격이 있다. 절대값보다 "어느 소스든 10% 내외는 죽은 데이터"라는 사실을 기억하는 것이 중요하다.

### 3.2 한국 시장 데이터 소스

글로벌 DB의 한국 커버리지는 빈약하다. 한국 리스트는 아래 소스를 조합해 직접 구축하는 것이 기본이다.

| 소스 | 얻는 것 | 용도 |
|---|---|---|
| **DART (전자공시시스템)** | 외감법인 재무제표, 사업보고서, 지배구조, 임원 현황 | firmographic 확정(매출·직원 수), 임원 변동 시그널 |
| **더브이씨 (THE VC)** | 국내 스타트업 투자 라운드·투자자 DB | 투자 유치 시그널, 성장 단계 필터 |
| **혁신의숲 (InnoForest)** | 스타트업 매출·고용·투자 추정, 소비자 거래 데이터 | 성장세 판별(고용 증가 = 채용 시그널 대체재) |
| **크레딧잡 / 국민연금 데이터 기반 서비스** | 기업별 직원 수·입퇴사 추이·평균 연봉 | 성장/축소 판별. 국민연금 가입자 수 증감은 한국판 headcount growth 시그널 |
| **잡코리아·사람인·원티드·점핏** | 채용공고(직무, 기술 요건, 조직 소개) | 채용 시그널 원천. 공고 본문의 기술 스택이 technographic 대체재 |
| **리멤버 (Remember)** | 500만 명함 기반 비즈니스 프로필, 세일즈리서치·타깃 광고 상품 | 한국판 인물 DB. 직무·직급 타기팅, 리드 확보 상품 |
| **넥스트유니콘·로켓펀치** | 스타트업 프로필, 팀 구성 | 초기 기업 발굴 보조 |
| **국가기관 DB (K-Startup, 벤처확인기관, 이노비즈 등)** | 인증 기업 목록 | 정책 자금·인증 기반 세그먼트 필터 |
| **홈페이지·뉴스룸·IR 자료** | 신사업, 조직 개편, 파트너십 | Tier 1 계정 심층 리서치 원천 |
| **협회 회원사 명부·전시회 참가사 목록** | 버티컬별 기업 리스트 | 산업 특화 리스트의 출발점(§8.4) |

실무 조합 예: "더브이씨에서 최근 18개월 시리즈 A+ 유치 기업 추출 → 혁신의숲/크레딧잡으로 고용 증가 확인 → 원티드에서 관련 직군 채용공고 확인 → DART·홈페이지로 임원·조직 확인 → 리멤버/서치로 인물 특정".

### 3.3 리스트 검증 (발송 전 게이트)

리스트는 만드는 것보다 거르는 것이 성과를 만든다. 발송 전 체크리스트:

- [ ] **이메일 검증 도구 통과**: ZeroBounce, NeverBounce, Prospeo 등으로 전량 검증. valid만 1차 발송 대상.
- [ ] **catch-all 분리**: catch-all 도메인 주소는 콜드 캠페인 본대에서 제외하거나 별도 저볼륨 트랙으로. 하드바운스 폭탄의 주범이다.
- [ ] **role 계정 제거**: info@, sales@, admin@ 등은 원칙 제외(답장률 낮고 신고율 높음).
- [ ] **중복·경합 제거**: 기존 고객, 진행 중 딜, 최근 90일 내 접촉 이력, 동료 담당 계정과 대조(suppression list).
- [ ] **negative ICP 필터 적용**: 탈락 기준 해당 계정은 점수와 무관하게 제거.
- [ ] **바운스 상한 설정**: 캠페인 바운스율 목표 2% 미만, 하드바운스 1% 미만. 5%에 도달하면 발송 중단하고 리스트를 재검증한다(딜리버러빌리티 전체가 무너진다, `02-deliverability.md` 참조).

### 3.4 데이터 위생 (상시 운영)

- B2B 연락처 데이터는 연 20~30% 부패한다는 것이 업계 통설이다. "검증일" 필드를 리스트 스키마에 넣고, 90일 지난 레코드는 재검증 전 발송 금지.
- 90일+ 무반응 연락처는 활성 시퀀스에서 제외(suppress)하고 분기별 재활성 캠페인으로 분리한다.
- 수신거부·반송·퇴사 확인 레코드는 삭제가 아니라 suppression 처리한다(같은 주소를 다른 소스에서 다시 사올 수 있기 때문).
- 리스트 스키마 최소 필드: 회사명, 도메인, 산업, 직원 수, ICP 점수, 티어, 인물명, 직함, 페르소나 역할, 이메일, 검증 상태, 검증일, 데이터 출처, 시그널(최신), 시그널 일자, 접촉 이력, 옵트인/거래관계 근거(한국 발송분, §8.2).

## 4. 인리치먼트와 워터폴

### 4.1 워터폴 인리치먼트

하나의 필드(예: 업무 이메일)를 여러 공급자에게 순차 조회해 첫 유효값을 채택하는 패턴. Clay가 대중화했다. 효과: 단일 소스 대비 커버리지(찾는 비율)가 유의하게 올라간다.

권장 순서 설계 원칙:
1. 저렴하고 정확한 소스 먼저, 비싼 소스는 뒤로(비용 최적화).
2. 각 단계 결과를 검증 도구로 확인 후 다음 단계로(오염 방지).
3. 최종 미발견 레코드는 버리지 말고 "전화·링크드인·소개 채널" 트랙으로 이관.

전형적 스택(영어권): Apollo(1차 DB) → Cognism(EU/전화) → Clay(워터폴 허브 + AI 리서치). 한국 타깃은 이 스택이 거의 작동하지 않으므로 §3.2 소스 + 수작업 특정이 현실적이다.

### 4.2 계정 레벨 인리치먼트 항목

인물 이메일만 채우는 것이 아니라 계정 레코드에 다음을 채워 티어링·개인화에 쓴다: 기술 스택(채용공고·홈페이지에서 추출), 최근 투자, 최근 임원 변동, 채용 중 직군 수, 뉴스 3건, 자사 제품과의 접점 가설.

## 5. 시그널 기반 아웃바운드

### 5.1 왜 시그널인가 (벤치마크)

| 방식 | 답장률(보고 구간) |
|---|---|
| 제네릭 콜드 (리스트에 뿌리기) | 1~5% |
| 시그널 1개 + 관련 가치 제안 | 15~25% (업계 통설) |
| 복수 시그널 스택(2~3개) + 페르소나 정합 | 25~40% (업계 통설, 상위 사례) |

"B2B 세일즈 인게이지먼트의 75%가 시그널 트리거에서 출발했다"는 2025년 조사 인용이 돌지만 모수가 불투명하다. 방향(시그널 우선주의)만 취한다.

### 5.2 시그널 분류표 (탐지 소스와 메시지 연결)

| 시그널 | 의미(가설) | 탐지 소스(글로벌 / 한국) | 유효 기간 | 메시지 연결 예 |
|---|---|---|---|---|
| **채용공고** (관련 직군) | 그 문제에 예산·의지가 생겼다. 공고의 기술 요건은 스택 정보 | LinkedIn Jobs, Indeed / 원티드·사람인·잡코리아·점핏 | 공고 게시~채용 완료(수주~수개월) | "X 직군을 채용 중이신데, 그 팀이 맡을 문제 중 Y는 저희가 단축해 드릴 수 있습니다" |
| **투자 유치** | 12~18개월 내 조직·인프라 투자 예산 존재 | Crunchbase / 더브이씨, 혁신의숲, 보도자료 | 발표 후 1~6개월이 골든타임(업계 통설) | 축하 인사가 아니라 "이 단계 기업들이 다음에 부딪히는 문제 Z" 프레임 |
| **임원 영입·승진** | 새 임원은 90일 내 성과를 만들려 한다. 전 직장에서 쓰던 도구를 다시 산다 | LinkedIn, UserGems류 / 보도자료, DART 임원 현황, 리멤버 | 부임 후 30~120일 | "새로 맡으신 어젠다에서 보통 첫 분기에 나오는 과제가..." |
| **챔피언 이직** (기존 고객 인물이 타사로) | 이미 우리를 아는 사람이 새 예산을 가짐 | UserGems, Clay job-change 모니터링 / 리멤버, 뉴스 | 이직 후 60~90일 | 재연결. 과거 챔피언 관여 딜은 승률 +114%, 딜 크기 +54%, 사이클 -12% 보고(UserGems 5,000건 분석) |
| **기술 스택 변화** | 마이그레이션·신규 도입은 보완재/대체재 구매 창 | BuiltWith, 채용공고 기술 요건 / 채용공고, 기술 블로그 | 수개월 | "A를 도입하셨다면 다음 병목은 보통 B입니다" |
| **규제·제도 이벤트** | 컴플라이언스 마감은 강제 트리거 | 규제기관 공지 / 금융위·개보위·과기부 고시, 시행일 | 시행일 역산 | "YYYY-MM 시행 전에 준비해야 할 3가지" |
| **신사업·시장 진출 발표** | 새 역량 필요, 기존 벤더 공백 | 보도자료, IR / 뉴스룸, DART 공시 | 1~6개월 | 해당 신사업의 구체 과제 언급 |
| **웹사이트·콘텐츠 행동** (1st party) | 능동적 탐색 중 | 방문 식별 도구, 폼, 웨비나 참석 | 며칠~2주(가장 뜨겁고 가장 짧다) | 24~48시간 내 관련 자료로 후속 |
| **리뷰 사이트 탐색** (3rd party intent) | 카테고리 비교 중 | G2, 인텐트 데이터 벤더 | 2~4주 | 비교 관점 콘텐츠 |
| **실적 발표·공시** | 우선순위가 문서로 공개됨 | 어닝콜 / DART 사업보고서·분기보고서 | 분기 | 보고서의 표현을 그대로 인용해 접점 제시 |

### 5.3 시그널 운영 원칙

1. **시그널 → 가설 → 메시지의 3단 변환을 지킨다.** 시그널을 언급만 하는 것("투자 유치 축하드립니다")은 개인화가 아니다. 시그널이 만드는 **문제 가설**을 제시해야 한다.
2. **신선도가 생명이다.** 시그널별 유효 기간(위 표)이 지나면 그 시그널로 접근하지 않는다. 특히 1st party 행동 시그널은 48시간 내 대응이 표준이다.
3. **복수 시그널 스택이 단일 시그널을 이긴다.** "투자 유치 + 관련 직군 채용 + 신임 임원" 3개가 겹친 계정은 자동으로 Tier 상향한다.
4. **시그널 모니터링을 자동화한다.** Clay의 job-change 모니터링, 채용공고 크롤링, 뉴스 알림(구글 알리미, 국내 뉴스 클리핑)을 워크플로에 넣고, 시그널 발생 시 계정 레코드에 (시그널, 일자, 출처)를 적재한다.
5. **과거 챔피언 추적은 별도 트랙으로 상시 운영한다.** 고객사 인물의 이직은 가장 승률 높은 시그널이다(§5.2 표).

## 6. 계정 리서치: 루틴과 아웃리치 연결

### 6.1 10분 계정 리서치 루틴 (Tier 1~2용)

목표: "왜 이 회사, 왜 지금, 왜 이 사람"에 답할 훅 1~2개. 완벽한 이해가 아니다. 10분을 넘기면 수확 체감한다.

| 시간 | 할 일 | 찾는 것 |
|---|---|---|
| 0~2분 | 홈페이지 + 뉴스룸/보도자료 | 사업 모델 한 줄 요약, 최근 발표(신사업·파트너십·수상) |
| 2~4분 | 채용 페이지(원티드·사람인·자사) | 채용 중 직군, 공고 속 기술 스택·조직 구조·우선순위 |
| 4~6분 | 재무·성장 확인(DART, 혁신의숲, 크레딧잡) | 매출·직원 수 추이, 투자 이력, 고용 증감 |
| 6~8분 | 타깃 인물 확인(리멤버·링크드인·기사 인터뷰) | 직함, 부임 시기, 공개 발언·인터뷰, 관심사 |
| 8~10분 | 종합: 가설 작성 | "이 회사는 지금 [시그널] 때문에 [문제]를 겪고 있을 것이고, [페르소나]가 [KPI] 압박을 받는다. 우리 접점은 [X]" |

산출물 형식(계정 레코드에 그대로 저장):

```
계정: ____ / 티어: __ / 일자: ____
시그널: [종류, 일자, 출처 링크]
가설: 이 회사는 지금 ___ 때문에 ___ 가 필요할 것이다
타깃 인물: 이름/직함/역할(챔피언·EB·검증자)
훅 1문장: (메일 오프닝에 그대로 쓸 문장)
배제 확인: negative ICP 해당 없음 (확인자)
```

### 6.2 리서치를 아웃리치에 연결하는 규칙

1. **훅은 오프닝 첫 문장에 쓴다.** 리서치했다는 사실을 자랑하는 문장("귀사 홈페이지를 보니...")이 아니라, 리서치 결과가 만든 관찰("X 직군을 세 자리나 채용 중이시더군요. 보통 이 단계에서 Y가 병목이 됩니다")로 시작한다. `01-cold-email-craft.md`의 첫 12단어 원칙과 결합.
2. **리서치 항목당 문장 하나만.** 찾은 것을 다 쓰면 스토커 메일이 된다. 가장 강한 훅 1개 + 예비 1개(후속 터치용).
3. **가설은 단정하지 않고 검증형으로 쓴다.** "~겪고 계실 겁니다"보다 "~가 다음 과제라고 짐작했는데, 맞는지요"가 답장을 만든다.
4. **리서치 없는 계정은 시퀀스에 넣지 않는다** (Tier 1~2 기준). Tier 3은 세그먼트 단위 리서치(§7.2)로 대체한다.
5. **리서치 유효 기간은 30일.** 그 이상 지난 가설로 발송하지 않는다(시그널 신선도 원칙과 동일).

### 6.3 시간 배분 벤치마크

- 개인(prospect) 단위 리서치: 2~3분 상한이 업계 권고(개인 단위는 훅 1개 찾기면 충분).
- 계정(account) 단위 리서치: Tier 1은 10분+(필요시 30분 딥다이브 별도), Tier 2는 5~10분, Tier 3은 계정 단위 생략하고 세그먼트 단위로.
- AI 리서치 에이전트를 쓰는 경우에도 위 산출물 형식(§6.1)을 강제하고, 훅 문장은 사람이 최종 검수한다. 환각 훅(존재하지 않는 보도 인용 등)은 신뢰를 영구 파괴한다.

## 7. 우선순위화: 계정 티어링

### 7.1 3티어 표준 모델

ICP 점수(§2.4) + 예상 딜 크기 + 시그널 강도로 컷오프를 정한다. 성숙한 ABM 조직 대부분이 3티어(1:1, 1:few, 1:many)를 쓴다.

| | Tier 1 (1:1) | Tier 2 (1:few) | Tier 3 (1:many) |
|---|---|---|---|
| 계정 수(담당자당) | 5~20 | 30~100 | 수백+ |
| 선정 기준 | ICP 최상위 + 대형 ACV + 강한 시그널 | ICP 적합 + 중형 ACV | ICP 기본 적합 |
| 계정 리서치 | 10분 루틴 + 딥다이브, 상시 모니터링 | 10분 루틴 1회 | 세그먼트 단위만 |
| 개인화 깊이 | 완전 맞춤: 계정 전용 자료·랜딩, 임원 스폰서십, 구매위원회 다인 커버 | 세미 맞춤: 산업/세그먼트 템플릿 + 계정 훅 1~2개 치환 | 템플릿 + 동적 치환(산업·직무·시그널 변수) |
| 채널 | 멀티스레드(메일+전화+소개+행사+DM) | 메일+전화+링크드인/리멤버 | 메일 시퀀스 중심 자동화 |
| 담당 | AE 주도, SDR 지원 | SDR 주도 | SDR/자동화 |
| 접촉 인원(계정당) | 3~5명+ (구매위원회 커버) | 2~3명 | 1~2명 |

### 7.2 티어별 개인화 차등의 원칙

- 개인화는 비용이다. 티어는 "개인화 예산 배분표"다. Tier 3에 Tier 1 수준 리서치를 하는 것도, Tier 1에 템플릿을 쏘는 것도 모두 배분 실패다.
- Tier 3의 개인화는 "세그먼트 정확도"로 달성한다: 같은 산업·같은 직무·같은 시그널 유형끼리 묶으면 템플릿이어도 관련성이 확보된다. 세그먼트당 최소 공통 시그널 1개를 강제한다.
- 티어는 고정이 아니다. 시그널 발생(투자, 임원 교체, 인바운드 행동) 시 자동 상향, 2분기 무반응·negative 판정 시 하향. 분기마다 티어 재배정 리뷰를 한다.
- 파이프라인 산식으로 역산해 티어 규모를 정한다: 목표 신규 매출 ÷ 평균 ACV = 필요 딜 수 ÷ 승률 = 필요 상담 수 ÷ 미팅 전환율 = 필요 접촉 계정 수. 이 수가 티어별 계정 수 합계와 맞아야 한다.

## 8. 한국 B2B 시장의 프로스펙팅 특수성

### 8.1 구조적 차이 요약

| 항목 | 영어권 | 한국 |
|---|---|---|
| 인물 DB | LinkedIn이 사실상 표준 | 링크드인 보급 낮음(점유 한 자릿수 %로 추정, 업계 통설). 리멤버 500만 프로필이 실질 대체재 |
| 이메일 규제 | 옵트아웃 기반(CAN-SPAM, 미국) | **옵트인 기반**(정보통신망법 제50조, §8.2) |
| 기업 데이터 | ZoomInfo·Apollo 등 상용 DB 풍부 | 상용 통합 DB 빈약. DART·더브이씨·혁신의숲·크레딧잡 조합으로 자체 구축 |
| 접근 문화 | 콜드 아웃리치 일상화 | 소개(referral)·대면 신뢰 중심. 콜드 접근의 심리적 장벽 높음 |
| 이메일 환경 | Gmail/Outlook | 네이버·다음 메일 비중 높음. 자체 스팸필터 대응 별도 필요(`02-deliverability.md`) |
| 의사결정 | 구매위원회, 분산 | 결재라인(품의) 중심, 위계적. 임원 승인 없이 실무선에서 안 움직이는 경우 많음 |

### 8.2 규제: 정보통신망법 제50조 (발송 전 법무 게이트)

한국 수신자에게 영리목적 광고성 정보를 전자적 매체(이메일 포함)로 보내려면 **명시적 사전 동의(옵트인)** 가 원칙이다. 위반은 과태료·형사처벌 대상.

실무에서 중요한 예외·경계(요지, 개별 캠페인은 법무 확인 필수):

- **거래관계 예외**: 재화·서비스 거래 과정에서 수신자로부터 직접 연락처를 수집한 경우, 거래 종료일부터 6개월 이내에는 같은 종류의 재화·서비스 광고를 사전 동의 없이 전송 가능.
- **명함 교부**: 사업자가 거래관계 형성을 위해 명함 등 서면으로 연락처를 직접 제공한 경우 사전동의 예외로서의 거래관계에 준해 볼 수 있다는 해석이 통용된다. 행사·미팅에서 받은 명함이 한국 콜드 아웃리치의 핵심 자산인 법적 이유다.
- 광고성 메일에는 (광고) 표기, 전송자 명시, 수신거부 수단 등 표시의무가 있으며, 수신거부 의사 표시 후 재전송은 금지된다.
- 순수한 개별 비즈니스 제안(1:1 거래 교섭)과 광고성 정보의 경계는 사안별 판단이 필요하다. **대량 발송 시퀀스는 광고성 정보로 취급된다고 전제하고 설계한다.**
- 따라서 리스트 스키마에 "수신 근거" 필드(옵트인 일자 / 명함 수령 일자·경위 / 거래관계)를 반드시 두고, 근거 없는 레코드는 이메일이 아닌 다른 채널로 돌린다.

### 8.3 한국형 채널 우선순위

이메일 옵트인 제약 때문에, 한국 프로스펙팅은 "이메일 리스트를 만드는 것"이 아니라 **"이메일을 보낼 수 있는 근거(명함·옵트인·거래관계)를 만드는 활동"** 이 상류 공정이 된다.

1. **소개(referral)**: 기존 고객·투자자·파트너 경유 소개가 최상위 채널. Tier 1 계정은 "누구를 아는가" 맵부터 그린다.
2. **행사·전시회·컨퍼런스**: 명함 확보 = 법적 접촉 근거 확보. 산업별 전시회 참가사 목록은 그 자체가 검증된 버티컬 리스트다.
3. **웨비나·콘텐츠 옵트인**: 상위 SaaS 기업 대부분이 웨비나를 리드 수집에 활용(상위 100대 SaaS 중 78개사 운영, 92%는 녹화본으로 상시 수집이라는 국내 보고 인용). 폼 제출 시 광고성 정보 수신 동의를 함께 받는 설계가 표준.
4. **리멤버 생태계**: 세일즈리서치·타깃 광고 등 500만 프로필 기반 상품으로 옵트인 리드를 만드는 경로.
5. **전화(대표번호 경유)**: 이메일 대비 규제 부담이 다르고, 한국 조직 문화에서 대표번호 → 담당 부서 연결이 여전히 작동한다. 단 전화 광고도 별도 규제가 있으므로 확인 필요.
6. **뉴스레터·커뮤니티**: 디스콰이엇, 커리어리, 아웃스탠딩 등 실무자 커뮤니티에서의 존재감이 인바운드 접점을 만든다(채널 지형은 변동이 빠르므로 분기 점검).

### 8.4 한국형 리스트 빌딩 순서 (표준 플로)

```
1. 버티컬 정의 (ICP)
2. 모집단 확보: 협회 명부 / 전시회 참가사 / DART 업종 필터 / 더브이씨 투자 목록
3. 시그널 필터: 혁신의숲·크레딧잡 고용 증감 + 원티드·사람인 채용공고
4. 계정 스코어링·티어링
5. 인물 특정: 리멤버, 뉴스 인터뷰, 회사 조직도 페이지, 링크드인(있는 경우)
6. 접촉 근거 확보 전략 배정: 소개 경로 / 행사 / 웨비나 초대 / 대표 채널
7. 근거 확보된 레코드만 이메일 시퀀스 투입, 나머지는 근거 생성 트랙
```

## 9. 운영 체크리스트 (에이전트팀 게이트)

### 9.1 신규 캠페인 착수 전

- [ ] ICP 문서 존재·최신(분기 내 갱신) 확인
- [ ] negative ICP 필터가 리스트에 적용되었는가
- [ ] 계정별 티어 배정과 티어별 개인화 수준이 계획에 명시되었는가
- [ ] Tier 1~2 계정 전건에 리서치 산출물(§6.1 형식)이 있는가
- [ ] 시그널 일자가 유효 기간(§5.2) 내인가
- [ ] 리스트 전량 이메일 검증 통과, 예상 바운스 2% 미만인가
- [ ] (한국 수신자) 레코드별 수신 근거 필드가 채워져 있는가, 경계 사안은 법무 확인을 받았는가
- [ ] suppression list(고객·진행 딜·수신거부) 대조 완료인가

### 9.2 분기 정기 리뷰

- [ ] closed-won/lost/churn 데이터로 ICP 기준별 예측력 검증, 가중치 조정
- [ ] 티어 재배정(상향/하향)
- [ ] 리스트 재검증(90일+ 레코드)과 부패율 측정
- [ ] 시그널별 답장률·미팅 전환율 비교, 저성과 시그널 폐기
- [ ] 데이터 소스별 유효율·비용 검토, 워터폴 순서 조정
