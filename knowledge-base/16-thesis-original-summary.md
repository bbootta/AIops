## 2. 실제 연구설계 — 갈래 11의 추정과 다름

**갈래 11이 추정한 Mankiw-Zeldes/BCG식 주주·비주주 구분 설계가 아니다.** 실제 논문은 **집계문제(aggregation problem)** 논문이다:

- **핵심 명제 (정리 1)**: 가구별 소비성장률의 AR 계수가 이질적일 때, 횡단면 집계(평균) 시계열의 자기상관은 개별 시계열 자기상관의 평균보다 크다 (ρ_I < ρ_A). 집계는 소비 시계열을 평활화하여 분산을 줄인다.
- **함의**: 총소비 자료는 소비위험을 과소측정 → CCAPM 검증 시 위험회피계수(RRA)가 과대추정된다. 따라서 개별가계 소비자료가 총소비 자료보다 적절하다.
- **이론 프레임**: Hall(1978) 임의보행 + Campbell-Deaton(1989) 과잉평활을 결합한 소비 과정 (근시안 계수 δ_i 포함 AR(1) 소비성장률), Lucas(1978) 교환경제 + CRRA + 오일러방정식, Mehra(2003) 내부해 (13) logE(R_e) − logR_f = γσ_x², Hansen-Jagannathan 하방경계.
- **문헌 좌표**: 갈래 07(소비 측정·집계편의, Savov 2011 직접 인용)과 갈래 05·06의 교차점. Monteiro(2007) "Reassessing the Equity Premium Puzzle Using Micro Data", BCG(2002), C-D(1996)를 미시데이터 실증의 선행으로 인용.

## 3. 데이터 (확정)

- **개별가계 소비**: 통계청 **도시가계조사(HIES)** 소비지출, 분기, 1993Q2~2002Q4. 6차 표본개편기(1993Q2~1997Q4) 1,200가구+, 7차(1998Q1~2002Q4) 700가구+ 를 분기 연속 추적. 1997Q4·1998Q1은 이상치로 제외, 가구 소비성장률 평균 ±3σ 밖 가구 제외, X-12-ARIMA 계절조정, CPI로 실질화, 로그차분.
- **수익률**: KOSPI(FnGuide) = 시장포트폴리오, **91일 CD 유통수익률** = 무위험이자율 대용치(은행 신용프리미엄 포함 한계 명시). 1993~1997 기간 초과수익률이 음수인 문제 있음.
- **비교 대상**: ① 개별가구 소비성장률(id) ② 횡단면평균 소비성장률(cr) ③ 1인당 총지출성장률(agg, 한국은행, 비내구재+서비스).

## 4. 방법론과 결과 (확정)

1. **AR 추정 (표 3.1)** — 집계문제의 실증 확인: 개별 AR 계수 평균은 음수(6차 약 −0.41, 7차 약 −0.23, 평균회귀)인데 횡단면 평균 시계열은 −0.05, +0.34로 상승. 분산은 0.08→0.0004, 0.15→0.0166으로 급감. 집계 수준이 높을수록 평활화 심화.
2. **M&P 추정치 (Mehra 2003 내부해, 표 4.1)** — 외환위기 이후 기간: 총지출 자료 RRA **약 542** (전형적 퍼즐) vs 미시 자료 **0.2 (개별)·2.41 (횡단면평균)** — 모형 허용 범위 내이며 HJ 하방경계 일부 충족. RRA가 집계수준에 비례.
3. **GMM 추정 (Hansen-Singleton 2단계, Newey-West 8분기 시차, 표 4.1)** — 외환위기 이후: 유의하고 J-검정 통과하나, 거시 자료 RRA는 음수, 개별가구 RRA는 0.00003으로 지나치게 0에 가까움 → 저자 스스로 "절반의 성공"으로 평가. 원인으로 짧은 시계열, 사후 수익률·CD금리 대용치 문제 지목.
4. **모의실험 (표 4.2)** — 6차·7차에서 가구를 하나씩 복원추출해 이어붙인 가상 시계열 1,000개로 GMM (가중행렬 시차 1~9년 조정): 모형 기각 없음, 추정치는 두 조사기간 값 사이. 집계 후 추정 RRA 상승은 시차 설정과 무관하게 유지. — 짧은 패널 극복용 **스플라이싱 부트스트랩**이라는 방법론 제안.

## 6. 저자가 명시한 한계와 후속 방향 (디벨롭의 출발점)

- 한계: ① 시계열이 짧다(기간당 약 19분기) ② 수익률 대용치 부적절(사후 KOSPI 수익률 음수 구간, CD 신용프리미엄) ③ GMM 추정치가 정량적으로 비합리적(0.00003) ④ 생애주기·가구특성 통제 없음 ⑤ 가중행렬 시차에 민감.
- 저자 제시 후속 방향: 모형 수정 / 변수 대용치 개선 / 추정방법 개선. 추가 조사기간 자료 확보 시 모의실험 기반 장기 추정 가능.

## 7. 로드맵 수정 지침 (12번 파일에 반영)

1. 논문의 실제 축은 **집계문제·측정**(갈래 07)이므로, 주주/비주주 구분(갈래 06 MZ/BCG 설계)은 "재현 대상"이 아니라 **저널 버전의 핵심 신규 확장축**이 된다.
2. 재현(Phase 1)의 대상이 구체화됨: 표 3.1(AR·집계문제), 표 4.1(M&P vs GMM), 표 4.2(모의실험). 데이터는 도시가계조사 1993~2002 + 가계동향조사(2003~)로 연장.
3. 신규성 주장이 이중화됨: (i) 원논문 자체가 "한국 개별가계 소비 CCAPM 검증"의 선행 (ii) 저널 버전은 집계문제 + 주주 구분 + 측정오차 견고화의 결합으로 차별화.
