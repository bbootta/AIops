# 메카 카멜레온 (Mecha Chameleon)

위장 잠입형 2D 아케이드 게임. 브라우저에서 `index.html`을 열면 바로 플레이할 수 있습니다 (의존성 없음, 단일 파일).

## 플레이 방법

전투 위장 기체 **CHM-05**를 조종해 헌터 드론 웨이브에서 살아남으세요.

- 헌터 드론은 당신이 **보이는 동안** 실드를 켜고 레이저를 쏩니다.
- **위장(Shift 홀드)** 하면 드론이 조준하지 못하고 실드를 내립니다 — 이때만 혀로 잡아먹을 수 있습니다.
- 혀를 쏘는 순간 위장이 풀리며 잠시 노출됩니다.
- 위장은 에너지를 소모합니다. 떠다니는 벌레봇을 먹어 에너지를 보충하세요.
- 웨이브의 헌터를 모두 먹으면 다음 웨이브가 시작됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| A / D 또는 ← → | 이동 |
| Space / W | 점프 |
| 마우스 클릭 | 혀 발사 (커서 방향) |
| Shift (홀드) | 위장 |
| R | 게임 오버 후 재시작 |

## 기술

HTML5 Canvas + Vanilla JS 단일 파일. 외부 라이브러리·에셋 없음 (효과음은 WebAudio 신스로 생성).
