# 마인크래프트 (브라우저 복셀 게임)

Three.js로 만든 마인크래프트 스타일 복셀 게임입니다. 별도 빌드나 설치 없이 `index.html` 하나로 실행됩니다.

## 실행 방법

```bash
cd minecraft
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 접속 후 화면을 클릭하면 시작됩니다.
(Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 회전 |
| Shift | 달리기 (비행 중에는 하강) |
| Space | 점프 / 수영 (비행 중에는 상승) |
| F | 비행 모드 토글 |
| 좌클릭 | 블록 부수기 |
| 우클릭 | 블록 설치 |
| 1 ~ 6 / 마우스 휠 | 블록 선택 (잔디·흙·돌·나무·나뭇잎·모래) |
| ESC | 일시정지 |

**모바일**: 왼쪽 가상 조이스틱으로 이동, 화면 드래그로 시점 회전, 오른쪽 버튼으로 점프(⤒)/부수기(⛏)/설치(▣), 핫바 슬롯은 터치로 선택.

## 기능

- 128×128 노이즈 기반 절차적 지형 (언덕, 호수, 모래 해변, 나무)
- 땅속 광석 — 돌 층에 석탄 광석, 깊은 곳에 철 광석이 섞여 생성
- 낮/밤 주기 — 해와 달이 하늘을 가로지르고, 밤에는 별이 뜨며, 우측 상단에 게임 내 시각 표시
- 떠다니는 구름
- 물 — 호수에서 수영 가능 (약한 중력, Space로 떠오르기), 물속 시야 효과, 물결 애니메이션, 물가에서 Space로 뭍에 오르기
- 블록 부수기/설치 — 조준한 블록 테두리 표시, 파괴 시 파편 파티클과 효과음 (WebAudio 합성)
- 체력 시스템 — 하트 10개, 낙하 데미지, 물속 산소 게이지와 익사, 시간 경과 자연 회복, 사망 시 리스폰
- 비행 모드 — F로 토글, Space 상승 / Shift 하강
- 모바일 터치 지원 — 가상 조이스틱, 드래그 시점, 터치 버튼
- 자동 저장 — 바꾼 블록·위치·체력·시각이 localStorage에 저장되어 새로고침해도 유지 (시작 화면에서 초기화 가능)
- 청크(16×16) 단위 렌더링으로 블록 편집 시 해당 청크만 다시 그림
- 복셀 DDA 레이마칭으로 블록 조준 (매 프레임 갱신해도 비용이 거의 없음)
- 중력·점프·충돌 처리가 있는 1인칭 플레이어
- 캔버스로 생성한 픽셀 텍스처 (외부 이미지 에셋 불필요)
