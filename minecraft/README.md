# 마인크래프트 (브라우저 복셀 게임)

Three.js로 만든 마인크래프트 스타일 복셀 게임입니다. 별도 빌드나 설치 없이 `index.html` 하나로 실행됩니다.

## 실행 방법

```bash
cd minecraft
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 접속 후 화면을 클릭하면 시작됩니다.
(Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 회전 |
| Shift | 달리기 (비행 중에는 하강) |
| Space | 점프 / 수영 (비행 중에는 상승) |
| F | 비행 모드 토글 |
| C | 제작 메뉴 |
| E | 인벤토리 화면 |
| M | 배경음악 켜기/끄기 |
| Q | 먹기 (가진 음식 중 가장 좋은 것 자동) |
| R | 활 (누르면 차지, 떼면 발사) / 슈트 중엔 레이저 |
| G | 🤖 변신 순환: 사람 → 아이언 → 🦾 헐크버스터 → 🔮 스트레인지 → 🌪 위더 스톰 |
| Z / X / B / N | 변신 종류별 바로가기: 🤖아이언 / 🦾헐크버스터 / 🔮스트레인지 / 🌪위더 스톰 (같은 키 다시 = 해제) |
| 0 | 🧍 사람으로 돌아가기 |
| Tab | 🎛 마우스 커서를 풀고 변신 아이콘을 크게 띄워 클릭으로 고르기 |
| V / 📷 | 3인칭 카메라 각도 전환 (뒤·멀리·좌우 어깨·정면) |
| 마우스 휠 (슈트 중) | 카메라 줌 |
| 좌클릭 (꾹) | 블록 캐기 / 동물·좀비 공격 |
| 우클릭 | 블록 설치 · 씨앗 심기 · 상자 열기 |
| 1 ~ 9 / 마우스 휠 | 핫바 9칸 슬롯 선택 (데스크톱) |
| ESC | 일시정지 |

> 🌍 오버월드는 608×608 블록입니다. 미니맵의 **주황 점**이 마을, **색깔 점**이 포탈 위치예요.
> 🚪 포탈은 **색으로 목적지가 정해집니다** — 🟢초록 오버월드 · 🔴빨강 네더 · 🟣보라 보이드 · 🟡금색 ⚔공성전. 각 맵 스폰 근처에 갈 수 있는 색 포탈이 모두 놓여 있고, 다이아 2개로 원하는 색을 제작해 어디든 설치할 수 있습니다.

> 데스크톱 핫바는 9칸(숫자키 1~9)으로 고정. 1인칭 시점에선 마우스로 핫바를 클릭할 수 없으므로, 음식은 **Q**, 활은 **R**로 슬롯 선택 없이 바로 사용합니다.
> 📱 **모바일 핫바는 칸 수 제한이 없습니다.** 숫자키가 없는 대신 쓸 수 있는 아이템 26종(설치 블록 전부 + 💣TNT·💥슈퍼·⚡번개·🌋지진 TNT + 음식 + 씨앗 + 활)이 모두 들어 있고, 아래 띠를 **좌우로 밀어(슬라이드)** 넘긴 뒤 칸을 **탭하면 선택**됩니다. 고른 칸은 자동으로 화면 가운데로 옮겨집니다.
> 핫바 칸 교체(데스크톱): **E**(인벤토리)를 열고 설치 가능한 블록(모래·나뭇잎·눈·네더랙 포함)을 누르면 지금 선택된 칸에 들어갑니다. 배치는 저장됩니다. 모바일은 이미 전부 들어 있어 교체가 필요 없습니다.
> 🎛 변신 아이콘 바: 화면 왼쪽 위(낮은 가로 화면에서는 위쪽 가운데)에 🧍🤖🦾🔮🌪 작은 아이콘이 항상 떠 있고, 지금 모습이 노란 테두리로 표시됩니다. 모바일은 아이콘을 바로 탭하면 변신하고, 데스크톱은 Z/X/B/N/0 핫키 또는 **Tab**으로 커서를 풀어 아이콘을 클릭합니다(빈 곳 클릭 시 닫힘).

**모바일**: 왼쪽 가상 조이스틱으로 이동, 화면 드래그로 시점 회전, 오른쪽 버튼으로 점프(⤒)/부수기(⛏)/설치(▣)/먹기(🍗)/활(🏹), 핫바 슬롯은 터치로 선택.

## 기능

- 128×128 노이즈 기반 절차적 지형 (언덕, 호수, 모래 해변, 나무)
- 땅속 광석 — 돌 층에 석탄 광석, 깊은 곳에 철 광석이 섞여 생성
- 낮/밤 주기 — 해와 달이 하늘을 가로지르고, 밤에는 별이 뜨며, 우측 상단에 게임 내 시각 표시
- 떠다니는 구름
- 물 — 호수에서 수영 가능 (약한 중력, Space로 떠오르기), 물속 시야 효과, 물결 애니메이션, 물가에서 Space로 뭍에 오르기
- 블록 부수기/설치 — 조준한 블록 테두리 표시, 파괴 시 파편 파티클과 효과음 (WebAudio 합성)
- 서바이벌 인벤토리 — 블록을 캐서 모아야 설치 가능, 핫바에 보유 수량 표시 (시작 지급: 횃불 2개)
- 채굴 시스템 — 좌클릭을 꾹 눌러 캐기, 블록별 캐는 시간, 4단계 균열 애니메이션
- 횃불 — 석탄 광석을 캐면 횃불 3개 획득, 설치하면 일렁이는 불빛이 밤을 밝힘 (가까운 횃불 5개에 실제 광원 배치)
- 동물 — 돼지와 양이 들판을 돌아다니고 한 칸 턱은 뛰어오름, 잡으면 고기 드롭 (우클릭으로 먹어 체력 +3)
- 좀비 — 밤에만 스폰되어 플레이어를 추격·공격, 해가 뜨면 소멸. 공격하면 넉백
- 제작 (C) — 나무→판자, 판자→횃불, 곡괭이(돌/광석 3배 속도)·검(공격력 2배) 제작
- 멀티 세이브 — 시작 화면에서 월드 1·2·3 선택, 슬롯마다 시드가 달라 서로 다른 지형
- 동굴과 다이아몬드 — 의사 3D 노이즈로 지하에 동굴을 굴착, 깊은 곳에 다이아몬드 광석(곡괭이로만 채광)
- 활/원거리 — 활과 화살 제작, 우클릭으로 발사, 블록·몹과 충돌 판정
- 🔮 닥터 스트레인지 — 변신 3단계. 붉은 망토가 속도에 따라 펄럭이는 마법사로, 좌클릭=주황 마법 미사일 연사, 우클릭=순간이동(조준 방향 최대 12칸), R=시간 정지(누르는 동안 모든 몹·투사체 정지, 초록 빛)
- 🌪 위더 스톰 변신 — 변신 4단계. 머리 셋 달린 괴수가 되어 둥실 떠다니며(둥실 부유 애니메이션), 좌클릭=폭발하는 스컬 연발(착탄 폭발), 우클릭=대형 미사일, R=보라 레이저, F=사방 10발 스컬 폭풍 필살기. 받는 피해 80% 감소
- 🤖 변신 슈트 — G(순환)·Z/X/B/N 핫키·화면 왼쪽 위 아이콘 탭으로 사람→아이언 슈트→🦾헐크버스터→🔮닥터 스트레인지→🌪위더 스톰 순환. 디테일한 박스 슈트(헬멧+금 페이스플레이트+발광 눈, 아크 코어, 어깨 갑주, 손바닥 리펄서, 금 부츠, 등 부스터)가 보이는 3인칭 시점으로 전환되고 보는 방향으로 자유 비행(빠를수록 앞으로 기울고 부스터 불꽃이 일렁임). 좌클릭=펄서 연사, 우클릭=미사일(폭발), R=레이저. 헐크버스터는 1.75배 거체로 느리지만 무기가 강력(펄서 5·미사일 반경3/피해10·피해 75% 감소)
- 3인칭 카메라 — V/📷 프리셋(뒤·멀리·좌우 어깨·정면)은 시작 각도이고, 이후 자유롭게 조정: 데스크톱은 Alt+마우스로 궤도 회전(상하 포함)·휠 줌, 모바일은 두 손가락 드래그로 궤도·핀치로 줌. 카메라 위치 스무딩, 블록에 가리면 자동으로 가까워짐
- 무기·부스터 연출 — 부스터 불빛+뒤로 흩날리는 불꽃 트레일, 펄서 총구 섬광·명중 시 하늘색 폭발+잔광, 미사일 연기 꼬리·화염구·폭발 섬광, 굵기가 고동치는 발광 레이저 빔+타격 스파크
- 농사 — 잔디를 캐면 씨앗 획득, 잔디/흙에 심어 시간이 지나면 밀로 자람, 밀 3개로 빵 제작(체력 +4)
- 다이아 장비 — 다이아 곡괭이(채광 5배 속도)·다이아 검(공격력 3) 제작
- 보스 — 밤에 드물게 등장하는 거대 좀비 군주(체력 40, 상단 체력바), 처치 시 다이아몬드 3개 드롭
- 스켈레톤 — 밤에 좀비와 함께 출몰, 거리를 두고 화살을 쏘는 원거리 적 (플레이어도 피격됨)
- 크리퍼 — 가까이 접근하면 부풀다 자폭, 주변 블록을 파괴하고 거리 비례 피해
- 거미 — 빠르게 추격하며 벽을 타고 오르는 근접 적
- 어둠 마법사 — 뾰족 모자의 원거리 적, 멀리서 보라 마법 구체를 던짐
- 화염 임프 — 네더 전용, 작고 빠르며 불덩이를 던짐
- 🐷 피글린 — 네더 전용, 금 벨트와 금검으로 무장한 돼지 전사. 빠르게 추격해 근접 공격하며, 처치하면 금 1개를 떨어뜨림. 처음 마주치면 업적 해금
- 🌍 **10배 넓어진 오버월드** — 192×192 → **608×608 블록**(면적 약 10배). 월드를 한 번에 만들지 않고 플레이어 주변 청크만 그때그때 생성·해제하는 스트리밍 방식이라 시작은 오히려 더 빠르고, 블록은 청크당 Uint8Array 한 덩어리로 저장해 메모리도 가볍습니다(청크당 12.5KB)
- 🏘 **마을** — 넓은 들판 곳곳(약 176블록 간격)에 마을이 생깁니다. 평탄한 잔디 광장, 십자 흙길, 지붕 얹은 **우물**, 창문과 문이 있는 **판자집 4~6채**, 횃불 **가로등**, 물길이 흐르는 **꽃밭**, 그리고 울타리로 둘러싼 **가축 우리**. 시작 지점 근처에도 반드시 하나 있어서 바로 찾아갈 수 있고, 미니맵에 주황색 점으로 표시됩니다
- 🧑‍🌾 **마을 주민** — 큼직한 코와 앞치마 차림으로 집 근처를 돌아다닙니다. 가까이 가면 인사를 건네고, 때리면 도망가며 아무것도 떨어뜨리지 않아요(주민은 지켜 주세요). 마을에 도착하면 업적 해금
- 🐮 **가축** — 우리 안에 소·돼지·양이 함께 살고, 우리 밖으로 나가지 않습니다. 야생 동물도 넓어진 월드에 맞춰 플레이어 주변에서 계속 나타나고 멀어지면 정리됩니다
- 🚪 **색깔 포탈** — 포탈마다 색이 곧 목적지(🟢오버월드/🔴네더/🟣보이드/🟡공성전). 도착하면 **왔던 곳 색깔의 귀환 오브**가 조금 떨어진 곳에 생겨 길을 잃지 않습니다
- ⚔ **공성전 맵 (수성)** — 금색 포탈로 입장. 평원 한복판의 **웅장한 대성채**를 지키는 역할입니다: 101×101 크기(예전의 약 10배), **두께 2·높이 10의 바깥 성벽**과 흉벽, **높이 19의 모서리 대탑 4개**, 성문루가 선 남쪽 성문, 성벽 위를 걷는 통로와 사방의 계단, 안쪽에는 **내성(높이 6, 작은 탑 4개)**, 안뜰 횃불 기둥. 중앙 단상의 **🏰 성채 코어**(체력 400, HUD에 표시)를 지켜야 하고, 성 안 **보급 상자 4개**에 화살·빵·TNT·돌벽돌이 들어 있습니다. 성벽이 부서지면 돌벽돌로 다시 쌓아 막을 수 있어요
- 🪖 **공성군 10종** — 웨이브마다 사방에서 몰려옵니다: ⚔검병 · 🛡방패병(체력 12) · 🏹궁수(원거리) · 🪓파괴병(성벽 파괴 특화) · 💣폭탄병(성벽에 붙어 자폭) · 🔥화염술사(불덩이) · 🐗멧돼지 기병(빠른 돌격) · 🗿공성 골렘(체력 34·거체) · 🦅비행 정찰병(성벽을 넘어 날아옴) · 👑공성 대장(3웨이브마다 등장, 부하 소환). 막히면 성벽을 도끼로 부수고 들어옵니다
- 🌊 **웨이브** — 한 웨이브에 **100명**이 사방에서 몰려옵니다(끊김 없이 조금씩 전장에 진입). 전멸시키면 화살 40·빵 4·TNT 4·다이아 1 보상 후 15초 뒤 다음 웨이브. 코어가 무너지면 잃는 것 없이 1웨이브부터 다시 시작합니다(아이 배려). 3·5웨이브 방어 시 업적 해금
  - 100명이 동시에 뛰어도 가볍도록, 병사 한 명을 **한 덩어리 메시(정점 색)로 미리 구워** 재사용합니다 — 병사 1명 = 오브젝트 1개
- 🌪 **거대 위더 스톰**(적) — 오버월드 밤에 등장하는 초대형 보스(HP 600). 몸집을 **8배(약 44블록 높이 — 하늘을 뒤덮는 크기)** 로 키웠습니다. 지면 가까이 떠서 몸통이 시야를 가득 채우고, 폭발 스컬 3연발에 더해 **굵기 8칸의 대형 보라 광선**(나무보다 두꺼움)을 12초마다 발사합니다. 0.6초 충전 경고 후 발사되며, 조준이 천천히 따라오니 뛰어서 피할 수 있고, 지나간 자리는 지형이 통째로 갈려 나갑니다. ※ 플레이어가 변신하는 🌪 위더 스톰 슈트 크기는 **그대로**입니다

## 검증

`node`로 THREE·DOM을 모킹한 스모크 테스트를 돌려, 구문 검사로는 못 잡는 런타임 오류가 없는지 확인합니다(월드 생성, 청크/몹/작물, 채굴·설치 전 분기, 제작·인벤토리, 실제 물리로 포탈→네더 전이까지 실행).

```bash
node minecraft/smoke-test.cjs
```

다만 실제 WebGL 렌더링 화면 검증은 브라우저에서 직접 확인이 필요합니다.
- 체력 시스템 — 하트 10개, 낙하 데미지, 물속 산소 게이지와 익사, 시간 경과 자연 회복, 사망 시 리스폰
- 허기 시스템 — 허기바(🍗)가 이동·달리기로 소모, 음식으로 회복, 허기가 충분할 때만 체력 자연 회복, 0이면 굶주림 피해
- 비행 모드 — F로 토글, Space 상승 / Shift 하강
- 모바일 터치 지원 — 가상 조이스틱, 드래그 시점, 터치 버튼
- 자동 저장 — 바꾼 블록·위치·체력·시각이 localStorage에 저장되어 새로고침해도 유지 (시작 화면에서 초기화 가능)
- 청크(16×16) 단위 렌더링으로 블록 편집 시 해당 청크만 다시 그림
- 복셀 DDA 레이마칭으로 블록 조준 (매 프레임 갱신해도 비용이 거의 없음)
- 중력·점프·충돌 처리가 있는 1인칭 플레이어
- 캔버스로 생성한 픽셀 텍스처 (외부 이미지 에셋 불필요)
