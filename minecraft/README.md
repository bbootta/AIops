# 마인크래프트 (브라우저 복셀 게임)

Three.js로 만든 마인크래프트 스타일 복셀 게임입니다. 별도 빌드나 설치 없이 `index.html` 하나로 실행됩니다.

## 실행 방법

```bash
cd minecraft
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 접속 후 화면을 클릭하면 시작됩니다.
(Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 회전 |
| Shift | 달리기 (비행 중에는 하강) |
| Space | 점프 / 수영 (비행 중에는 상승) |
| F | 비행 모드 토글 |
| C | 제작 메뉴 |
| E | 인벤토리 화면 |
| M | 배경음악 켜기/끄기 |
| Q | 먹기 (가진 음식 중 가장 좋은 것 자동) |
| R | 활 (누르면 차지, 떼면 발사) |
| 좌클릭 (꾹) | 블록 캐기 / 동물·좀비 공격 |
| 우클릭 | 블록 설치 · 씨앗 심기 · 상자 열기 |
| 1 ~ 9 / 마우스 휠 | 핫바 9칸 슬롯 선택 |
| ESC | 일시정지 |

> 핫바는 9칸(숫자키 1~9)으로 고정. 1인칭 시점에선 마우스로 핫바를 클릭할 수 없으므로, 음식은 **Q**, 활은 **R**로 슬롯 선택 없이 바로 사용합니다.

**모바일**: 왼쪽 가상 조이스틱으로 이동, 화면 드래그로 시점 회전, 오른쪽 버튼으로 점프(⤒)/부수기(⛏)/설치(▣)/먹기(🍗)/활(🏹), 핫바 슬롯은 터치로 선택.

## 기능

- 128×128 노이즈 기반 절차적 지형 (언덕, 호수, 모래 해변, 나무)
- 땅속 광석 — 돌 층에 석탄 광석, 깊은 곳에 철 광석이 섞여 생성
- 낮/밤 주기 — 해와 달이 하늘을 가로지르고, 밤에는 별이 뜨며, 우측 상단에 게임 내 시각 표시
- 떠다니는 구름
- 물 — 호수에서 수영 가능 (약한 중력, Space로 떠오르기), 물속 시야 효과, 물결 애니메이션, 물가에서 Space로 뭍에 오르기
- 블록 부수기/설치 — 조준한 블록 테두리 표시, 파괴 시 파편 파티클과 효과음 (WebAudio 합성)
- 서바이벌 인벤토리 — 블록을 캐서 모아야 설치 가능, 핫바에 보유 수량 표시 (시작 지급: 횃불 2개)
- 채굴 시스템 — 좌클릭을 꾹 눌러 캐기, 블록별 캐는 시간, 4단계 균열 애니메이션
- 횃불 — 석탄 광석을 캐면 횃불 3개 획득, 설치하면 일렁이는 불빛이 밤을 밝힘 (가까운 횃불 5개에 실제 광원 배치)
- 동물 — 돼지와 양이 들판을 돌아다니고 한 칸 턱은 뛰어오름, 잡으면 고기 드롭 (우클릭으로 먹어 체력 +3)
- 좀비 — 밤에만 스폰되어 플레이어를 추격·공격, 해가 뜨면 소멸. 공격하면 넉백
- 제작 (C) — 나무→판자, 판자→횃불, 곡괭이(돌/광석 3배 속도)·검(공격력 2배) 제작
- 멀티 세이브 — 시작 화면에서 월드 1·2·3 선택, 슬롯마다 시드가 달라 서로 다른 지형
- 동굴과 다이아몬드 — 의사 3D 노이즈로 지하에 동굴을 굴착, 깊은 곳에 다이아몬드 광석(곡괭이로만 채광)
- 활/원거리 — 활과 화살 제작, 우클릭으로 발사, 블록·몹과 충돌 판정
- 농사 — 잔디를 캐면 씨앗 획득, 잔디/흙에 심어 시간이 지나면 밀로 자람, 밀 3개로 빵 제작(체력 +4)
- 다이아 장비 — 다이아 곡괭이(채광 5배 속도)·다이아 검(공격력 3) 제작
- 보스 — 밤에 드물게 등장하는 거대 좀비 군주(체력 40, 상단 체력바), 처치 시 다이아몬드 3개 드롭
- 스켈레톤 — 밤에 좀비와 함께 출몰, 거리를 두고 화살을 쏘는 원거리 적 (플레이어도 피격됨)
- 크리퍼 — 가까이 접근하면 부풀다 자폭, 주변 블록을 파괴하고 거리 비례 피해
- 거미 — 빠르게 추격하며 벽을 타고 오르는 근접 적
- 미니맵 — 우측 상단에 위에서 본 지형과 주변 몹·플레이어 위치 표시
- 소 — 돼지·양에 이어 세 번째 동물
- 네더 차원 — 다이아 5개로 포탈을 제작·설치하고 들어가면 네더(네더랙·용암 호수·붉은 하늘)로 이동, 도착 지점에 귀환 포탈 생성. 용암은 닿으면 피해, 적이 더 많이 출몰
- 인벤토리 화면(E) — 보유 아이템 수량과 제작한 도구, 현재 차원을 한눈에 표시
- 몹 체력바 — 피해를 입은 동물·좀비·스켈레톤 머리 위에 빌보드 체력바 표시
- 배경음악(M) — WebAudio로 생성하는 펜타토닉 앰비언트(차원별 음색), 켜기/끄기 설정 저장
- 설정 메뉴 — 시작/일시정지 화면에서 마우스 감도·음량·시야 거리·음악·일시정지 시 시간 정지를 조절(localStorage 저장)
- 어린이 친화 조작 — 터치 버튼 확대 + 한글 라벨(점프/캐기/놓기/먹기/활/만들기), 자동 점프(기본 켬, 한 칸 턱 자동 오르기), 🧒 평화 모드(몬스터·배고픔·데미지 없음, 체력 빠른 회복)
- 첫 실행 튜토리얼 — 걷기→둘러보기→캐기→놓기→만들기 5단계를 말풍선으로 안내(실제 행동을 감지해 진행, 말풍선을 누르면 건너뛰기, 완료하면 다시 안 나옴)
- 실수 방지 — 월드 초기화는 3초 안에 두 번 눌러야 실행
- 조이스틱 크기 — 설정에서 90~160px로 조절(아이 손 크기에 맞춤)
- 활 차지 샷 — 활 선택 후 우클릭을 길게 누르면 화살이 충전되어, 떼는 순간 충전량만큼 더 빠르고 강하게 발사
- 음식 확대 — 나뭇잎에서 사과, 잔디에서 버섯이 가끔 드롭, 버섯 3개로 버섯 스튜(허기 +7) 제작
- 방어구 — 철 광석에서 철 획득, 철 5개로 철 갑옷(피해 30%↓)·다이아 8개로 다이아 갑옷(60%↓) 제작, HUD에 방패 표시
- 상자 — 판자 8개로 제작·설치, 우클릭으로 열어 아이템 보관/회수(차원별 저장), 캐면 내용물 회수
- 바이옴 — 저주파 노이즈로 평원·사막(모래·나무 없음)·눈(눈 지표) 영역 생성, 미니맵에도 반영
- 금·에메랄드 광석 — 깊은 층에 추가, 곡괭이로 채광. 금 5개로 황금 사과(체력 가득 회복) 제작
- 더 넓어진 동굴 — 굴착 임계값을 낮춰 탐험 공간 확대
- 멀티 세이브는 차원별 상태(오버월드/네더 지형·위치)를 각각 저장

## 검증

`node`로 THREE·DOM을 모킹한 스모크 테스트를 돌려, 구문 검사로는 못 잡는 런타임 오류가 없는지 확인합니다(월드 생성, 청크/몹/작물, 채굴·설치 전 분기, 제작·인벤토리, 실제 물리로 포탈→네더 전이까지 실행).

```bash
node minecraft/smoke-test.cjs
```

다만 실제 WebGL 렌더링 화면 검증은 브라우저에서 직접 확인이 필요합니다.
- 체력 시스템 — 하트 10개, 낙하 데미지, 물속 산소 게이지와 익사, 시간 경과 자연 회복, 사망 시 리스폰
- 허기 시스템 — 허기바(🍗)가 이동·달리기로 소모, 음식으로 회복, 허기가 충분할 때만 체력 자연 회복, 0이면 굶주림 피해
- 비행 모드 — F로 토글, Space 상승 / Shift 하강
- 모바일 터치 지원 — 가상 조이스틱, 드래그 시점, 터치 버튼
- 자동 저장 — 바꾼 블록·위치·체력·시각이 localStorage에 저장되어 새로고침해도 유지 (시작 화면에서 초기화 가능)
- 청크(16×16) 단위 렌더링으로 블록 편집 시 해당 청크만 다시 그림
- 복셀 DDA 레이마칭으로 블록 조준 (매 프레임 갱신해도 비용이 거의 없음)
- 중력·점프·충돌 처리가 있는 1인칭 플레이어
- 캔버스로 생성한 픽셀 텍스처 (외부 이미지 에셋 불필요)
