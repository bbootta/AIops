# RYNTA Bifrost 화면 잠금판 (Framer 코드 컴포넌트)

- 목적: RYNTA Bifrost 적용 전후 화면 (미적용·적용 단추 한 페이지)을 rynta.io 페이지에 올리되, 비밀번호를 넣은 사람만 화면이 열리게 함 (2026-10-26)
- 방식
  - 화면 HTML 문서를 gzip으로 줄인 뒤 AES-256-GCM으로 암호화해 Framer 코드 컴포넌트 `BifrostScreenLocked`에 담음. 키는 비밀번호에서 PBKDF2-SHA256 600,000회로 만듦
  - 방문자가 비밀번호를 넣으면 브라우저 안 (Web Crypto, DecompressionStream)에서만 풀어 iframe (srcdoc)으로 표시. 비밀번호 없이는 페이지 소스로도 화면 내용을 볼 수 없음
  - 비밀번호 입력은 대소문자·공백·하이픈 차이를 무시하고 O는 0, I·L은 1로 읽음
  - Framer 기본 비밀번호는 사이트 전체에만 걸려 쓰지 않음. 마켓 잠금 부품은 내용이 페이지 소스에 남아 쓰지 않음
- 파일
  - `build_locked.mjs`: 생성기. `node build_locked.mjs <화면 HTML> <출력 TSX> <비밀번호 파일>`. 비밀번호 파일이 없으면 새로 만들고 (Crockford base32 12자), 있으면 그 비밀번호를 씀. 같은 키로 풀어 원문과 바이트 대조하는 자체 점검 포함
  - `BifrostScreenLocked_v0.8.1.tsx.txt`: 화면 v0.8.1 잠금판. Framer 코드 파일에 내용 전체를 붙여 넣어 사용 (암호문만 포함)
- 이 저장소는 공개이므로 비밀번호와 화면 원본은 두지 않음
- Framer 배치: 빈 페이지에 컴포넌트 하나, 너비 Fill (100%), 높이 100vh. 페이지 설정에서 검색엔진·사이트 검색 노출 끔
- 게시 후 확인: 페이지 HTML과 불러오는 스크립트에 화면 문구가 평문으로 0건, 잠금 화면 표시, 비밀번호로 열림
- 한계: 비밀번호 하나를 함께 쓰므로 사람별 열람 기록·회수는 없음. 비밀번호를 바꾸려면 다시 만들어 게시. 화면의 수치는 모두 합성 데이터
