# RYNTA RiskOps — 민간협의체 IR 피칭 요약

제12회 금융회사–핀테크 기업 상호만남(Meet-Up) | 금융회사 실무진 대상 원라인에이아이 | 2026-08-06

## 한 줄 정의

**RYNTA RiskOps — 숫자는 엔진이, 문장은 에이전트가, 판단은 사람이.** 금융회사의 리스크모형 검증·감리 업무를 자동화하되, 최종 판단 권한과 책임은 사람에게 남기는 AI 에이전트 플랫폼입니다.

## 왜 지금인가

리스크 검증 업무는 **매년 반복되는 정량 재계산**과 **그 결과를 정리한 문서 작성**으로 구성됩니다. 두 작업 모두 담당자의 개인 역량과 개인 PC에 의존하며, 감독당국이 근거를 요구하면 자료를 다시 모아야 합니다. 담당자가 바뀌면 절차가 사라집니다.

한편 범용 LLM을 그대로 쓰면 **수치가 틀리고 재현이 안 됩니다.** 금융회사 리스크 부서가 AI 도입을 망설이는 이유가 여기 있습니다.

## 우리의 답

| 층위 | 담당 | 이유 |
| :-: | :-: | :-: |
| 계산 | **결정론 엔진** (LLM 미사용) | 같은 입력 → 항상 같은 출력. 재현·검증 가능 |
| 정리·초안 | **AI 에이전트 (AVI·ARI)** | 근거 수집, 문서 초안, 미비사항 목록 |
| 판단 | **사람 + 4-Eyes 승인** | 승인 없이는 어떤 산출물도 확정되지 않음 |
| 기록 | **Evidence Ledger** | 입력·버전·판정·승인 이력 불변 기록 |

## 위탁테스트로 무엇을 하려는가

**요청**: 리스크모형 **1~2개**에 대해, 귀사의 기존 수기 검증과 **병행 운영(parallel run)** 하는 3~6개월 테스트

**성공 기준은 우리가 아니라 귀사가 판단합니다**

| 지표 | 목표 | 측정 주체 |
| :-: | :-: | :-: |
| 기존 산출값과의 오차 | **0건** | 귀사 검증 담당자 |
| 모형 1개당 검증 소요일 | 50% 이상 단축 | 공동 측정 |
| 감사추적 완결률 | 100% | 귀사 감사 부서 |
| 4-Eyes 미준수 건수 | 0건 | 시스템 로그 |

**데이터는 나가지 않습니다** — 내부망 온프레미스 배포, 가명처리 또는 비반출 처리. 당사는 원본 데이터를 보유하지 않습니다.

**신규 규제 특례가 필요 없습니다** — 현행 법령 내 내부 업무 지원 도구로 즉시 시행 가능합니다.

## 우리가 다른 점

만든 사람이 **검증받는 쪽이 아니라 검증하는 쪽**에 있었습니다. 은행 리스크감리팀에서 적합성검증·여신감리를 직접 수행하며 IRRBB(ΔEVE·ΔNII), ICAAP, 위기상황분석, PD·LGD·EAD 검증, 외부감사·감독당국 보고를 담당한 실무 경험이 제품 요건에 그대로 들어가 있습니다. 금융 데이터·리스크모형 분야 약 10년.
