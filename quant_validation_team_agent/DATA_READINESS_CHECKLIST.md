# 데이터 준비성 및 Lineage 체크리스트

## 1. 목적

정량검증 착수 전 데이터, 권한, 표본, lineage, 증적의 준비성을 확인해 계산엔진 결과의 재현성과 감사 가능성을 확보한다.

## 2. 공통 가정 및 Gray 원칙

- 데이터 부족, 표본 부족, 권한 부족, lineage 불명확, 증적 부족은 `Gray`다.
- 준비성 점검은 수치 계산이 아니라 증적 완결성 확인이다.
- 데이터 준비성이 `Gray`이면 정량 결론 단계로 진행하지 않고 Action Notice를 생성한다.

## 3. 체크리스트

| 점검항목 | 필요 증적 | 충족 여부 | 이슈 | 판정 영향 | 후속조치 |
|---|---|---|---|---|---|
| 데이터 소유부서 | 데이터 오너, 담당자, 승인 경로 | Y/N/NA |  | 소유부서 불명확 시 Gray | 오너 확인 및 승인 요청 |
| 기준일 | 추출 기준일, 관측기간, 보고 기준일 | Y/N/NA |  | 기준일 불명확 시 Gray | 기준일 재확인 |
| 추출 조건 | SQL, ETL 설정, 필터 조건, 제외 기준 | Y/N/NA |  | 추출 조건 부재 시 Gray | 추출 로직 제출 |
| 모집단 정의 | 대상 포트폴리오, 상품군, 등급, default 정의 | Y/N/NA |  | 모집단 불명확 시 Gray | 모집단 정의서 제출 |
| 표본 수 | 세그먼트별 표본 및 사건 수 산출물 | Y/N/NA |  | 표본 부족 시 Gray | 기간 확장 또는 pooling 검토 |
| 결측률 | 결측 현황 계산엔진 산출물, 처리 정책 | Y/N/NA |  | 결측 근거 부족 시 Gray | 결측 처리 승인 근거 제출 |
| 이상치 처리 | 이상치 기준, 처리 전후 로그, 승인 근거 | Y/N/NA |  | 이상치 임의 처리 시 Yellow/Gray | 처리 정책 검토 |
| Lineage | 원천계-중간계-계산엔진 매핑, ETL 로그 | Y/N/NA |  | lineage 불명확 시 Gray | 매핑표와 로그 제출 |
| 권한 | 접근권한 승인, 반출 승인, 마스킹 정책 | Y/N/NA |  | 권한 부족 시 Gray | 권한 승인 또는 대체 증적 요청 |
| 증적 | 파일 목록, 버전, 해시, 실행 로그, 승인 문서 | Y/N/NA |  | 증적 부족 시 Gray | 증적 패키지 보완 |
| 재현 가능성 | 입력 데이터 ID, 코드/엔진 버전, 파라미터 파일 | Y/N/NA |  | 재현 불가 시 Gray | 재실행 가능한 패키지 제출 |
| 데이터 품질 이슈 이력 | 과거 DQ 이슈, 조치 현황, 미해결 이슈 | Y/N/NA |  | 미해결 중대 이슈 시 Yellow/Red/Gray | 조치 상태 확인 |

## 4. Gray 사례 라이브러리

| 사례명 | 입력상황 | 사용 가능한 증적 | 부족한 증적 | 판정 후보 | Action Notice | 인간 검증자 확인사항 |
|---|---|---|---|---|---|---|
| 데이터 부족 | PD 검증기간 중 일부 월 데이터 누락 | 일부 월별 파일 | 누락 월의 원천 데이터 또는 제외 승인 | Gray | 필요 | 누락 영향과 재추출 가능성 |
| 표본 부족 | 특정 등급 default 표본이 매우 적음 | 등급별 표본 요약 | pooling 기준 또는 기간 확장 근거 | Gray | 필요 | 대체 검증방법 허용 여부 |
| 권한 부족 | 담보 회수자료 접근권한 없음 | LGD 방법론 | 회수현금흐름 원천 또는 대체 공식 리포트 | Gray | 필요 | 권한 승인 또는 대체 증적 인정 여부 |
| Lineage 불명확 | 계산엔진 입력과 원천계 매핑 부재 | 계산 결과 파일 | ETL 경로, 추출쿼리, 변환로직 | Gray | 필요 | 재현성 확보 전 검토 중지 여부 |
| 증적 부족 | 숫자 결과만 있고 실행 로그 없음 | 결과 PDF | 엔진 버전, 입력 데이터 ID, 파라미터 파일 | Gray | 필요 | 결과 신뢰성 판단 가능 여부 |

## 5. 완료 기준

- 모든 필수 항목의 Y/N/NA와 이슈가 기록되어야 한다.
- N이 하나라도 있고 공식 보완 근거가 없으면 `evidence_gaps`에 기록한다.
- Gray 조건에 해당하면 `provisional_judgement = Gray`, `required_action_notice = true`로 핸드오프한다.
