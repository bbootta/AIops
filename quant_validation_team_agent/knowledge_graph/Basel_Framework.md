# Basel Framework

The Basel Framework is the primary consolidated reference point for Basel
standards used by the validation package. It anchors credit, market, liquidity,
IRRBB, supervisory review, disclosure, and data-governance controls.

Related nodes: [[Regulatory_Source_Control]], [[Korean_Supervisory_Rules]],
[[Credit_Rating_System]], [[Market_Risk_FRTB]], [[IRRBB]],
[[Liquidity_Risk_LCR_NSFR]], [[BCBS_239_Data_Aggregation]].

Validation impact:

- The framework source identifies the international standard family.
- Domestic applicability and internal adoption are separate control checks.
- Framework references should be mapped to local policy and engine evidence
  before Green is allowed.
