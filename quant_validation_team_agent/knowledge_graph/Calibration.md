# Calibration

Calibration compares model or parameter outputs with observed outcomes and
approved target levels.

Related nodes: [[PD]], [[LGD]], [[EAD]], [[Default_Definition]],
[[Backtesting]], [[Discriminatory_Power]], [[Risk_Data_Lineage]].

Validation impact:

- Calibration evidence requires observation period, population, bin or grade
  mapping, and threshold policy.
- Sparse samples should be escalated through evidence-gap handling.
- Conflicting calibration outputs require reviewer resolution, not automated
  averaging.
