# Domestic Data BOK ECOS

BOK ECOS is a domestic macroeconomic and financial time-series source used for
macro variables, interest rates, exchange rates, and other economic indicators.

Related nodes: [[Korea_Macro_Financial_Data_Map]], [[Downturn_Adjustment]],
[[Stress_Testing]], [[IRRBB]], [[EVE_NII]], [[Risk_Data_Lineage]].

Validation impact:

- Series code, extraction timestamp, vintage, and transformation rules must be
  stored.
- ECOS data supports scenarios and validation evidence but does not replace
  approved engine results.
- Revised macro series should trigger source-version review.
