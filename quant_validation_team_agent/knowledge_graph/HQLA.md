# HQLA

High-quality liquid assets are the liquidity buffer used in LCR monitoring. The
validation focus is eligibility, haircut treatment, encumbrance, operational
availability, and source evidence.

Related nodes: [[Liquidity_Risk_LCR_NSFR]], [[Domestic_Data_KOFIA_Bond]],
[[Domestic_Data_KRX]], [[Risk_Data_Lineage]], [[Regulatory_Source_Control]].

Validation impact:

- Asset eligibility must be evidenced, not inferred from security type alone.
- Encumbrance and operational availability need system evidence.
- Missing HQLA evidence maps to Gray.
