# Korean Supervisory Rules

Korean supervisory rules connect Basel concepts to domestic bank-supervision
requirements, stress testing, and ICAAP review expectations.

Related nodes: [[Regulatory_Source_Control]], [[Basel_Framework]],
[[Credit_Rating_System]], [[PD]], [[LGD]], [[EAD]], [[Stress_Testing]],

Validation impact:

- Domestic rule references should be stored as source IDs and exact policy
  versions.
- If domestic rule evidence and Basel source evidence conflict, the agent raises
  a reviewer issue instead of choosing a rule.
- Local approval conditions are part of source control, not optional context.
