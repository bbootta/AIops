# 자산 목록

점검 대상 자산의 등록부. **여기 등재되고 권한이 확인된 자산만 점검한다.**

갱신 규칙: 신규 자산 추가·폐기 시 즉시 반영. 주간 모니터링 1단계에서
최신 여부를 확인한다.

## 로컬 머신

| 자산 ID | 설명 | OS/버전 | 소유 확인 | 중요도 | 비고 |
|---|---|---|---|---|---|
| L-01 | (예: 업무용 노트북) | | 본인 소유 | 높음 | |

## 회사 자산

| 자산 ID | 설명 | 유형 | 권한 확인 (근거·일자) | 중요도 | 비고 |
|---|---|---|---|---|---|
| C-01 | (예: example.com) | 도메인 | | 높음 | |

권한 확인 열에는 점검 권한의 근거(담당자 승인, 소유 증빙 등)와 확인
일자를 기록한다. 비어 있으면 점검하지 않는다.

## 주요 소프트웨어 (CVE/권고 대조 대상)

| 소프트웨어 | 버전 | 사용 위치 (자산 ID) | 벤더 공지 URL |
|---|---|---|---|

## 중요도 기준

- **높음**: 침해 시 고객 데이터, 자격증명, 서비스 가용성에 직접 영향.
- **중간**: 내부 업무 영향, 외부 직접 노출 없음.
- **낮음**: 실험·개발용, 민감 데이터 없음.
