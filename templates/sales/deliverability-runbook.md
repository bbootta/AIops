## 5. 서킷브레이커 3요소 [G6]

### 5.1 판정 기준 (하나라도 발생 시 발동)

- 바운스율 2% 초과 / 스팸 신고율 0.1% 이상 / 인박스 배치율 85% 미만 / 블랙리스트 등재

### 5.2 사전 방어선 (발송 도구 자동 중단)

- §3의 설정 4번을 PO가 사전 설정하고 deliverability-engineer가 검증 완료한 상태가 캠페인 착수 조건이다. 발동 시 도구 자동 중단이 실제 작동했는지 확인한다.

### 5.3 실행 절차 (PO 수동 중단 런북)

1. 에이전트: 임계 초과 판정 즉시 PO에게 중단 실행 요청 + 도구 자동 중단 작동 여부 확인
2. PO: 발송 도구에서 해당 캠페인/도메인 발송 중단 실행
3. 배치 테스트로 착지 위치 확인 (Gmail/Outlook 분리)
4. 원인 점검 순서: 블랙리스트 → 인증(SPF/DKIM/DMARC 통과율) → 최근 리스트 품질 → 카피/링크 변경 이력 → 트래킹 도메인 → 발송량 급증
5. 원인 제거 후 웜업 볼륨 비중을 높여 1~2주 회복 운전
6. **재개 조건: 원인 제거 확인 + PO 승인, 둘 다 필수** [G6]

## 6. 사고 대응 절차 (kb/sales/02 §6.5)

**스팸함 착지 감지**: 해당 도메인 콜드 발송 즉시 50% 감축(심하면 전면 중단) → 배치 테스트 → §5.3의 원인 점검 순서 → 회복 운전. 회복 불능(2~3주 후에도 배치율 < 50%)이면 도메인 폐기·교체 결정 (PO 승인).

**반송률 급등**: 발송 전면 중단 → 리스트 재검증, 데이터 소스 확인 (catch-all 비중, 리스트 나이) → 하드바운스 전역 suppression 반영 후 재개 (§5.3의 6 재개 조건 적용).

**블랙리스트 등재**: 원인 제거 먼저, 그 다음 해제 신청 (원인 제거 없는 해제 신청은 재등재를 부른다).
