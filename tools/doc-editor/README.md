# 라이트테이블 문서 편집기 (HTML·Markdown)

`index.html` 한 파일로 된 브라우저용 편집기다. 설치와 서버가 필요 없고 인터넷 연결 없이 동작한다.
HTML 문서는 이미지 편집 기능을 크게 보강했다.

## 여는 방법

1. `tools/doc-editor/index.html`을 Chrome 또는 Edge로 연다 (파일을 브라우저 창에 끌어다 놓아도 된다).
2. 처음에는 예시 문서가 열린다. 이미지를 클릭·두 번 클릭해 기능을 바로 써 볼 수 있다.
3. `열기`로 `.html`·`.htm`·`.md` 파일을 열거나, 파일을 편집기 창에 끌어다 놓는다.

## 기능

| 구분 | 기능 |
|---|---|
| HTML 보기 | 시각 편집 · 소스 · 분할(소스와 미리보기 나란히) |
| HTML 서식 | 문단 형식(본문·제목 1~4·인용·코드), 굵게·기울임·밑줄·취소선, 글자 색·형광펜, 정렬, 목록, 들여쓰기, 링크, 표, 구분선, 서식 지우기, 실행 취소 200단계 |
| Markdown 보기 | 편집 · 분할(스크롤 위치 맞춤) · 미리보기 |
| Markdown 서식 | 제목 수준, 굵게·기울임·취소선·코드, 링크, 이미지, 표, 목록·번호 목록·할 일 목록, 인용, 코드 블록, 구분선, 목록 자동 이어쓰기 |
| 내보내기 | Markdown을 서식이 적용된 HTML 한 파일로 내보내기 (Pretendard 서체 지정) |
| 인코딩 | UTF-8·UTF-16·EUC-KR(CP949) 자동 감지. 저장은 UTF-8, `meta charset`도 함께 고친다 |
| 임시 저장 | 편집 중인 문서를 이 브라우저에 자동 보관하고 다시 열 때 복구를 묻는다 |

### HTML 이미지 편집

**문서 안에서 바로**

- 이미지 클릭: 크기 핸들 8개와 도구 막대가 나타난다. 모서리는 비율을 지키고(Shift를 누르면 자유), 변은 한 방향으로 늘린다.
- 도구 막대: 편집 창 열기, 자르기, 왼쪽·가운데·오른쪽 배치, 글 감싸기, 캡션 넣기·빼기, 속성 패널, 삭제.
- 속성 패널(오른쪽):
  - 표시 크기: px 또는 %, 비율 고정, 폭 25·50·75·100%, 원본 크기
  - 배치: 글자처럼·왼쪽·가운데·오른쪽·왼쪽 감싸기·오른쪽 감싸기, 바깥 여백
  - 모양: 테두리(두께·선 모양·색), 모서리 둥글기, 그림자 3단계, 불투명도
  - 설명: 대체 텍스트(비어 있으면 경고), 캡션(`figure`·`figcaption`), 링크, 제목(title)
  - 작업: 이미지 편집, 교체(크기·배치 유지), 파일로 저장, 삭제
- 문서 이미지 목록: 썸네일, 형식, 픽셀 크기, 용량, 경고(대체 텍스트 없음·깨짐·외부 연결·1MB 초과).
- 일괄 최적화: 최대 너비와 형식(자동·원본 유지·JPEG·WebP·PNG), 품질을 정해 내장 이미지를 한 번에 줄인다. 결과가 원본보다 크면 원본을 둔다.
- 넣기: 붙여넣기, 끌어다 놓기(놓은 위치에), 파일 선택, 편집한 뒤 넣기, 웹 주소 연결. 설정한 최대 너비(기본 1600px)보다 크면 줄여서 넣는다.

**이미지 편집 창** (두 번 클릭 또는 Enter)

| 도구 | 내용 |
|---|---|
| 자르기 | 끌어서 영역 지정, 비율 고정(자유·원본·1:1·4:3·3:2·16:9·3:4), 좌표 직접 입력, **여백 자동 자르기**(차트·캡처의 흰 테두리 제거) |
| 회전 | 90° 회전, 좌우·상하 반전, 기울기 보정 -45°~45° (빈 모서리 자동 잘라내기) |
| 크기 | 픽셀 크기 변경, 25·50·75%, 긴 변 800·1280·1600·1920px. 단계적으로 줄여 화질을 지킨다 |
| 보정 | 밝기·대비·채도·색온도·색조·흑백·세피아·선명도·흐림·색 반전, 프리셋(문서 스캔·선명하게·흑백·따뜻하게·차갑게) |
| 주석 | 화살표·사각형·원·직선·펜·형광펜·글자·번호 표시, 색 8종, 굵기·글자 크기, 선택 도구로 옮기기·지우기·글자 고치기 |
| 가리기 | 칠하기·모자이크·흐림. 개인정보는 칠하기를 권장한다 |
| 저장 형식 | 원본 형식·PNG·JPEG·WebP, 품질, 예상 용량과 원본 대비 증감 |

편집 창 안에서 실행 취소·다시 실행·원본으로 되돌리기가 되고, 적용하기 전까지 문서는 바뀌지 않는다.

### 소스 보기의 이미지 데이터 접기

문서에 내장된 이미지(data URI)는 소스에서 `⟦img:3 PNG 245KB⟧`처럼 짧게 접어 보여 준다.
저장·미리보기·복사할 때는 원래 데이터로 펼쳐진다. 도구 막대의 접기 단추로 끌 수 있다.

| Chrome·Edge | 열기로 연 파일에 그대로 덮어쓴다(처음 한 번 권한 확인). 새 문서는 저장 위치를 묻는다 |

| Ctrl+O | 열기 |
| Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | 실행 취소 / 다시 실행 |

## 보안과 데이터

- 문서 내용은 브라우저 밖으로 전송하지 않는다. 편집기가 스스로 외부에 요청하는 것은 없다.
  사용자가 웹 주소로 이미지를 넣거나 문서에 원래 외부 이미지가 있을 때만 그 주소를 불러온다.
- 시각 편집 화면은 스크립트를 막은 iframe에서 연다. 문서 안 스크립트는 실행되지 않고 저장할 때는 그대로 남는다.
- 임시 저장본은 이 브라우저의 IndexedDB에만 남는다. 저장하면 지워진다.
- 모자이크와 흐림은 글자 크기에 따라 다시 읽힐 수 있다. 주민등록번호·계좌번호는 칠하기로 가린다.

## 제약과 알려진 차이

- 시각 편집으로 바꾼 문서는 브라우저가 HTML을 다시 써서 저장하므로 공백·속성 표기가 정리될 수 있다.
  시각 편집에서 아무것도 바꾸지 않았거나 실행 취소로 되돌렸다면 원문 그대로 저장한다.
- 스크립트가 그려 넣는 내용(자바스크립트 차트 등)은 시각 편집 화면에 나타나지 않는다. 소스 보기에서 편집한다.
- 상대 경로 이미지(`images/a.png`)와 CORS를 허용하지 않는 외부 이미지는 편집 창에서 열 수 없다. 교체로 파일을 넣은 뒤 편집한다.
- GIF는 편집하면 첫 장면만 남고, SVG는 PNG 같은 그림 파일로 바뀐다.
- Markdown 미리보기는 GFM 주요 문법을 따르되 두 가지가 GitHub와 다르다.
  - `**PLGD(Potential LGD)**는`처럼 닫는 `**` 앞이 괄호·따옴표이고 뒤가 한글이면 이 편집기는 굵게 보여 주지만 GitHub에서는 굵게가 풀린다.
  - `1.5~1.6`처럼 물결표 하나는 범위 표기로 두고 `~~두 개~~`만 취소선으로 본다. GitHub은 물결표 하나 쌍도 취소선으로 바꾼다.
- 점검은 Chromium에서 했다. Firefox·Safari는 직접 확인하지 않았다.

## 점검

```
npm install -g playwright && npx playwright install chromium     # 처음 한 번
PLAYWRIGHT_MODULE="$(npm root -g)/playwright/index.mjs" node tools/doc-editor/e2e_test.mjs
```

81개 항목을 점검한다: 이미지 선택·핸들·실행 취소, 편집 창 7개 도구, 속성 패널, 붙여넣기·끌어다 놓기,
링크·표, 일괄 최적화, 소스 접기·분할 보기, 저장 결과물(편집기 흔적이 남지 않는지), Markdown 편집·변환 규칙·내보내기,
EUC-KR 열기, 조각 HTML, 스크립트 문서, 임시 저장본 복구, 좁은 화면.
`SHOTS=폴더`를 주면 화면 캡처를 남긴다.
