설명과 링크

대체 텍스트가 비어 있습니다. 화면 낭독기 사용자와 검색을 위해 입력하세요. 꾸밈용 이미지라면 비워 두어도 됩니다.

    이미지를 넣을 때

    이미지는 문서 안에 data URI로 내장됩니다. 문서 한 파일만 옮겨도 이미지가 함께 갑니다.

    HTML UTF-8
    이미지 편집

    자르기

    사진 위를 끌면 새 영역을 지정합니다. 상자 안을 끌면 옮겨집니다. 차트·캡처의 흰 여백은 '여백 자동 자르기'로 한 번에 정리됩니다.

    회전과 반전

    기울기 보정

    0°

    스캔하거나 찍은 문서가 비뚤어졌을 때 쓰세요. 잘라내기를 끄면 빈 모서리는 투명(JPEG는 흰색)으로 남습니다.

    픽셀 크기 바꾸기

    문서에 넣는 이미지는 화면 너비(보통 1600px 이하)면 충분합니다. 픽셀을 줄이면 파일이 크게 가벼워집니다.

    보정

    미리보기는 축소본으로 계산합니다. 적용하면 원본 해상도로 다시 계산합니다.

    주석

    굵기
    글자 크기

    선택 도구로 주석을 끌어 옮기고 Delete로 지웁니다. 글자는 두 번 클릭해 고칩니다. 다른 도구로 넘어가면 주석이 이미지에 합쳐집니다.

    가리기

    강도
    색

    가릴 부분을 끌어서 지정하면 바로 적용됩니다. 주민등록번호·계좌번호 같은 개인정보는 칠하기가 가장 안전합니다. 모자이크와 흐림은 글자 크기에 따라 다시 읽힐 수 있습니다.
