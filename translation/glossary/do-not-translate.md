# 번역 금지 목록 (Do Not Translate)

다음 항목은 어떤 언어로 번역하든 **원문 그대로 유지**한다.

## 항상 유지

- 제품명, 브랜드명, 서비스명 (예: AIops)
- 코드, 명령어, 함수·변수명, 파일 경로, 설정 키
- URL, 이메일 주소, 도메인
- 법인 등기 영문 명칭 (재번역 금지 — 등록 표기 사용)
- 널리 통용되는 기술·비즈니스 약어: API, SDK, KPI, ROI, OKR, B2B, SaaS, MOU, NDA 등
  - 단, 독자가 일반 대중이면 첫 등장 시 풀네임 병기 가능
- 국제 표준·규격 명칭: ISO 27001, SOC 2, GDPR, IFRS 등
- 상표 표기 기호: ™, ®, ©

## 조건부 유지

| 항목 | 규칙 |
|---|---|
| UI 문자열 | 제품에 해당 언어 버전이 있으면 그 문자열 사용, 없으면 원문 + 괄호 번역 병기 |
| 문서·계약 제목 | 참조용이면 원문 유지 + 괄호 번역, 그 문서 자체를 번역 중이면 번역 |
| 법률 라틴어 (force majeure 등) | 영문 계약서에서는 유지, 한국어 번역 시 확립된 법률 용어로 |
| 인용문 출처 | 서지 정보는 원문 유지 |
