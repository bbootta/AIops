# 기타 언어 가이드 (Japanese, Chinese, and Other Target Languages)

한·영 외 언어로 번역할 때의 공통 절차와 주요 언어별 핵심 주의점. 상세 규칙이 없는 언어는 이 문서의 공통 절차를 따른다.

## 공통 절차 (모든 기타 언어)

1. **중계 번역 금지 원칙**: 원문에서 도착어로 직접 번역한다. 한→일 번역 시 영어를 거치지 않는다.
2. **격식 체계 매핑**: 번역 브리프에서 도착어의 격식 수준(경어·존칭 체계)을 먼저 결정하고 문서 전체에 통일 적용한다.
3. **로캘 표기**: 날짜·숫자·통화·주소는 도착 로캘 관례를 따른다 (`style-formatting.md`의 로캘 표 참조).
4. **확립 표현 우선**: 고유명사·기관명·제품명은 해당 언어권의 공식/통용 표기를 검색·확인 후 사용한다. 확인 불가 시 `[TN]`으로 표시한다.

## 일본어 (ja)

- **경어 체계**: 비즈니스 문서 기본은 です・ます체. 사외 문서(고객·거래처)는 존경어(尊敬語)·겸양어(謙譲語)를 관례에 맞게 사용한다. 사내 보고서는 だ・である체도 가능 — 문서 유형에 따라 결정하고 통일한다.
- **비즈니스 관용구**: 일본 비즈니스 문서 고유의 인사 관용구(お世話になっております, よろしくお願いいたします 등)는 영·한 원문에 대응 표현이 없어도 **장르 관례상 필요하면 추가한다** (이메일·공문의 관례적 첫인사/끝인사는 '첨가'가 아니라 장르 변환이다).
- **한자어 주의**: 한국어 한자어와 일본어 한자어의 의미 차이(愛人, 慇懃, 檢討 등 동형이의어)를 경계한다. 검토(검토하다) → 検討(O)이지만, 팀별 뉘앙스 확인 필요한 어휘는 사전 검증한다.
- **가타카나 외래어**: 통용 가타카나 표기를 따른다 (project → プロジェクト). 무리한 한자어 대체 금지.

## 중국어 (zh-CN 간체 / zh-TW 번체)

- **간체/번체는 별개 타깃**: 중국 본토(zh-CN)와 대만·홍콩(zh-TW)은 문자뿐 아니라 어휘·관례가 다르다 (软件/軟體, 网络/網路). 번역 브리프에서 반드시 구분한다.
- **격식**: 비즈니스 문서는 서면어(书面语) 기준. 과도한 성어(成语) 사용은 마케팅 외 문서에서 자제한다.
- **고유명사**: 외국 기업·제품의 공식 중문 명칭이 있으면 사용, 없으면 원문 병기.

## 스페인어·프랑스어·독일어 등 유럽 언어

- **T-V 구분**: 2인칭 격식(usted/tú, vous/tu, Sie/du)을 브리프에서 결정한다. 비즈니스 기본은 격식형.
- **성·수 일치**: 직함·독자 성별을 모르면 포괄적 표현을 쓴다 (스페인어 병기 관례 등은 대상 시장 관례를 따른다).
- **로캘 변형**: 스페인어(es-ES/es-419), 프랑스어(fr-FR/fr-CA), 포르투갈어(pt-PT/pt-BR)는 대상 시장을 브리프에서 확정한다.

## 언어 미지정/신규 언어 체크리스트

새 도착어 첫 번역 시 브리프에 다음을 명시한다:

- [ ] 대상 로캘 (국가·지역 변형)
- [ ] 격식/경어 수준
- [ ] 날짜·숫자·통화 표기 관례
- [ ] 문자 방향(RTL 여부 — 아랍어·히브리어는 서식 재검토 필요)
- [ ] 회사 고유명사의 해당 언어 공식 표기 존재 여부
