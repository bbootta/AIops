# 번역 QA 체크리스트 (Translation QA Checklist)

검수 에이전트(accuracy-reviewer, translation-qa)가 사용하는 점검 기준. 항목별로 통과/수정/보고를 판정한다.

## A. 정확성 (Accuracy) — accuracy-reviewer 담당

원문과 번역문을 문장 단위로 대조한다.

- [ ] **오역 없음**: 의미가 바뀐 문장이 없다. 특히 부정문("~하지 않는다"), 조건문, 주체(누가), 시제.
- [ ] **누락 없음**: 원문의 모든 문장·절·수식어·표 셀·각주가 번역에 존재한다.
- [ ] **첨가 없음**: 원문에 없는 정보가 추가되지 않았다 (장르 관례상 인사말 등은 예외 — `document-types.md`).
- [ ] **숫자 전수 대조**: 모든 숫자·날짜·금액·퍼센트가 원문과 일치한다. 만/억 ↔ million/billion 환산 재검산.
- [ ] **고유명사 대조**: 인명·조직명·제품명이 용어집 또는 공식 표기와 일치한다.
- [ ] **중의성 보존**: 법무 문서에서 원문의 중의성이 임의로 해소되지 않았다.

## B. 용어 (Terminology) — accuracy-reviewer 담당

- [ ] 용어집(`../glossary/glossary.md`) 등재 용어가 지정 번역과 100% 일치한다.
- [ ] 번역 금지 목록(`../glossary/do-not-translate.md`) 항목이 원문 그대로 유지되었다.
- [ ] 용어집에 없는 핵심 용어가 문서 전체에서 하나의 번역으로 통일되었다.
- [ ] 신규 용어가 용어집 추가 후보로 보고되었다.

## C. 자연스러움 (Fluency) — fluency-editor 담당

번역문만 읽고 판정한다 (원문 비교 없이).

- [ ] 번역투 패턴이 없다 (`en-to-ko.md` §1 / `ko-to-en.md` §2~5의 패턴 목록 기준).
- [ ] 어체·격식이 문서 전체에서 통일되었다.
- [ ] 도착어 원어민이 소리 내어 읽었을 때 걸리는 문장이 없다.
- [ ] 문장 길이가 도착어 관례에 맞다 (지나치게 긴 직역 문장 없음).
- [ ] 장르 관례를 따랐다 (이메일 인사말, 개조식 종결, 계약 관용구 등).

## D. 형식 (Formatting) — translation-qa 담당

- [ ] 제목 계층·표·목록·강조·링크가 원문 구조와 일치한다.
- [ ] 표 내부 텍스트, 이미지 캡션, 각주가 모두 번역되었다.
- [ ] 날짜·숫자·통화 표기가 `style-formatting.md` 로캘 규칙을 따른다.
- [ ] 문장부호가 도착어 관례를 따른다.
- [ ] 좌우 공백, 전각/반각(일·중), 특수문자가 깨지지 않았다.

## E. 최종 판정 — translation-qa 담당

- [ ] A~D의 모든 수정이 반영되었고, 수정이 새 오류를 만들지 않았다.
- [ ] 남은 `[TN: ...]` 번역 노트를 전부 수집해 사용자 확인 목록으로 정리했다.
- [ ] 산출물 요약 작성: 문서 유형, 어체/격식 결정, 주요 용어 결정, 확인 필요 항목.

## 심각도 분류

| 등급 | 정의 | 처리 |
|---|---|---|
| Critical | 오역·누락·숫자 오류·용어집 위반 | 반드시 수정 |
| Major | 번역투, 격식 불일치, 형식 깨짐 | 반드시 수정 |
| Minor | 더 나은 표현이 있는 수준 | 수정 권장, 취향 문제면 유지 |
| Query | 원문 자체의 오류·모호함 | 수정하지 말고 사용자 보고 |
