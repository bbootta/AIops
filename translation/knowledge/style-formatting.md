# 표기·서식 규칙 (Style & Formatting Rules)

숫자, 날짜, 통화, 단위, 고유명사 표기의 로캘별 변환 규칙. QA 단계에서 이 문서 기준으로 기계적 대조를 수행한다.

## 날짜·시간

| 로캘 | 표기 | 예 |
|---|---|---|
| ko | YYYY년 M월 D일, YYYY. M. D. | 2026년 8월 8일 |
| en-US | Month D, YYYY | August 8, 2026 |
| en-GB | D Month YYYY | 8 August 2026 |
| ja | YYYY年M月D日 | 2026年8月8日 |
| zh | YYYY年M月D日 | 2026年8月8日 |

- 영문 기본은 en-US로 하되 브리프에서 지정 시 변경.
- 숫자만 쓰는 표기(8/9, 09.08)는 로캘별 해석이 갈리므로 **월을 문자로 풀어쓰는 것을 기본**으로 한다.
- 요일 병기 관례: 한국어 "8월 8일(금)" → 영어 "Friday, August 8".
- 시간: 한국어 "오후 2시" → "2:00 PM" (24시간제 원문은 24시간제 유지).
- 기간: "3박 4일" 같은 관용 표기는 도착어 관례로 ("4 days, 3 nights").

## 숫자·단위

- 자릿수 구분: EN/KO/JA/ZH 모두 3자리 콤마 (1,234,567). 유럽 언어는 로캘 확인 (독일어 1.234.567 / 프랑스어 1 234 567).
- **만·억·조 환산 (오류 최다 구간)**:
  - 1만 = 10 thousand / 10만 = 100 thousand / 100만 = 1 million
  - 1억 = 100 million / 10억 = 1 billion / 1조 = 1 trillion
  - 예: 3,500억 원 → KRW 350 billion / $2.4B → 24억 달러
- 퍼센트포인트(%p)와 퍼센트(%)를 구분해 유지한다.
- 단위: 원문 단위 유지 기본. 미국 대상 마케팅 문서 등 요청 시에만 환산하고 원 단위 병기.

## 통화

- 한→영: "1억 5천만 원" → "KRW 150 million" (첫 등장) 이후 "KRW 150M" 허용. ₩ 기호는 표에서만.
- 영→한: "$3.2 million" → "320만 달러". 환산 원화 병기는 **요청 시에만** (환율 명시 필수).
- 혼동 방지: "billion"이 나오는 문장은 QA에서 전수 재검산한다.

## 고유명사

- **인명 (한→영)**: Revised Romanization 기본 + 확인된 개인 공식 표기 우선. 표기: Gildong Hong (이름-성). 문서 전체 통일.
- **인명 (영→한)**: 외래어 표기법 기준 (John → 존, Catherine → 캐서린). 통용 표기가 굳어진 인물은 통용 표기.
- **회사·조직명**: 공식 등록 명칭 최우선 (홈페이지·공시 확인). 용어집 `glossary.md`의 조직명 절이 최우선 소스.
- **제품명·브랜드**: 번역 금지 (`do-not-translate.md`).
- **직급·직함**: 용어집의 직급 매핑 표를 따른다. 매핑이 없으면 다음 기본값:

| 한국어 | 영어 기본값 |
|---|---|
| 사원/주임 | Associate |
| 대리 | Assistant Manager |
| 과장 | Manager |
| 차장 | Deputy General Manager |
| 부장 | General Manager / Director |
| 이사/상무/전무 | Director / Managing Director / Executive VP |
| 대표이사 | CEO |
| 팀장 | Team Lead(er) |
| 실장 | Head of [부서명] |

## 문장부호

- 한국어: 온점(.) 기본, 낫표(「」)·화살괄호(《》)는 관례상 필요 시. 영문 따옴표 " " → 한국어도 " " 사용(현행 어문 규범 허용).
- 영어: 이탤릭(문서 제목), Oxford comma는 문서 내 통일(기본: 사용).
- 물결(~) 범위 표기는 영어에서 en dash 또는 "to" ("10~20%" → "10–20%" / "10 to 20 percent").
- 중점(·) 나열은 영어에서 콤마 또는 슬래시로.

## 서식 보존 체크

- 제목 계층(H1~H4), 표 구조, 목록 깊이, 굵게/기울임, 링크 URL, 이미지 참조는 원문과 동일하게 유지.
- 표 안 텍스트도 번역 대상이다 (누락 빈발 구간).
- 각주·미주 번호와 내용 대응 유지.
