# Policy — PD / LGD / EAD

신용위험측정요소(PD, LGD, EAD)의 검증 기준.

## 1. PD

### 1.1 공통
- 변별력: 신용평가모형과 동일 임계 적용 (`harness/policies/credit_scoring.md`)
- 캘리브레이션: 등급별 PD vs CDR (`tools/binomial_calibration.calibration_test_per_grade`)
- Holm-Bonferroni 다중보정 적용 권고
- 등급별 표본 < 30 시 신뢰구간 폭을 보고서에 명시

### 1.2 설계 구분 (TTC · PIT)

PD 는 용도에 따라 설계가 갈린다. **TTC** 는 IRB 자본 산출용이라 경기순환주기를
반영한 장기평균이어야 하고, **PIT** 는 IFRS 9 ECL 용이라 시점 조건부여야 한다.
같은 등급체계를 양쪽에 쓰면서 라벨만 바꿔 다는 것이 이 절의 주된 점검 대상이다.

국내 근거는 세칙 별표 3 이다.

> 은행은 PD 추정시 5년 이상의 관측기간에 걸친 외부 데이터, 내부 데이터 또는
> 금융기관간 공유 데이터 중 하나 이상을 이용하여야 한다.

> PD 추정에 사용된 데이터는 경기순환주기를 반영하여야 하며, 과거 1년 부도율의
> 평균을 기초로 산출되어야 한다.

임계는 `harness/pd_design_thresholds.json`, 도구는 `tools/pd_cyclicality.py`.

**TTC 주장 시 점검**
1. 관측기간이 5년 이상인가 (세칙 별표 3 인용값, `regulatory_criteria thresholds` 가 원문 대조)
2. 등급별 PD 의 연도간 변동계수가 임계 이하인가. 등급별 PD 가 움직이면 TTC 가 아니다
3. 포트폴리오 평균 PD 변동이 **등급 이동**으로 설명되는가. 수준분이 지배하면 사실상 PIT 다
4. 등급별 PD 가 거시변수와 유의하게 상관되지 않는가
5. 관측기간이 하방 국면을 포함하는가. 호황 구간만의 평균은 장기평균이 아니다

**PIT 주장 시 점검**
1. 예측 PD 시계열이 실현 1년 부도율 시계열을 추종하는가 (상관·평균절대편차·방향 일치율)
2. 시나리오별 PD 반응의 방향과 크기가 타당한가 (가중치는 `tools/scenario_weights`)
3. OOT 변별력을 **시점별로 분해**했는가. 전체 평균은 특정 국면의 붕괴를 가린다
4. PIT PD 변화가 SICR 판정·스테이지 이동으로 연결되는가

**TTC ↔ PIT 변환 점검**
1. 변환 함수(단일요인)의 자산상관과 시스템적 요인 추정 근거
2. 왕복 검증: TTC → PIT → TTC 에서 원값이 복원되는가
3. 국면 부호: 호황에서 PIT < TTC, 침체에서 PIT > TTC 가 뒤집히지 않는가
4. 자본(TTC)과 ECL(PIT)에 같은 등급체계를 쓸 때 두 값이 변환 관계로 설명되는가.
   설명되지 않으면 둘 중 하나는 근거가 없는 값이다

판정은 **설계 주장과 자료가 어긋나는지**를 본다. 어긋나지 않는다는 것이 추정이
옳다는 뜻은 아니다.

## 2. LGD
- downturn LGD vs 평상시 LGD 구분 기준 명시
- 회수 인정 시점·임계가 모형 가정과 일치하는지 확인
- 부도시점 표본 적정성 (`middleware/sample_size_guard`)
- 추정 LGD vs 실측 LGD 비교 (평균/중위/분포)

## 3. EAD
- CCF 추정 시 한도 사용률 0% / 100% 극단값 처리 기준 명시
- 한도 사용률 분포의 안정성 (PSI)
- 추정 EAD vs 실측 EAD 비교

## 4. 공통 점검
- 부도 정의 일관성
- 표본 기간 / 개발-운영 분리
- 누수 (`middleware/leakage_guard`)

## 5. 임계 변경
임계 변경은 `harness/change_manifest.json`에 사유·증거·롤백 기준과 함께 기록.
